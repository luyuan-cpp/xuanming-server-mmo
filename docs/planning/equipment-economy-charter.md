## 1. 需求分析

### 1.1 历史方案复盘：为什么仅靠“回收 + 5% 手续费 + 自由当面”会踩坑

站在个人开发者的真实经营与玩家体验视角，复盘旧经济候选稿（16+4 / 旧器砂→调灵符 / 聚宝斋 5% 手续费 / 自由当面交易）及 V1 简化稿，存在 **4 个必须从顶层根治的结构性风险**：

1. **个人开发者赚不到钱，利润倒挂**：
   - 旧稿寄希望于“冷启动不在官方商城直售材料，先靠聚宝斋 5% 手续费 + 未落地外观”赚钱。按旧稿自身算例，月成交额（GMV）¥10,000 时 5% 毛收仅 ¥500，扣支付、出款、拒付准备、服务器与客服后税前仅余 ¥150；要覆盖个人开发者基本生活与运维，需撑起 ¥30 万+/月玩家间真钱交易额，中小体量独立游戏几乎不可能达到。
   - 同时，玩家愿意花 ¥30–¥60 省进度，95% 现金流进卖料者或工作室口袋，开发者只分 5% 却承担 100% 研发、运维、二清合规与纠纷风险。
2. **物价稳不住：前期怕免费多开砸盘，后期怕毕业通缩死市**：
   - 若按角色每日发可交易料，工作室可建大量零成本免费小号刷爆供给，材料迅速贬值成白菜价；
   - 而装备采用“固定词条 + 强化 +10 必成 + 永不损坏”的良心框架，玩家 30–60 天满套后若缺乏横向消费出口与合理供给闸门，市场会迅速滞销通缩，搬砖与经营双双熄火。
3. **游戏内当面交易的“制度摩擦差”把玩家逼去站外被骗**：
   - 技术层面的双边锁单、条款修订递增、明文差异对比与禁用缩写已经防住了“临门少打零 / 同名白板换强装”；
   - 但官方聚宝斋要等 **48 小时公示 + 5% 手续费 + 3 天卖家冷静期**，而游戏内当面交易**免税、秒到、还允许 0 银两赠送 / 1 银两转移贵重装备**。骗子天然能用“走游戏内当面我微信转你，省税不用等两天”把小白诱出官方托管，产生个人开发者无力兜底的站外诈骗纠纷。
4. **“绑定染毒”误操作 + 跨端资金契约缺口 + 换流派卡脖子**：
   - 纯可交易（T）装备混入哪怕 1 颗绑定（B）材料即永久变绑，玩家连点强化极易手滑毁掉装备残值；
   - 现有代码仍存两项真钱硬缺口：`go/trade` 生成 `trade:<数字>` 与 `java/mall_game` 纯数字校验不兼容，以及缺少逐单争议冻结拦截提现；且货已消耗后的渠道强制拒付无法仅靠 3 天冷静期自动追回；
   - 若为了强行养商人而把改词条成本做重、让免费玩家无旧装可拆或逼玩家多开小号凑 T 料，会同时毁掉“好玩”与“不肝”。

### 1.2 本总纲要同时达成的五大目标

1. **好玩不肝**：延续 [core-gameplay-loop.md](core-gameplay-loop.md) 的“无日常打卡、有空就玩”，让换技能、换词条、试新流派轻快无负担，杜绝经济设计倒逼玩家建十个小号当苦力。
2. **免费公平**：零氪玩家不买月卡、不逛市场，依然可以 100% 拿到满配 +10 首套与全部玩法体验，付费不突破战力上限。
3. **官方 7 : 搬砖/工作室 3**：通过《问道》式“官方直售配套道具 + 搬砖产出月卡门槛 + 永久收藏外观”组合，让玩家花出的总消费中约 **70%+ 稳进官方口袋**、约 **20%–30% 净利留给真实付出时间的搬砖/经营玩家**。
4. **物价长期稳得住**：建立供给真成本锚、价格上下双锚、横向长青消费、真实中位参考价与动态调节护栏，做到不靠官方现金保底也不崩盘。
5. **防骗与资金零硬伤**：堵死游戏内当面逃费引流站外、消除手滑绑定染毒、明确真钱聚宝斋上线前的一票否决工程与合规门禁。

## 2. 设计分析

### 2.1 官方 7 : 搬砖/工作室 3 的《问道》式双轨商业化模型

核心思想：**不靠抽玩家交易的 5% 过日子，而是把“打造/进阶/养成提速/外观/搬砖门票”拆成官方与玩家市场互补的双轨结构。**

#### (1) 消费流向分工（官方 70%+ vs 玩家市场 30%）

| 板块 | 归属 | 核心载体 | 免费玩家公平边界 |
|---|---|---|---|
| **零氪自养基盘** | 全员免费 | [核心循环](core-gameplay-loop.md)永久 660 份自用材料（300 打造 + 300 百炼石 + 60 余量）+ 满套后稳定产银两与绑定重铸砂 | 0 元可达成与付费玩家完全一致的 +10 必成上限与 36 固定词条 |
| **官方直售配套道具（问道核心引擎）** | **官方 100%** | 官方商城（灵石直购，明码标价、无随机赌博）提供配套功能道具：<br>① **装备传功/继承令**（跨套/换装保留强化或转移养成，配合玩家银两/旧装）；<br>② **天工保交易打造/提纯配套件**（想造“可交易成品/进阶副套/精炼外显”时，需玩家产出的可交易胚子/材料 + 官方配套道具组合）；<br>③ **解封/剥离符**（对原胚纯 T 但误混 B 养成的装备剥离绑定附着、恢复纯 T 原胚，不洗白 B 料）；<br>④ **限量绑定首套提速包**（6–30 元档，终身限购总量，仅自用不污染市场）；<br>⑤ **绑定「定星保底符」与「天工秘墨」**（见 [equipment-quality-and-skill-crafting-v1.md](equipment-quality-and-skill-crafting-v1.md)：分别用于装备 5 档词条打磨保底提速与 ≤10% 稀世绝学定向制书，均永久绑定防洗白，免费玩家按节奏可达 100% 同上限） | 所有官方道具均不提供“免费玩家永不可及的独占数值上限”；仅卖省时间、保交易、多套便捷与外显 |
| **永久收藏外观 + 轻便利月卡 + 江湖恩怨仪式耗材** | **官方 100%** | ① 10 元永久角色形象卡衣柜 + 后续宝宝幻化/技能与擂台特效；<br>② 整合升级现有 30 元 [挂机月卡](../design/afk-monthly-card.md)（可提供 ¥18–¥30 档位「仙途轻享卡」）：含断线跟队托管、技能/配装预设槽扩展（3→6）、摆摊时长翻倍、**搬砖产出可交易货源资格**；<br>③ **江湖恩怨纯排面/便利直售**（[battle-jianghu-grudge-duel-bounty-v1.md](battle-jianghu-grudge-duel-bounty-v1.md)，经 [灵石百宝阁](spirit-shop-and-starter-packs-v1.md) 绑定直发）：一期「金帖生死状」（20 灵石）与「清风洗尘符」（10 灵石），二期「千里追踪符 / 清心保释文书 / 金令通缉文书」；严禁自由银两对赌或 1:1 悬赏转移银两（普通战书/洗尘/铜银悬赏全部销毁银两，兼具稳物价回收池作用） | 绝不做月卡掉落翻倍、绝不做每日登录领奖打卡、0 战斗数值加成且零波及和平散人 |
| **玩家时间件与旧物流转** | **搬砖/玩家（官方抽 5% 税）** | 游戏内可交易基础材料、可交易旧装胚子、可交易重铸砂、高资质野生灵宠、游戏银两（先走银两集市/摆摊，二期资质齐备再择机开聚宝斋） | 普通玩家不逛市场照样毕业；想省时间或淘极品胚子/野宠时，从玩家市场购买 |

#### (2) 7:3 收入比例算例校验

假设一位微氪/中氪玩家在 1–2 个月内围绕多流派与外观共投入 **¥140**：
- 在官方商城花 **¥80**（如 2 张 10 元形象卡 + 1 张 30 元轻享卡 + ¥30 官方配套道具/限量绑定提速包）→ **100% 进官方**；
- 在玩家市场花 **¥60** 购买搬砖玩家产出的可交易材料 / 旧装胚子 / 高资质野宠（假设官方抽 5% 手续费 = **¥3**，卖家毛收 ¥57）；
- 搬砖玩家为了具备持续产出可交易材料的资格，向官方缴纳月卡门票 **¥25–¥30/月**（100% 进官方）。

最终现金流分配：
- **官方（你）净收**：`¥80 + ¥25（搬砖门票） + ¥3（5% 税） = ¥108`（占玩家总支出 **约 77%**，若考虑多个搬砖号分摊单月门票，稳落 **70%–78%** 区间）；
- **搬砖/经营玩家净利**：`¥57 − ¥25（门票成本） = ¥32`（占总盘 **约 23%–30%**）。

**关键红利**：即便冷启动阶段**完全不开真钱提现聚宝斋**（只开官方商城灵石直购 + 游戏内银两集市），玩家仍可用灵石/银两双轨流畅消费，你第一天就能赚到 70%+ 的全端合规现金流，零二清风险、零 iOS/小游戏过审阻碍。

### 2.2 「物价稳得住」五道经济稳定器（核心机制）

游戏物价失控无非两个方向：**通胀崩盘**（免费脚本无限产货砸成 1 分钱）与 **通缩死市**（毕业后无人消费、挂单全滞销）。本总纲用五道互锁机制从根部稳住物价：

#### 稳压器 1：供给侧「真成本门槛」（消灭免费黑号零成本砸盘）
- **零氪体验与持续搬砖解耦**：
  - 零氪账号享受永久 660 份免费自用材料（全额自养毕业）+ [core-gameplay-loop.md](core-gameplay-loop.md) 账号终身 60 份起步体验可交易额度（删角、换季不重置），保证每个普通玩家都能体验一次“卖东西”的乐趣；
  - 账号终身 60 份体验额度用尽后，**免费未开月卡账号的后续产出全部自动绑定（仅自用）**；
  - 只有**开通有效月卡（搬砖通行证）且完成实名/正常活跃度校验的账号**，才能在玩法中持续产出可交易材料、可交易基础胚子或高流通银两（且受合理的账号级周平滑产出上限约束，不设逼人天天打卡的日清任务）。
- **稳价原理**：只要每个搬砖号每月存在固定真实成本 `¥18–¥30` + 真实游玩时间，工作室就不可能无限起一万个免费脚本号把单价砸穿成本线——一旦市场价逼近门票成本，多余脚本自动无利可图退场，**供给端自带负反馈止跌机制**。

#### 稳压器 2：价格「上下双锚」（既防黑商炒上天，也防滞销跌归零）
- **价格上限锚（防炒作与垄断）**：
  - 官方商城存在明码标价的**绑定限量提速包**与配套功能道具（例如锚定 0.1 元/份参考价值）。
  - 如果有大商企图囤货把市场可交易材料炒高到远超合理溢价，正常买家直接转购官方绑定包或自己免费打试炼，囤货大商瞬间滞销亏本。**市场价天然被锁在合理上限以下**。
- **价格底线锚（防通缩归零，且绝不做现金回购）**：
  - **坚决不设官方人民币保底回收价**（避免变成随时挤兑的资金盘）；
  - 但在游戏内建立**稳定、真实的银两与重铸砂消耗底盘**：
    - 银两（`kCurrencyGold`）出口：自由技能解锁与修习、轻度词条重铸（20 银两/次）、装备原地升档、全 8 件法宝补充兑换、商店普通宠/抓宠口粮、神秘商人 4–6 折淘货、离线摆摊与集市 5% 银两税销毁；
    - 旧装/重铸砂出口：旧装拆砂用于可交易装备改配与多套流派切换；阶段二满套后的日常战斗产出**绑定自用砂**，不再向市场倒灌过剩可交易砂。
  - 当材料/银两价格偏低时，玩家用便宜银两去解锁技能、淘神秘商人、多养一只宝宝、多配一套副套的意愿会立刻上升，形成**自然抄底消费垫**。

#### 稳压器 3：需求侧「纵向封顶、横向常青」（防 60 天毕业后全服鬼市）
- 纵向装备上限永远封顶在 `+10 必成`（不碎装、不靠赛季清零强迫重肝），但经济消费不依赖单套装备：
  - **多流派副套需求**：物攻 / 法攻 / 封控 / 治疗 / 护盾 / 混搭，老玩家有动力配第 2、第 3 套装备与全 8 件法宝；
  - **多宠生态需求**：22 种分图栖息灵宠 + 不同技能/资质定位（破甲宠、速控宠、龟速拉人宠、收割宠），抓宠口粮、洗炼与培育持续消耗银两与时间件；
  - **周期新主题内容（平级扩宽，不淘汰旧装）**：新地图、新首领机制、新技能组合与外观收藏系列持续带来温和的新流派配置需求，让市场保持细水长流的换手率。

#### 稳压器 4：信息透明与防操纵护栏（不让假行情带偏物价）
- **真实中位成交价锚点**：集市、摆摊与游戏内当面交易均展示服务端统计的**近 7 日真实中位成交价（p50）与成交笔数**；样本量不足阈值（如 < 10 笔）明确显示“样本不足”，**绝不把“挂高价未成交的标价”或“同账号/关联对敲单”画成市场指导价**。
- **防刷盘与囤货限制**：同账号自买自卖直接拒绝；单角色同时在售挂单数与大宗商品单批上限可配；新上架商品按实际成交纳税，撤单不产生任何活跃度奖励或补贴。

#### 稳压器 5：个人开发者可用的「低运维调控仪表盘」（只调未来，不毁旧账）
服务端定期输出 5 项低基数聚合指标（严禁把 `player_id` / 订单号放进 Prometheus 标签），按红黄绿阈值做小步微调：

| 监测指标 | 异常信号 | 允许的温和调控动作 | 严禁的破坏性动作 |
|---|---|---|---|
| **核心流通品净库存天数** | 连续 14 天飙升（产大于销） | 略微收紧未来新活动流通比例、新增银两/耗材横向趣味消费（如新宠口粮/外观染色） | 严禁悄悄削弱已产出道具属性或强制装备损耗 |
| **近 7 日 p50 成交价偏离度** | 跌破门票折算成本带 / 暴涨超官方锚 2 倍 | 下跌时排查脚本多开并收紧零门槛异常产出；暴涨时微调官方限量包配额或增加新图正常产出 | 严禁官方下场印钱托盘或强制封顶没收玩家合法库存 |
| **银两净增发/净销毁比** | 连续 2 周产出远大于消耗（银两通胀） | 提高神秘商人银两精选池吸引力、补齐技能/法宝/摆摊银两消耗 | 严禁暗加首套必经的银两卡点逼肝 |
| **Top20 关联账号产出占比** | 异常集中且伴随重复脚本战斗轨迹 | 结合行为审计（非单凭同 IP）封禁脚本外挂、限制异常搬货号流通产出 | 严禁仅凭“赚得多”或“同家庭 Wi-Fi”误封正常玩家 |
| **30/60 日后真实换手率** | 活跃卖家有货但独立买家持续萎缩 | 推出新流派技能/新宠/新副本主题带动横向换配，接受低峰期商人自然减少 | 严禁通过赛季清空强化或强迫每日改词条制造伪需求 |

### 2.3 游戏内当面交易防骗与站外引流阻断

> 明确口径：本文所指“当面交易”均为**游戏内面对面交易窗口**。

#### (1) 技术防骗底座（完整保留并固化）
沿用并强制执行 [equipment-recycling-trade-economy-candidate.md §7](equipment-recycling-trade-economy-candidate.md#L268-L314) 与 [V1 §6](equipment-recycling-trade-economy-v1.md#L94-L105) 已经验证合理的技术机制：
- 双方各编辑自己一侧，固定展示服务端权威的角色公开编号、名字、头像与系统好友关系（好友不等于担保）；
- 固定“我付出 / 我得到”两列，原件完整展示唯一实例号、模板、强化、全部词条、流通状态；金额与数量**严禁“万 / 亿 / K”缩写**；
- 各自锁定 = 后端真实资产预留/托管；**任意一方修改任何条款立即递增 `offer_revision`、清空双方锁定与确认，并持久化明文高亮变更项**（如 `100,000 银两 → 10,000 银两`、`青锋剑+5(实例A) → 青锋剑+0(实例B)`）；
- 双方确认同一 `offer_revision` 与服务端规范清单摘要后，trade 单事务落唯一交割决定，两侧幂等持久到账后完成，断线/未知只查原单恢复。

#### (2) 堵死“免税秒到后门把小白诱去微信/QQ 站外被骗”（核心补齐）
仅靠技术锁单挡不住骗子说“聚宝斋太慢还扣 5%，走游戏内当面先给我装备我微信转你”。必须通过**制度收口 + 降低官方托管摩擦**双向夹击：

1. **游戏内当面交易收紧策略（二选一，首选 A）**：
   - **方案 A（首选推荐，最适合个人开发者）**：**游戏内当面交易仅开放低价消耗品与单日小额银两互助**（例如单日单角色当面流转参考价值上限，禁止当面转移成品装备原件与大宗核心材料）。所有贵重装备、宠物、大宗材料一律统一走**公开银两集市 / 离线摆摊 / 未来聚宝斋**。从物理上消除“陌生人当面零元秒转高价货”的诈骗工具，省掉 80%+ 人工判案。
   - **方案 B（若坚持保留游戏内当面转贵重装备的社交情怀）**：必须同时上线三道硬闸，拉平与官方托管的摩擦力差：
     - **好友时长门槛**：仅允许**互加好友满 7 天（且非临时解绑重加）**的双方进行游戏内当面贵重品低价/赠送转移，陌生人或新加好友禁止 0/低银两转移贵重资产；
     - **参考价偏离保护**：服务端比对“双方物品按近 7 日中位成交价折算的差额”；若偏离超过 50%（含 0 银两赠送、1 银两换贵重品），非长期好友直接拒绝，长期好友交易后物品自动进入 **24–48 小时不可拆/不可转/不可上架冷静保护锁**；
     - **官方“指定买家”定向单**：无论银两集市还是二期聚宝斋，均支持卖家下“指定对方角色 ID”的定向托管单，把“熟人/谈好价想交易”的合法需求导回官方资金托管，彻底剥夺骗子“嫌公开单会被别人抢走、只能走当面”的话术借口。
2. **聚宝斋（二期）分层公示，消除逼人逃费的体验痛点**：
   - **48 小时公示期仅用于高价值唯一资产**（成品装备原件、高阶宠物、角色过户，用于防盗号贱卖留出冻结找回窗口）；
   - **小额标准同质材料包**（如单笔 ≤ ¥50 的材料/重铸砂批次）公示期缩短为 **0–2 小时**（上架前过安全锁/绑定验证即可），让正常买家觉得官方渠道又快又省心，自然不愿冒险去站外。

### 2.3.1 卖家信用评分系统（类日常店铺评分，过户清空 + 异地换机直接清 0 + 防刷分）

借鉴日常电商/店铺评分机制，为集市、摆摊与聚宝斋卖家建立可查、可量化、防买壳诈骗的信用体系（权威归属 `go/trade` 逻辑库 `mmorpg_trade`，遵循 `AGENTS.md §7.6` 一库一服务）：

1. **展示与评分口径（像平常店铺一样一眼看懂）**：
   - 卖家档案按当前持有周期（`owner_revision`）独立统计并对外展示：**信用分 / 星级（0–100 分 / 1.0–5.0 星，新店初始基准 60 分 / 3.0 星）**、**真实成交总笔数**、**好评/中评/差评数与好评率**、**违约/投诉/拒付次数**、**异地换机清零标与最近环境变更时间**、**当前持有者开始时间**；
   - **只能基于真实官方托管成交产生评价与加分**：单笔订单完成后允许买家在有限窗口内（默认 7 天）提交一次好评/中评/差评，超时默认计正常履约但不虚高刷星。
2. **私下卖号 / 外地借号 / 盗号换机直接清 0（绝不误伤坐高铁/切 5G）**：
   - 记录卖家在当前持有周期内的最近 IP 与有界常用设备列表（上限 8 台；仅用于服务端风控比对，不进 Prometheus 高基数标签、不向其他玩家泄露原始 IP/设备号）；
   - **单纯换 IP 绝不扣分**：同一台手机/电脑坐高铁回家、出差跨城或切 5G/Wi-Fi，设备未变，**0 影响**；
   - **同网络换设备或切回已记录常用设备不扣分**：例如在家同一 Wi-Fi 下手机与电脑切换（或换新手机后先在家里常用 Wi-Fi 登录登记），或切回此前常用设备，**0 影响**；
   - **一旦同时命中「从未见过的陌生新设备」且「IP 也发生变化」**（私下卖号、外地借号、盗号换机的核心特征）：
     - **直接清 0**：立即清空累计正面成交笔数、好评数、中评数与历史常用设备列表，**信用分直接清为 0（1.0★）**，标记 `EnvCreditCleared = true`（对外显式提示“检测到异地陌生新设备，历史信用已清零”），风控档立降为受限档并开启换机后防突击刷分冷静期；
     - **防洗白红线**：本操作**绝不清除原有 `ViolationCount`（核实违约/拒付）与 `NegativeReviews`（差评）**，防止劣迹卖家借故意异地换机洗白黑历史。
3. **四重防刷分硬限制（杜绝小号刷五星）**：
   - ① **同账号自买自评直接拒绝**（`ErrSelf`）；
   - ② **买卖同 IP / 同设备互评不计分**：买家与卖家命中相同 IP 或相同设备指纹时，评价留痕但 `CountedForScore = false`，不加信用分、不计入好评数；
   - ③ **跨小号同账号 / 同 IP / 同设备 7 天滚动窗口限计一次**：即使骗子用 10 个不同小号在同一台设备或同一 IP 下买单刷好评，7 天内对同一卖家最多仅计 `MaxScoredReviewsPerPairInWindow`（默认 1 次）评分，其余一律 `CountedForScore = false`；
   - ④ **最低有效计分金额 + 单笔幂等禁改评**：低于 `MinScoreAmountMinor` 的极小额（如 1 银两）好评不涨分；同一订单只能评一次，改评拒回 `ErrReplay`；核实违约、欺诈投诉或恶意拒付单笔重扣 25 分并立降受限档。
4. **角色过户 / 换人强制清空信用（防“买高信誉老号行骗”）**：
   - 当角色经由聚宝斋角色交易、官方过户或后台变更归属账号（`owner_revision` 递增或 `owner_account` 变更）时，服务端在同一权威链路上**强制清空该角色名下的历史卖家信用分、星级、累计成交数、好评/差评数、异地换机清零记录与历史店铺标签**，新持有者从初始默认信用重新积累；
   - 新持有者对外展示明确标注“**持有者已变更（YYYY-MM-DD），历史信用已清空重算**”，且同时重置回“新卖家保守额度档位”，过户前旧交易的迟到评价只归档在旧 `owner_revision`，绝不污染新持有者。
5. **信用与风控/交易权限联动**：
   - 高信用且长期无违约的正常卖家，可逐步解锁更高单日挂单上限、定向单效率及二期更高提现额度；
   - 新换人/触发异地换机清零/低信用/有未结纠纷的卖家，自动受更严格的额度与公示保护约束。

### 2.4 防“绑定染毒”手滑毁装机制

针对“纯可交易（T）装备误混 1 颗绑定（B）材料即永久失去交易资格、残值归零”的隐形坑，建立四重防护：

1. **后端+前端默认绝对隔离**：只要操作目标装备为 `可交易（T）`，打造、装词条、强化、重铸接口**默认锁死 `consume_policy = TRADEABLE_ONLY`**。背包里 T 材料不够时，按钮直接置灰并明确提示“可交易材料不足”，**严禁静默用绑定（B）材料补齐**。
2. **显式降级 + 防肌肉记忆强确认**：若玩家确实想拿 B 材料给 T 装备强化，必须在界面手动打开独立开关“允许混用绑定材料（此装备将永久变为仅自用）”，且最终确认弹窗不能与普通“强化/确定”按钮重合——采用**长按 2 秒或手动输入“确认绑定”**提交，彻底消灭连点手滑。
3. **轻改配不染毒**：对 T 装备执行不增加战力数值上限的流派词条替换时，只要消耗的是可交易银两与可交易重铸砂（或仅消耗非绑定银两），装备保持 `T` 不降级。
4. **不洗白的官方“剥离/解封符”（兼顾容错与官方 70% 营收）**：
   - 物品实例持久记录两个独立语义：`origin_tradeable`（原始胚子是否纯 T 出生）与 `current_tradeable`（当前是否可交易）。
   - 若装备原胚为 `origin_tradeable = true`，后来因使用了 B 强化石或 B 词条材料导致 `current_tradeable = false`，允许玩家消耗官方商城小额灵石道具「解封剥离符」执行**清空绑定附着养成**（将后加的绑定强化/绑定投入清零或剥回绑定仓库，**绝不产出任何可交易材料、绝不将 B 料洗成 T**），使原胚恢复 `current_tradeable = true`。

### 2.5 跨端资金契约与交付后拒付兜底（真钱上线一票否决门禁）

#### (1) 冷启动硬边界：先不开放真钱提现聚宝斋
- **首发阶段（一期）**：只开 **官方商城直售（灵石/外观/月卡/配套道具）+ 游戏内银两集市 + 主城离线摆摊**。
  - 官方直售遇恶意退款只需封停退款账号并扣回对应灵石，不存在“货已被买家消耗、卖家还要向平台追讨货款”的三角死局；
  - 彻底绕开冷启动期个人主体无法申请平台收付通/二清合规风险，以及 iOS / 微信小游戏 / 抖音小游戏审核限制。

#### (2) 二期开启真钱聚宝斋前必须通过的 6 项一票否决门禁

| 编号 | 门禁项 | 必须落地的具体方案与验收标准 |
|---|---|---|
| **G-1** | **修复跨端托管引用格式冲突** | 解决 `go/trade/internal/commerce/rmb.go`（生成 `trade:<数字>`）与 `java/mall_game/.../RmbConsignmentStore.java`（纯数字校验）不兼容；统一正式契约（推荐商城接口显式接收 `source + uint64 contract_id` 或校验规范 `trade:<uint64>`），并补齐 **Go trade → Java mall 真实 HTTP 登记 / 幂等重放 / 退回** 跨端集成测试通过 |

| **G-4** | **支付渠道拒付隔离** | 聚宝斋玩家寄售订单**仅开放国内实名微信支付 / 支付宝直连**；**严禁接入高拒付风险的海外信用卡或苹果 IAP / 小游戏充值渠道**购买玩家寄售商品，不支持的端隐藏真钱购买入口且不提供站外扫码 |
| **G-5** | **买家 72 小时保护锁对齐卖家冷静期** | 买家在聚宝斋购得的高价资产（或可转售资产）交付后自动带 **72 小时禁转卖/禁拆毁保护期**（与卖家 3 天收益冷静期对齐）；冷静期内若触发盗刷/司法协查/渠道撤销，自动冻结该单卖家出款并锁定买家背包内原件或记负账追偿 |
| **G-6** | **提现风控梯度与坏账准备金** | 新实名卖家设小额月/日提现上限（随账号信誉与交易履约逐步放开）；平台从 5% 手续费中固定计提 10%–20% 作为拒付坏账准备金，不把全部毛手续费当作净利支配 |

## 3. 思想分析

1. **为什么“官方 7 : 搬砖 3”与“稳物价”本质上是同一枚硬币的两面？**  
   如果游戏允许零成本免费小号无限刷可交易材料，表面上是“让利给玩家”，实际上是把整个经济交给了脚本集群：脚本把物价卷崩 → 散人搬砖赚不到钱、官方 5% 手续费归零 → 开发者没收入弃坑 → 全服鬼服。反过来，引入**零氪自用免费毕业 + 搬砖持续产出需月卡门票 + 进阶/多套采用“玩家坯子 30% + 官方配套 70%”双轨配方**后：
   - 免费玩家体验 100% 不打折；
   - 工作室的每一分产出都有真实门票成本和需求锚，物价跌不穿底、炒不破顶；
   - 官方拿稳 70%+ 主现金流，才有余力长期更新好玩的新副本、新流派和新外观，形成**开发者—搬砖生态—普通玩家三方共赢的正飞轮**。
2. **为什么防骗不能只靠“弹窗提醒 + 免责声明”？**  
   玩家被骗几乎都不是“没看清少了一个零”，而是**机制激励本身制造了绕过官方托管的诱惑**（一边慢 48 小时扣 5%，一边当面秒到免税）。好的经济安全设计不是出事后拿免责条款教育玩家，而是通过**拉平官方与私下的体验摩擦 + 封堵陌生人零元直转后门 + 默认隔离防手滑**，让玩家沿着最顺手的路径走就是最安全的路径。
3. **为什么“好玩优先”要求把换流派从经济税源里解放出来？**  
   回合制的核心爽感是研究技能、装备词条、法宝与宝宝的化学反应。如果换一次词条都要拆 1.25 件昂贵装备、等两天买符，玩家就会锁死抄作业的唯一解，既毁掉了游戏趣味，也反噬了市场活跃度。用轻度银两/满套绑定砂托底自由换流派，把付费和经营留在“省时间、多套副装、外观收藏、极品胚子与灵宠”上，游戏才真正好玩且长青。

## 4. 漏洞分析与防线总表

| 潜在漏洞 / 攻击场景 | 攻击路径与破坏后果 | 本总纲硬防线 |
|---|---|---|
| **免费多开脚本砸穿物价** | 注册上千个免费账号刷完首套 60 份流通额后抛售砸盘 | 账号 60 份体验额需真实合格对局完成（受异常战果与 `afk-detection` 监控）；用尽后无月卡全绑定；持续搬砖必须交月卡门票，抬高脚本边际成本，压缩无利可图脚本空间 |
| **大商囤货恶意拉高市场价** | 垄断某类材料高价挂单，利用均价显示割小白韭菜 | 上方有官方直售绑定提速包价格锚封顶；行情仅展示近 7 日真实成交 p50 且剔除同号/高关联对敲；样本不足隐藏行情曲线 |
| **游戏内当面骗局诱去微信转账** | 骗子用“省 5% 税、不用等 48 小时”诱导小白走当面 0/1 银两先交货 | 首选 A 直接限制当面仅可交易低价耗材与小额银两；若选 B 则强加 7 天好友门槛 + 参考价偏离拦截/冷静锁 + 官方指定买家定向单；小额标准品公示缩至 0–2h |
| **连点强化误把纯 T 装备染成 B** | 花钱买的纯 T 装备因手滑混用 1 颗 B 石头永久贬值归零 | `T` 装备服务端默认强制 `TRADEABLE_ONLY`，料不够直接置灰报错；混 B 需独立勾选 + 长按/输入确认；另提供不洗白原材料的官方小额「剥离解封符」救回原胚 |

| **私下卖号/外地借号/盗号换机绕过过户借壳行骗** | 骗子线下私买账号、外地借号或盗号换设备登录，未触发官方 `owner_revision` 递增，企图冒用原号主高信誉 | 命中**陌生新设备 + IP 同时变化**时**直接将信用分、历史成交与好评清 0**（保留黑历史违约/差评防洗白）并立降受限档 + 开启短期防刷分冷静期；单纯坐高铁/切 5G 换 IP 或同 Wi-Fi 切换常用设备 0 影响 |
| **同号/多小号同设备或同 IP 刷店铺五星好评** | 骗子用 10 个不同小号在同一台手机/模拟器或同一 IP 下买单互刷好评 | 四重防刷分：同账号自评直接拒绝；买卖同 IP/同设备互评不计分；同一买家账号、同一买家 IP 或同一买家设备 7 天窗口内对同一卖家仅计有限次（默认 1 次）评分；低于最低金额不涨分 |
