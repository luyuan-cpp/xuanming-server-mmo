## 选人规则草案

1. 先保留玩家指定的合法主目标，再从其他合法单位中按该技能的规则排序补选，主目标和副目标均不重复。合法人数不足时只作用实际人数。
2. **低血收尾按当前气血数值；救援按气血比例。** 比如120/1000与50/200，比例最低的是前者，气血数值最低的是后者。初版建议并列时随机；不据相同比例再擅自加入另一套优先规则。
3. 物攻、法攻、物防、法防分别比较。建议读取实际出手时已生效的战斗属性，包含已有增减益；高攻不等于真实威胁必然最高，低防也不保证最终伤害最高，护罩和减免仍正常结算。
4. 低速策略建议读取**本回合排速使用的速度值**。本回合新施加的加减速从下一回合才影响排速及该策略排序，不额外把速度低解释为脆弱、治疗职业或必定尚未行动。
5. 出手时一次确定名单，后续某目标抵抗、闪避、倒地或气血变化不额外补人。主目标在出手前失效、各技能合法候选过滤和取样时点的精确顺序，随公用规则一起确认。
6. 选中与命中分开：S03/S04对主目标和副目标都按对应条目判障碍；S01/S02有害标记的抵抗归类仍待定，不新增未经确认的条目字段。策略不赋予必封、必中或无视护罩。
7. 固定自身、混乱强制行动、被动、追击、开场保留各自规则。受混乱的宝宝仍只攻击自己随机1名队友并正常耗蓝，不能借这些候选技能扩大友伤人数。

## 平衡取舍草案

- **S01/S02与长期降攻分工。** 标记建议最多保留2回合，削弱一次对应攻击后消耗。A03戈鸣断势仍是敌5、降物攻5回合，候选不改写A03。一次多目标或多段攻击怎样消费标记及降伤幅度待定。
- **S03/S04用覆盖人数换精准封锁。** 先测敌2，基础成功率不高于对应普通群封，也不额外延长控制。精准两目标仍可能比随机五目标更有压制力，要观察核心单位实际能否获得行动窗口。
- **S05/S06用覆盖换收尾。** 先以普通五目标群攻同档的每目标伤害、减少到敌3测试，不同时增加收割附效。
- **S07/S08用覆盖换救援。** S07先以普通即时治疗同档每目标恢复量测试友4，避免与A12残血增幅同时叠出全面优势。S08的容量和持续时间需单独配置；两招都不具备A26的复活效果。
- **S09/S10集中强化一次出手。** 印记建议最多保留2回合、触发即消耗，与A25七目标且持续5回合的增伤分工。增幅、与A25及其他增伤的叠加、一次多段攻击如何消费均待定。
- **S11/S12先保守测试敌2。** 低防选人可能直接提高实际伤害，初版不再加穿防或必暴；若有效伤害和击杀收益不足，再评估是否扩大到3目标，不提前改表。
- **S13/S14先测试敌3。** 低速不保证低防或低血，重点观察对后手单位的实际压力；是否能先于目标出手仍遵守正常排速。
- **宝宝候选保留两目标。** 降为单目标后只剩玩家手选目标，副目标策略失去作用。SP01/SP02先用略低伤害换精准收益，耗蓝、冷却及伤害降幅需验证，不凭人数相同直接照搬普通双目标的全部数值。
- 新旧同类障碍、减益共用对应抗性、覆盖和连控边界，不能因新技能名绕开限制。这里只记录独立候选，不因“同效果取最大人数”删除它们，也不将其直接折回旧技能的模式开关。

## 后续评审条件

所有候选维持待定，不进入当前基础技能实施排期。恢复评审时，先确认保留哪些招式、各自学习资格、目标数、完整效果和成本，再给正式表分配身份。

优先试打方向仅供后续安排：S01/S02、S05/S06与S07，随后比较S08和低防/低速攻击；精准硬封S03/S04需重点验证连控。覆盖5人物加5宝宝、小规模对局、纯物理/纯法术/混合阵容及首领，比较有效伤害、击杀、过量治疗、被压制行动数和多人轮流施放的覆盖率。低目标人数不等于已达到平衡。

当前仅记录这些新策略技能。[率土式候选](stzb-inspired.md)继续等待用户研究原作机制，不用该页的E编号或原作名义为本页效果背书。
