# 宝宝条目点与轻量培养

更新：2026-11-17。返回[技能总览](README.md) · [宝宝技能与分类](active-pet.md) · [宝宝条目点 UI 交接](pet-entries-ui.md) · [公用规则](combat-rules.md)。

**最新已确认：宝宝输出、障碍、治疗、护盾等专项方向共用一份条目点预算，替代原来的自选条目加成，不额外赠送障碍池或辅助池。** 基础四维与人物装备来源不变。总点数、每点收益、单项上限和具体开放目录仍待定；本页不表示代码或正式配置已经实现。

## 四维与条目来源（本轮已定）

人物和宝宝均保留**体质、灵力、力量、敏捷**四维基础加点，不新增神识、慧心等第五／第六基础维度。宝宝另用统一条目点分配原有专项培养预算；四维点与条目点是两种用途，不把障碍和辅助各做成一个赠送点池。

| 内容 | 人物 | 宝宝 |
|---|---|---|
| 基础加点 | 体质、灵力、力量、敏捷 | 同样四维；资质参与属性成长收益 |
| 专项培养来源 | 人物装备词条 | 每只宝宝自身的统一条目点分配结果 |
| 调整入口 | 按人物装备规则获取、替换和调整 | 宝宝面板“条目加点”，战外调整、战内锁定 |
| 保留的技能系统 | 合法已学技能、被动与临时状态按各自规则 | 技能、被动、追击、开场与条目点分开记录 |

宝宝不读取主人的装备词条，不新增宝宝装备栏或第二套打造。人物合法施加给宝宝的增益仍是技能状态，不属于装备继承。底层效果结构是否复用被动尚待设计；同一贡献不得同时作为旧自选条目、新条目点和被动重复计算，已有合法被动也不能因此被删除。

人物装备规则及V1数值分别参考[八部位装备策划](../equipment-eight-slot-planning.md)与[装备V1词条、法宝目录](../equipment-v1-affixes-artifacts.md)。宝宝分点规则不直接套给人物装备，也不把人物打造材料预算套给宝宝。

## 统一条目点怎样分配

- **已确认的取舍**：物理输出、法术输出、对应障碍、治疗与护盾争用同一有限预算。提高某个方向的投入，必须占用这份预算；不能保留原自选条目的全额加成后再叠加点收益。
- **基础能力仍存在**：某方向投入0点，仅表示没有来自条目点的该项强化，不清零技能基础效果、资质、四维或其他合法来源。点数也不自动解锁新技能。
- **分项计算**：治疗效果与护盾容量分别投入；封物命中、混乱命中等按具体障碍类型分别投入，不用一个“辅助点”或“控制点”同时抬高全部效果。
- **界面与数值待定**：总点数、每项上限、允许同时投入的方向数、每点收益与是否递减均须另定。10点、单项6点、6＋4等仅是对话举例，不成为正式配置；不再沿用4条或1固有＋3自选的槽数设计。
- **非随机结果**：同配置、同条件、同投入对应确定的效果，不做随机高低值洗练。旧“同档固定条目值”改为由投入与规则表确定收益，并不要求所有投入都得到同一数值。
- **成本边界**：沿用不专门做任务、不刷材料升级条目的方向，战外可调整、战内锁定。建议获得宝宝即开放可分配预算、战外免费重分配；具体总量和发放／重分配契约待定，不擅加收费或刷点流程。

建议正式分配使用非负整数点数：各项投入之和不超过总预算，每项不超过其配置上限；若正式规则另有限制，由服务端统一校验。UI显示总量、已用、剩余与各项当前／草稿投入。剩余点数不等于少学了技能，不能为凑满而自动分配。

| 分配方向示意 | 四维投入方向 | 条目点重点 |
|---|---|---|
| 物攻 | 力量为主，体质／敏捷取舍 | 物理伤害；若改投治疗，输出强化随之减少 |
| 法攻 | 灵力为主，体质／敏捷取舍 | 法术伤害；其他专项共用剩余预算 |
| 障碍 | 体质和敏捷按时机取舍 | 一种已获准使用的障碍命中，兼修另一种也要分同一池 |
| 治疗／护盾 | 体质和敏捷按队伍节奏取舍 | 治疗与容量分别分点，兼顾两者不能各免费取满 |

表中是新规则下的方向建议，不是最优比例。现版治疗仍读取法攻、现代技能按最大法力比例耗蓝；未改公式前，不向玩家声称灵力只管法力或法力越多一定多放几次。需要同步评审法攻与治疗基础的关系，避免高法攻兼得过高治疗。

## 宝宝具体条目清单（首版建议，待确认）

PE编号保留作为效果方向引用，不是技能ID、正式表ID或已开放的分配项。以下各项是否纳入首版、每点增幅、上限和单位仍待评审；不因改变为加点就自动批准整张候选表。

| 引用 | 效果方向 | 作用范围 | 新点池中的状态与边界 |
|---|---|---|---|
| PE01 | 物理伤害 | 本宝宝普攻及合法手动技能的直接物理伤害 | 输出方向候选；不同时再加一遍物攻面板，不放大破甲比例、毒伤或派生事件 |
| PE02 | 法术伤害 | 合法手动技能的直接法术伤害 | 输出方向候选；不自动提高治疗、护盾或毒伤，耗蓝不等于法术伤害 |
| PE03 | 速度 | 本宝宝行动速度属性 | 是否纳入专项点池待评审，避免与四维重复购买；不直接增加命中或行动次数 |
| PE04 | 气血上限 | 本宝宝最大气血 | 是否纳入专项点池待评审；不自动提供治疗／护盾倍率，调整后的当前气血另定 |
| PE05 | 防御 | 本宝宝防御属性 | 是否纳入专项点池待评审；现有面板只有统一防御，不等于固定减伤百分比 |
| PE06 | 施放治疗效果 | 合格即时治疗、持续治疗 | 辅助方向候选；不等于受疗增加，不自动增加复活血量、吸血、蓝换血或人数 |
| PE07 | 护盾容量 | 合格容量型护盾／护罩的吸收量 | 辅助方向候选；不增加次数、时长、反弹或法力承伤换算，治疗过量不产盾 |
| PE08 | 指定障碍命中 | 一种已开放障碍的成功率修正 | 按类型分别投入，不强化全部障碍、不解锁技能、不突破免疫 |
| PE09 | 指定障碍抵抗 | 抵抗一种可遭遇的障碍 | 是否及如何纳入首版待定；不要求宝宝自己会施放，不等于免疫或伤害减免 |
| PE10 | 中毒命中 | 合法施毒技能的施加成功率 | 专项候选；与毒伤分开，不延长中毒 |
| PE11 | 毒伤 | 合法中毒效果的周期伤害 | 专项候选；不提高命中、不额外叠毒或增加目标 |
| PE12 | 劝退命中 | B09游说退敌的成功率修正 | 专项候选；仍仅合法敌宠，不等同一般障碍命中 |
| PE13 | 抗劝退 | 本宝宝抵抗劝退的能力 | 专项候选；不等于全部异常抵抗，不恢复已退场宝宝 |

PE08／PE09按具体类型展开。封灵、封法、封物、混乱、昏睡、冰冻是否开放与字段映射，按技能资格及[公用规则](combat-rules.md)落实；PE08不再包含已单列PE10的中毒命中。抗中毒可作为PE09类型，劝退单列PE12／PE13，不重复归入一般障碍。攻击类选项的资格须明确；没有合适技能不由客户端自行解锁或擅加禁选规则。

PE03—PE05仍是保留的效果候选，并未删除现有速度、气血、防御或相关被动。首版建议基础面板主要由四维负责，是否将这些候选开放到条目点另评审；如果采用，也必须占用同一预算，不能再附赠生存或速度点池。

### 配套结算与平衡边界

- 每方向按自身收益曲线换算，1点伤害与1点命中不机械对应相同百分比。须明确百分比／百分点、基数、叠加层、取整、总上限、免疫和特殊目标规则；共有预算不等于已经平衡。
- PE01／PE02建议先只覆盖直接伤害，反击、追击、反弹、转移与混乱强制攻击的适用性另评审。B12吸血若随实际伤害增加，只承接间接收益，不额外乘治疗条目。
- PE06仅在宝宝已获准的即时治疗（如A10）及A26存活目标正常续疗中按正式公式适用，不因分点开放人物A12。A26复活消费整份印记不变，复活初始血量不自动吃治疗加成。
- PE07用于B05／B06等技能须以正式采用容量型吸收为前提；不将容量点换成护罩次数、反弹比例、B14承伤扣蓝或B15蓝换血优惠，人物A40也不因此开放给宝宝。
- 分点只强化明确的数值效果，不购买额外目标、行动、控制时长、净化数量或技能资格。0点不禁止已有合法技能；既有被动、追击、开场仍按自身资格与触发规则生效。
- 共享预算、每项上限与收益曲线要一起试算，不能默认线性6＋4就有多种最优搭配。比较同等级／资质／技能条件下的输出、有效治疗、吸收、控制行动数、生存和耗蓝，检查纯方向、混合与少量多项分配。
- 若未来纳入上限属性，重分配时必须防止反复调整免费补满血蓝；当前资源如何保持或夹取另定。不得修改真实状态再回滚来冒充预览。

物法暴击、分类减伤、忽视对应抗性、正常施法减耗仍是后续扩展候选，不默认开放；若采用也占同一条目预算，不另赠点。暴击不自动作用于治疗／盾／毒，忽视不突破免疫，施法减耗不减生命代价、蓝换血支出或法力承伤扣蓝。

## 品阶与个体特色（五档讨论方案，待确认）

用户要求高阶宝宝优于低阶但差距不要太大，先讨论神兽高于变异、变异高于普通，并进一步询问五个阶级。当前命名候选为：**普通 → 变异 → 灵兽 → 神兽 → 圣兽**。五档是否正式采用、名称、定义、获取／升阶方式及具体差异仍待确认，不能据此改现有品质枚举、资质或玩家资产。

| 项目 | 当前建议 | 确认边界 |
|---|---|---|
| 条目点总量与单项上限 | 各品阶保持一致，不随高阶赠送点数或额外池 | 平衡建议；不把示例总量写死 |
| 固有特色 | 可按宝宝种类体现条件性用途，高阶仅在擅长处小幅增强 | 固有特色是否采用、是否占预算、与被动关系及数值均待定 |
| 速度、命中、人数与行动 | 不同时按品阶全面抬升 | 推荐边界；不改变现有技能规则 |
| 外观差异 | 模型、入场动作、技能表现体现稀有度 | 美术方向建议，非新增战斗效果 |
| 获取与养成 | 不默认每档都要刷一遍，不推定普通能逐档升成神兽 | 获取／升阶／付费方案另议 |

此前“4条”“1固有＋3自选”未确认，也不再作为新点池的槽位合同；固定特色如后续采用，须明确预算与既有被动关系，不能默认叠送新效果。普通至圣兽气血0%／2%／4%／6%、特色10%／11%／12%／13%及条目12%／15%等都是讨论试值，不能自动沿用或扩成五档正式数值。综合强度还受资质、四维、技能和触发条件影响，不能声称某一项差3个百分点就保证总体只差3%。

## 获取、调整与实现边界

用户的“不想专门做任务、不要太肝、可以小氪”继续适用。条目点不建立刷材料升级或随机洗数值流程；具体发放总量、是否随等级变化、重分配流程待配表。小额付费不自动授权付费加点、提高上限、出售独占技能或强制升阶，收费方案另议。

新系统须保存每只宝宝的分配向量、预算与配置版本，并在战斗前生成权威效果快照。当前四维加点、资质和技能列表接口不能代存条目点；新协议、正式存档、归属／预算／上限／战斗锁定校验和精确预览均待实现。UI详细交接见[条目点面板](pet-entries-ui.md)，不把本地演示当已保存账号数据。

三分类、全部合法已学手动技能可选、每回合合计一招保持。宝宝辅助／一般障碍单体，物法攻击及蚀骨毒最多敌2，特殊技能按各自规则；条目点数不等于技能数、被动数或分类入口数。人物A40独立七目标护盾与免费／付费最终技能资格一致等已定规则不受本次分配方式变化影响。

## 历史已替换：固定自选条目

原方案是从共同候选中选择有限数量的固定加成，战外更换、战内锁定。2026-11-17用户明确确认以统一条目点替代该自选加成流程。保留其不随机洗数值、不刷材料、按宝宝分别保存及效果语义，不再保留旧勾选数量和固定加成作为新点池之外的收益。

## 历史未采用方案：四类独立专长

**以下各节完整保留前轮讨论，只供历史对照，均非当前生效规则。** 当前采用上文的条目定位方向，不因下文使用“建议”“首版”等旧措辞恢复独立专长或其加成。

### 历史：共同规则建议

- 每只宝宝同一场战斗只启用1个专长方向，玩家在战斗外选择，进战斗锁定；是否允许切换、切换条件与成本待定，不默认绑定物种或新增收费。
- 首版专长不另设等级、经验条或多级天赋树。建议以一种独立成长选择承载，不占主动攻击／障碍／辅助三个入口，也不据此规定宝宝只能有一个被动。被动、追击、开场的启用数量与方式仍另行确认。
- 全部合法已学的手动技能仍可选，跨三个分类每回合合计一招；辅助/障碍按各技能既定单体规则，攻击及蚀骨毒最多敌2，不由专长扩人数。混乱强制攻击仍仅自己随机1名队友、正常耗蓝。
- 非专长技能按正常基础效果使用，不额外惩罚伤害、命中或治疗。专长只提供该方向的加成，救场同时仍要放弃本轮其他手动行动。
- 同档宝宝成长投入有限。速度主要改变先后，伤害读取对应输出属性，障碍读取对应条目；不能因为选了一个专长再同时额外提高速度、生存、全部输出和全部控制。

### 历史：四类专长首测参数

| 方向 | 暂定名称 | 核心加成试值 | 耗蓝试值 | 主要用途 |
|---|---|---|---|---|
| 物攻 | 锋锐 | 本宝宝普攻及手动技能的直接物理伤害提高15% | 物理攻击手动技能的正常施法耗蓝降低10% | 两目标物伤、碎甲后接输出、集中击杀 |
| 法攻 | 灵慧 | 本宝宝手动技能的直接法术伤害提高15% | 法术攻击手动技能的正常施法耗蓝降低10% | 两目标法伤、应对物理护罩、法术输出 |
| 封控 | 凝神 | 选择一种已开放且可用的障碍类型，对应命中修正增加8个百分点 | 该重点障碍的手动施法耗蓝降低10% | 让某一种封锁或障碍更可靠，仍可使用其他已学技能 |
| 辅助 | 济世 | 施加的治疗量或合格护罩容量提高15%；每个辅助动作只指定一个受强化的主数值项 | 已明确标记为辅助的手动技能正常施法耗蓝降低10% | 治疗、保护与辅助续航；净化、增益等主要获得耗蓝优势 |

这些参数需要在相同成长投入、技能等级、目标防御/抗性和战斗时长下比较。百分比增伤与命中百分点不是同一种收益，不能据表格数值相近认定已经平衡。

### 历史：物攻与法攻的作用边界

专长放在统一的伤害加成环节，同一伤害段只应用一次，不同时给物攻/法攻面板再加15%。这样不会因为法攻专长提高面板，连带提升治疗基数或“最高法攻”选人优先级。原有养成属性照常参与基础伤害计算。

- A02横戈裂岳吃物攻专长，A06紫霄雷阵吃法攻专长；两目标各按对应伤害段结算，人数不变。
- A18碎甲击只强化物理伤害，破防幅度与时长不增加。B12摄魂汲血在伤害类型确定后按对应专长处理；吸血若由实际伤害折算，只承接伤害增加的间接收益，不再额外乘一次治疗加成。
- 首版不强化追击、镜像反击、反弹、转移伤害等派生事件，也不新增暴击、穿防或追击次数。其伤害归类和后续是否开放专长加成分别待定。
- 蚀骨毒仍是最多敌2的持续攻击；毒伤不因“攻击”分类自动算物理或法术直伤。首版物法专长不强化毒跳伤害，毒伤培养继续按对应条目评审。
- 混乱强制攻击首测不享受专长伤害或耗蓝优惠，沿用正常攻击数值和耗蓝，避免从敌方施加的障碍获益；这一交互是待评审建议，不改变混乱的单队友规则。

物理/法术攻击的识别必须按技能效果标签，而不是“耗蓝就算法术”。治疗、护罩、封法等虽消耗法力，也不自动享受法攻专长。

### 历史：封控专长的重点类型

凝神建议在封物、封法、混乱、昏睡、冰冻、中毒中选一种重点类型，前提是该类型已允许宝宝学习且本宝宝有合法技能。名单是选择范围草案，不直接开放目前未确定的宝宝技能资格。游说退敌首版不享受凝神的命中加成或耗蓝折扣，劝退仍按自身条目规则评审。

8个百分点是统一成功率公式的一项专长修正，不是忽视抗性、不是再掷一次骰，也不是同时给所有障碍加成。建议按原条目算出未截断结果，加入该修正后使用统一上下限；免疫仍优先，不能被专长突破。正式条目单位、上下限、修正顺序和快照来源须在实施前确认，不能把“8个百分点”直接当作现有某个字段加8。

例如其他条件不变、原判定60%且未触碰上下限时，试值为68%，不是60%乘1.08。成功仍逐目标判定；时长、人数和同类控制覆盖规则不变。中毒重点只提高施毒成功率，不放大毒伤、延长毒或增加目标；其他障碍只获得原本的正常效果。

宝宝的对应条目来源和战斗传递需要核对，不预设已经存在完整宝宝装备、命中或忽视字段。速度影响出手先后，不直接换算障碍命中，也不代替对应条目。

### 历史：辅助专长的具体覆盖

济世的“提高15%”不表示所有辅助效果都提高15%。每个技能只选一个可量化主效果作为加成入口，其他机制保持原规则。状态若已记录加成后的每跳回血或容量，后续消耗/结算不再重复乘专长加成。

| 技能或机制 | 主数值试值 | 继续保持的规则 |
|---|---|---|
| A10青莲润生 | 即时治疗量提高15% | 宝宝友1，不能复活 |
| A26生生不息 | 存活目标在回合末的正常持续回血提高15% | 最多五次结算；触发复活时只按复活规则处理，不提高复活初始血量、不另补一次续疗；复活即消费整份印记，重挂仍可再复活，不额外增加结算或复活资格 |
| B05如意灵环、B06神龙护体 | 若采用已讨论的容量模型，所施护罩容量提高15% | 抵挡次数、持续回合、适用伤害类型不增加；容量模型未确定前不能把加成转换成额外免疫次数 |
| B16舍身救主 | 治疗部分提高15% | 仍牺牲施法宝宝、只救助1名其他存活友方，净化项数和次数限制不改变 |
| A33清心荡秽、A34驱灵散势 | 不提高净化/驱散数量，仅正常施法耗蓝降低10% | 友/敌单体、可清除范围与清除顺序按技能规则 |
| A14/A16/A25/A27、B11等增益 | 不提高增益数值，仅正常施法耗蓝降低10% | 防御、速度、伤害、闪避、追加倍率、持续回合及次数不因专长增加 |
| B07乾坤反震、B08五色返照 | 不提高反弹比例，仅正常施法耗蓝降低10% | 受护友1，反弹回该次来袭者，不扩大对象或次数 |
| B14法力护盾 | 仅施放该技能的正常法力成本降低10% | 受护者用法力承伤的换算和扣除不打折，不能把施法优惠再用于每次挡伤 |
| B15移灵养元 | 首版不纳入辅助优惠 | 自身法力换血的比例、临时上限与代价保持，防止改变资源转换收益 |
| B09劝退、B13舍命破灵 | 首版不纳入辅助优惠 | 敌方资源/退场机制单独评审，不因“敌方辅助单体”标签自动强化 |

治疗基础公式应保留辅助方向的价值；如果基础治疗高度依赖法攻，必须比较高法攻输出宝宝是否仍能同时成为最强治疗。15%专长加成不能单独保证解决该问题，必要时重新评审治疗对技能等级、宝宝等级与属性的取值。该公式调整仍待定。

### 历史：消耗与结算示例

普通施法成本折扣只应用一次，例：100法力变为90；零耗蓝动作保持零，不生成返蓝。正数成本的最低值、取整与其他折扣共存时的计算顺序待统一确认。血量牺牲、资源转换、目标替自己承伤消耗等不属于施法耗蓝优惠。

| 隔离其他变量的例子 | 无专长 | 对应专长试值 |
|---|---|---|
| 一段符合条件的直接物理或法术伤害 | 1000 | 1150 |
| 一次合格即时治疗 | 1000 | 1150 |
| 回生印对存活目标的正常持续回血 | 200 | 230，仍最多五次；复活按原复活血量结算且消费整印，不叠加本次续疗 |
| 一个合格护罩的容量 | 2000 | 2300，次数不变 |
| 一次所选重点障碍的成功率 | 60% | 68%，仅限未触碰概率边界且目标非免疫的例子 |
| 一次符合优惠标签的正常施法法力成本 | 100 | 90 |

伤害例子仅比较专长因子，不意味着护盾、免疫或其他减免失效。计数类机制和资源转换不按这些比例套算。

### 历史：四种定位的试打

| 定位 | 成长与专长搭配建议 | 跨定位技能的用途与代价 |
|---|---|---|
| 物攻宝宝 | 偏物理输出，配锋锐 | 可以临时治疗、净化，但没有济世加成，并放弃本轮攻击 |
| 法攻宝宝 | 偏法术输出，配灵慧 | 可用物攻绕开局部限制或帮忙治疗，但只获得该技能原本效果 |
| 封控宝宝 | 投入速度与对应障碍条目，配凝神的一种重点 | 可用其他障碍或辅助应急，只有重点类型享受专长修正；不能同时拥有最高生存与输出 |
| 辅助宝宝 | 投入生存与合适速度，配济世 | 治疗/保护更有效且辅助续航更好；攻击或封控时没有输出/封控专长收益 |

这些搭配不规定某物种必须走某方向。先比较同档成长投入下的实际输出、有效治疗、有效吸收、控制行动数、法力耗尽时间与存活率，检查高速宝宝是否仍在所有方向占优。再检查多人交替护罩/回生印与连续控制的覆盖，以及普通宠临时救场是否仍有实际价值。

只按试打结果调整参数，不把上述15%、10%和8个百分点当作已验证数值。四专长的采纳、最终参数和实现方式都需后续确认。
