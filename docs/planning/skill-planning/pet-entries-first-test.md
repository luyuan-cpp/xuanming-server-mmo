# 宝宝条目点与五阶首测参数（2026-11-18）

本文件把 `pet-specialties.md`、`pet-entries-ui.md` 中已确认的共享预算、分型障碍、独立治疗/盾和五阶身份落实为首测配置。下述数值由本轮授权采用，均待平衡；不是美术示意值、旧品质或获取类别的换算。

## 权威配置

- `PetRule.xlsx`：`entry_config_version=1`，每只宝宝独立共享 `entry_total_points=20`，`entry_max_directions=0`（不限非零方向数）。所有等级、五阶使用相同预算。
- `PetEntry.xlsx`：21 个稳定方向，单项上限均为 20。物理伤害 501、法术伤害 502、治疗 503、数值盾 504、中毒伤害 531 每点 +50 万分比（0.5%），满投 +10%。
- 511–517 分别为封主动、封法、封物、混乱、睡眠、冰冻、中毒命中；521–527 为相应抗性；532 劝退命中、533 抗劝退。每点 +25 万分比（0.25 个百分点），满投 +5 个百分点。命中仍遵守原技能合法目标、概率钳位与抗性，不等于必中/免疫。
- PE03 速度、PE04 气血、PE05 防御原本仅候选，首版继续归四维；不额外复制条目渠道，不产生加减点补血。
- 免费全量重分配，允许从已保存方向减点；0 点仍可使用已学技能。既不授予技能，也不增加目标、持续时间、额外行动。
- 任意预算/目录/上限/收益变动必须递增 `entry_config_version`；旧配置版本的预览/保存拒绝。

## 作用边界

物/法伤只作用于宝宝普通攻击及正常手动直接技能，普通连击可享受；反击、追击、镜像、混乱强制行动、反震、分担、周期伤害不重复享受。物/法攻击面板不改。

治疗仅施放方即时和持续治疗；持续治疗挂载时快照一次。复活起始血量、吸血和蓝血转化排除。护盾只增加有限数值容量，不增加次数、时长，法力盾换算排除。中毒伤害只在中毒挂载快照中计一次，消费中毒与每跳不再叠乘。分型命中/抗性与劝退各走自身渠道。

## 五阶归属

`PetTier.xlsx` 独立定义 1 普通、2 变异、3 灵兽、4 神兽、5 圣兽，使用对应美术徽章资源。此字段与 `quality`（普通/精良/稀有/传说）和 `acquisition_tier`（获取方式）完全独立。

本次核对 `Pet.xlsx` / 导出的 `pet.json` 22 个现有种类名称、描述和获取行，没有明确“变异××”或“神兽××”种类。因此这 22 行在新 `cultivation_tier` 列显式首测登记为普通（1）；不根据灵狐、苍嶂麟等名字猜阶，也不把品质 2 推断成变异。后续明确种类归属只修改此列。新宝宝出生写入独立实例身份；老存档仅缺省 0 时按显式列补一次，非 0 身份（包括未来未知值）不被重登或改表覆盖。交易保留整只实例。

本轮不新造五阶进阶消费/抽奖来源，也不从身份额外叠加伤害、速度或命中倍率。现有种类原始资质/成长照常；高阶优势的进一步数值仍需独立平衡配置，不能拿徽章样例当结算参数。

## 保存与兼容

`PetInstance.entry_allocated` 独立保存。`entry_state_version` 乐观并发控制；成功请求同时保存 request_id、旧状态版本、配置版本和完整目标，重复原样请求只回原成功结果，不再增版本。相同 ID 改目标拒绝；过期请求不能覆盖新分配。回执与分配属于同一个玩家持久组件，按既有 owner_epoch 围栏存盘；scene 内存成功回包沿用现有培养写口径，不额外声称数据库已同步 fsync。

保存经玩家可写判断（冻结、交接、退出、缺少归属围栏拒绝）和战斗锁。完整目标只替换已知键，省略的已知方向归零；未知存档键原样保留、占预算但不生效。非法超额整池贡献为零，UI显示原始分配，允许按合法预算重新配置。

客户端 `GetPetEntries` / `PreviewPetEntries` / `SavePetEntries` 消费服务器目录与收益，缓存带宝宝/状态/配置版本。预览不写存档；超时保留原请求显式重试，断线不自动提交，迟到响应失效。仅确切匹配成功回执与目标的保存能清草稿；无关全量列表不能当保存成功，也不能回滚已确认的新条目版本。战斗只读，未提交草稿不进战斗快照。

旧服务器不回 `PetInfo.entries` 时仍保留原未同步/禁写页；五阶未同步显示“—”，不会套品质。旧表没有新条目配置时保留原宝宝参战，条目贡献为零。

## 复现

`tools/configure_pet_entries.mjs` 用官方 artifact-tool 生成两张新表并只补 Pet/PetRule 尾列，随后运行既有 `tools/data_table_exporter/run.py`。新增永久方向/阶级 ID 账本随导表保留。正式消息源位于 `proto/`，通过统一生成器生成所有语言契约，禁止手改产物。

## Java 版本能力边界

Java 版共享相同目录和五阶身份，但其现有战斗引擎尚未迁入本轮 69 原型的现代 Buff 执行器。本批只开放已接入实际结算的 501/502 物理/法术直伤；其余 19 项在响应中明确标注“当前 Java 战斗引擎尚未接入”、上限与预览收益为 0，服务端拒绝非零投入。已有保存值仍随存档保留，可由玩家主动移出。不能把 Java 的目录/存档通过当作 21 方向全部实战通过。C++ 版本的 21 个方向不受此能力限制。
