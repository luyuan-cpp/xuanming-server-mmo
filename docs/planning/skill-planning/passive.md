# 人物与宝宝被动技能

[返回技能策划总览](README.md) · [战斗公用规则](combat-rules.md) · [实施顺序](implementation.md)

本页列出 15 个有效被动原型，其中人物专用 8 项、人物和宝宝共用 2 项、宝宝专用 5 项。2026-11-17 按用户要求撤回P11过量治疗转盾，独立主动护盾见[人物A40](active-character.md)；2026-11-21 撤回仅限单体的 P10 闪影回锋。常驻属性、条件回复、受击反应都归被动。由符合条件的主动动作接出的技能见[追击与开场](pursuit-opening.md)。P09 和 P19 的复刻约束为已确认的设计。表中标为建议或待定的参数须在实现前确认。

人物被动、追击、开场共用两个战法槽是装配草案。宝宝被动单独管理，是否需要装配、怎样生效以及同时生效数量均待定。被动不占宝宝的攻击、障碍、辅助三个手动分类入口，触发也不会增加一次可手动选择的行动。人物和宝宝共用被动原型时，各自按对应的生效资格处理。

宝宝已确认以[统一条目点、资质与四维加点](pet-specialties.md)形成定位；输出、障碍、治疗、护盾共用预算，替代原自选条目，不另外赠送辅助／障碍池。人物专项培养仍走装备，宝宝不继承主人装备或新增宝宝装备。条目点总量、每项上限及是否复用属性型被动底层结构待定，点数不等于被动槽数。P04、P06、P15、P16等合法被动仍按各自规则存在，不能因新点池而删除，也不能将同一来源重复结算；某方向0点不删除该方向的合法被动收益。速度／气血／防御旧候选是否纳入点池另定。固有特色与被动的关系仍待评审，不自动额外送新被动；旧“技能书＋刷材料升级”不作为条目点培养方案。

## 物理反击与法术反击

**已确认。** P09 反戈一击响应物理攻击，P19 法术反击响应法术攻击。反击释放与来袭相同的技能，使用反击者自己的相应物理或法术属性，消耗 0 点法力。P09 原先的单体普攻反击描述已被这个规则替换。两招与 B07、B08 按实际扣血返还一部分伤害的反伤是独立机制。

**待确认。** 触发率、结算触发的精确阶段、是否复制附带状态与附效、是否保留原技能的群攻目标范围、是否要求反击者习得该技能、每回合的反击次数、受控时是否可以反击。来袭未命中、被护罩完全吸收和目标离阵时的处理也须与战斗时序对齐。

**实现建议。** 为复刻动作保留来袭技能身份，并标记它是反击生成的动作。同一链上生成的反击、追击、反伤等效果不再互相触发，避免两方反击无限往复。链内防递归与每回合触发次数分别配置。前者只约束派生动作，后者目前未确定。

## 技能子类型与配合

- **常驻属性**：P01、P02 决定角色输出取向，P03 和 P14 分别提供人物与宝宝的防护。人物与宝宝都可用 P04 或 P06 调整气血或速度，再用主动技能补齐队伍需要的效果。
- **治疗与蓝量**：悬壶济世强化适用治疗；护盾由A40独立施放，不从治疗过量产生。凝神节用和灵息回转提供续航，后者在每轮首次受到敌方直接伤害时给宝宝回蓝。
- **中毒与受击应对**：自己的毒每轮首次造成伤害时，借毒养元回自身气血。忠心护主抗劝退，卸力护身削弱同一次攻击的后续段。物法反击则复刻对应来袭技能。
