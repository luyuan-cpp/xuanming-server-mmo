# 宝宝主动技能

[返回技能策划总览](README.md) · [战斗公用规则](combat-rules.md) · [实施顺序](implementation.md)

本页列出12个当前有效的宝宝专属手动技能原型（含 2026-11-21 由人物侧转入宝宝专属的 A18 碎甲击）。**宝宝使用主动攻击／障碍／辅助三个分类入口，已学且允许该宝宝使用的技能均可选，每回合合计最多释放一招。** 分类入口不限制总共只能装2或3招。被动另计；被动、追击、开场的生效方式、是否需装配及数量尚未确认。人物和宝宝可以共用原型，但目标上限按施法者区分。旧编号留作合并对照，具体数值和未定结算细节须在实现前确认。

## 手动分类与回合选择（最新已定）

- 主动攻击、障碍、辅助是三个战斗分类入口，每类可包含多招已学技能。比如已学且符合资格的物攻、法攻、混乱、封法、治疗、护罩六招，均可从各自分类中选择，并非只装三招。例子不自动开放尚未确定的技能学习资格。
- 每回合从三个分类中的所有可用技能合计选择一招；不能每类各释放一次，也不能同轮先上护罩再攻击或先碎甲再自行接另一个手动爆发。需要分回合使用，或由人物、其他队友/宝宝接力。
- 选择普通攻击、防御等合法动作也占用正常行动，不能额外补用手动技能。被动、追击、开场按各自触发条件处理，不占三个手动分类入口，也不增加可自行选择的正常行动。
- 持有、学习资格、战斗候选列表与当前可施放条件分别校验；冷却、法力不足、封锁或无合法目标仍可阻止施放。已学可选不等于任何宝宝都能学所有技能。
- 宝宝被动数量、生效方式与是否需装配仍待定，之前两战法槽仅为旧建议，不据本次分类入口确认自动采用。

## 统一条目点与轻量培养（替代关系已定）

具体规则及效果候选见[宝宝条目点与轻量培养](pet-specialties.md)，制作入口见[宝宝条目点 UI 交接](pet-entries-ui.md)。**基础四维保留，人物用装备词条，宝宝用统一条目点分配输出／障碍／治疗／护盾强化，取代原自选条目**；不新增神识／慧心，不继承主人装备，不新增宝宝装备。点数预算与资质、四维共同形成定位，不另外赠送辅助／障碍点池，也不叠旧四专长的15%效果、10%耗蓝、8个百分点命中奖励。三分类、全部合法已学可选与每回合一招保持。

沿用不专门做任务、战外调整、战内锁定、不随机洗数值或刷材料升级的方向。建议获得宝宝即开放分配预算，具体总量和发放契约待定；同条件同投入按配置产生确定收益，不再要求不同投入都给同一个固定值。用户允许小额付费，具体收费项目与价格仍待定。

统一点池有限，输出、障碍、治疗、护盾相互取舍；总点数、单项上限、收益曲线、可分配方向数量及配置／存档待定，不以4条、1固有＋3自选或10点6＋4写死界面。速度／气血／防御等原候选是否纳入专项点池另评审，不能默认另赠预算。0点仅无该项条目点强化，不禁用合法已学技能；点数不等于被动槽数。学习资格、公式、耗蓝、冷却和被动关系仍按原确认状态处理。

- 速度主要决定行动先后，不额外提高治疗量或障碍成功率。封控仍读取对应条目，治疗/护盾靠各自公式及适用条目形成差异；现有公式如何承接需再核对。
- 共用的基础攻击、单体治疗与净化应有实际用途。通过耗蓝、冷却和放弃本轮其他行动的代价限制万能化，不把基础净化强行改为低概率，也不无条件附送治疗或护盾。
- 高速净化只能清已有状态；慢速净化可接在敌方控制之后，若受护者尚未轮到行动可能保住本轮出手机会，若已错过则不补行动。慢速治疗可能接在敌方伤害之后，但必须承担活到出手的风险。

| 首测定位举例 | 主要长处 | 应保留的取舍 |
|---|---|---|
| 高速封控 | 投入速度与某一种障碍条目，争取先手 | 生存、输出和治疗不同时突出；选择净化就放弃本轮封控 |
| 耐久治疗 | 投入生存与治疗条目，承压后补血或净化 | 先手能力有限，可能先被压制；封控成功率不能仅靠高生存获得 |
| 专注输出 | 投入物攻或法攻及对应伤害条目，形成击杀压力 | 临时治疗仍可用但恢复普通，救人同时放弃本轮输出 |

这些是属性与条目组合的例子，不直接规定某个物种的职业或技能禁学名单。学习范围、具体条目与自动效果数量另行确认。试打应记录同档成长下的有效伤害、治疗、控制行动数、净化时机和资源消耗，检查是否存在一只宝宝在各方面都明显占优。

## 宝宝目标规则（最新已定）

- **友方辅助：1 个友方单位。** 治疗、回生印、加防、加速、加伤、闪避、净化、护罩、反弹保护、连战印与开场保护均按单体；自身属性与资源转换仍只作用自己。
- **敌方辅助：1 个敌方单位。** 驱散、纯减益、削蓝、劝退按单体；劝退仍只能选敌方宝宝。含直接攻击的混合技能按攻击规则，不另选一组减益目标。
- **物理/法术攻击：最多 2 个不同敌方单位。** 包含宝宝横戈裂岳、紫霄雷阵、碎甲击和摄魂汲血。**蚀骨毒已单独确认按持续攻击，最多给2个敌方单位上毒。** 只有1个合法敌人时只作用1个，不重复攻击同一人凑数。
- **人物目标数不变。** 例如人物横戈/雷阵仍敌5，人物青莲/回生印仍友7；A18 碎甲击已取消人物资格，仅由宝宝施放（敌2）。原型复用不等于目标数相同，也不新增宝宝的技能学习资格。
- **特殊行动优先。** 混乱后的物理/法术攻击仍只打自己随机1名队友，正常耗蓝；不因宝宝攻击两目标而变为两名队友。反弹仍返还给该次攻击者，不自动寻找第二个敌人。

## 技能子类型与配合

- **攻击与铺垫**：横戈裂岳与紫霄雷阵负责两目标物法攻击，宝宝能用两目标碎甲击或蚀骨毒给人物创造联动条件。普攻才触发乘胜追击或裂甲追击；普通攻击的目标规则不因本次技能范围修改而自动扩大。灵术回响如何承接两目标法术见 T06 待定项。组合示例均以已学且有资格为前提，每回合从全部可用手动技能中择一。
- **保护与反制**：如意灵环、神龙护体的建议结算是每段对应类型的正直接伤害消耗一次，吸收量取该段伤害和剩余容量的较小值。次数或容量用尽就移除，溢出部分继续结算。毒、反伤与援护转伤默认单独结算。护罩类型、是否可驱散、同类护罩是否覆盖须显示清楚。乾坤反震、五色返照只返伤害，不复刻来袭招式，复刻机制见 [P09 和 P19](passive.md#物理反击与法术反击)。
- **续航与救场**：青莲润生给一名队友回血，移灵养元让宝宝花蓝换取暂时提高自身的血量上限和对应气血。单体法力盾使用受护目标自己的法力。舍身救主由宝宝牺牲自己，给一名其他存活友军治疗和净化。它的每战次数建议只适用于本招；A26每次给一名友方挂印，仍可重挂，复活也不会补回已经错过的行动。
- **劝退**：按劝退命中与抗劝退条目直接判定，本项目不设忠诚度养成。技能成功时目标离阵，区别于死亡。建议由主人花一个行动重新召出，退场后两个完整回合内同一只宝宝不可重新召出。返场参数待确认。
