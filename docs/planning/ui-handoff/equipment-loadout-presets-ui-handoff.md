> **美术边界声明**：**本文档不定义任何美术风格、画风、配色、材质、字体或装饰画法**；所有视觉外观完全以 `image` 仓库既有规范及仓库内已确认成品为准。本文档只列明要做什么 UI、功能与交互语义、像素尺寸、文件名、透明背景、文字留白规则、是否可拉伸与落盘目录。

## 1. 功能与技术红线（非美术风格要求）

1. **输出目录**：`designs/equip-loadout-ui-v1/`（所有路径均相对 `image` 仓库根目录，不修改旧目录已验收成品）。
2. **文件格式**：全部预览图（`previews/`）与运行时切片（`slices/`）必须为 **PNG-32 真透明背景（RGBA，窗框/图标边缘外 Alpha = 0，无棋盘格或场景底）**。
3. **文字与留白规则**：
   - `previews/` 用于排版确认，包含下方指定的业务样例文案；
   - `slices/` 全部为 Unity 运行时复用素材，**默认绝对不带任何烘焙文字或数字**，按钮/底板/槽位/标签内部留出干净排版区供程序动态叠字；
   - 仅当某枚角标明确标注「内置字样」时才绘制指定字样，其余一律无字。
4. **平台与交互红线**：
   - 严禁出现微信支付、支付宝、二维码或任何站外充值/跳转图标与文案；
   - 不依赖鼠标 Hover 展示关键信息，适配横屏异形屏安全区并避让右上角小游戏胶囊。
