## 1. 需要 Codex 制作的 3 组增量 UI 清单

> 注：V2 模块 D（报名期战队热身约战）与模块 C 的公开战报回放按钮全部复用 V1 已有界面，**无需 Codex 新增美术资源**。以下仅列真正需要新做的 3 组增量组件。

### 增量组 1：半决赛 / 总决赛 BO3 + 「五行灵脉阵眼」（对应 V2 模块 A）

#### 1.1 五行灵脉阵眼圆章（5 枚透明切图 PNG）
- **尺寸**：`128×128` PNG-32 透明底，严禁带文字/字母/数字（可缩小至 `36×36` / `56×56` 依然一眼辨认五行属性）。
- **文件名与语义**：
  1. `assets/leyline-metal.png`：金属性灵脉阵眼图标（金锐灵脉）
  2. `assets/leyline-wood.png`：木属性灵脉阵眼图标（木生灵脉）
  3. `assets/leyline-water.png`：水属性灵脉阵眼图标（水润灵脉）
  4. `assets/leyline-fire.png`：火属性灵脉阵眼图标（火炽灵脉）
  5. `assets/leyline-earth.png`：土属性灵脉阵眼图标（土厚灵脉）

#### 1.2 淘汰赛对阵树 BO3 局分胶囊（增量切图 + 状态说明）
- **用途**：叠挂在 V1 对阵树半决赛/总决赛节点卡右侧，清晰区分 BO1 与 BO3。
- **切图**：`assets/bo3-score-pill.png`（`112×44` PNG-32 透明底、无文字，支持横向 9-slice，内部留空给程序叠放 `BO3` 与 `2 : 1` 局分）。
- **状态需求**：支持区分 3 种状态——`0:0 未开战（含 3 枚预告灵脉小圆章）`、`1:1 局间换阵中（高亮态）`、`2:1 已完赛（胜方突出态）`。

#### 1.3 局间 60 秒「灵脉公示 + 换阵倒计时」居中轻弹层（结构规格）
- **画布尺寸**：弹窗本体 `820×520`，居中叠在 `1920×1080` 半透明遮罩上（复用 V1 `window_frame` 九宫底板）。
- **信息分区**：
  - 顶部横幅：`半决赛 BO3 · 第 2 局备战` + 大号比分牌 `太玄剑阁 1 : 0 青云仙宗` + 圆形倒计时 `00:48`；
  - 中部高亮卡「本局五行灵脉阵眼」：左侧 `84×84` 灵脉圆章 + 灵脉名（如「火炽灵脉」）+ 一句话效果说明（`全体五行属性伤害 +6%`）+ 右侧 3 局灵脉序列（第 1 局已完成 / 第 2 局当前高亮 / 第 3 局预告）；
  - 下部「本队 4 人快捷换阵条」：横向 4 张紧凑头像槽（3 首发标记 + 1 替补点一下直接互换），右下角主钮「确认出战阵容」（若对手已就绪则显示「对手已就绪，立即开战」；若超时提示「倒计时结束将自动沿用上局阵容」）。
