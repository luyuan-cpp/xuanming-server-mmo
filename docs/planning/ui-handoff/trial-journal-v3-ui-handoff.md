## 1. 本次新增的 3 处界面扩展（其余复用既有试炼志 V2 与大地图 V2 切图）

1. **野外三图底部 HUD 浮条扩展（场景 2 八景岛 / 场景 5 碧渊水宫 / 场景 3 月汐湾）**：
   - 在既有野外底部浮条右侧并列增加 1 枚「明雷首领」挑战按钮（显示尺寸 `190×50`，程序叠放「挑战明雷首领」或本图首领短名），点击发起本图明雷首领战（1–5 人）。
2. **「五行试炼志」主窗口新增「卷四 · 三境明雷」与「试炼誓约」勾选条**：
   - 左侧目录栏自动新增「卷四 · 三境明雷（3 格 · 9 印）」页签（复用既有 `rail_tab_idle / rail_tab_selected`）；
   - 选中可加誓约的 PVE 首领试炼格（卷一 / 卷二 / 卷四）时，展开详情区底部显示 4 枚可独立勾选的「试炼誓约」胶囊按钮（`160×44`），分别对应「禁控硬破」「单宝轻装」「无宠孤剑」「紧缩回合」，每枚左侧放 `24×24` 无字誓约小图标、右侧由程序叠放誓约名；
   - 已通关纪录行右侧提供「看录像」与「发帖约战」两个操作按钮（复用既有 `btn_secondary`）。
3. **聊天频道与试炼志内嵌「好友试炼约战帖」卡片**：
   - 玩家在世界 / 组队 / 好友私聊发送试炼约战帖后，聊天消息流中展示一张 `640×126` 嵌入式卡片（无字底板 `challenge_card_panel.png`），程序运行时在上方叠放：发帖人名、关卡名、已达成誓约徽标（0–4 枚）、最佳回合与脱敏配装摘要，以及右侧两个可点击按钮「看录像」「同誓约应战」（按钮高度 `≥44px`）。
