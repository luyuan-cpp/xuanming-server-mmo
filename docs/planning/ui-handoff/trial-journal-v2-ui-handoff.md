## 1. 功能与技术红线（非美术风格要求）

1. **格式规范**：全部切片必须为 PNG-32 透明底（背景及外缘 Alpha = 0，无实色底或棋盘格底）；**严禁在任何切片上带文字、字母或数字**，所有需要叠字的区域必须留空给 Unity 运行时动态渲染。
2. **布局与安全区**：
   - 基准画布 `1920×1080` 横屏，并同步核查 `1280×720` 与移动端窄横屏（`896×414`）排版；
   - 适配手机 `Screen.safeArea` 与小游戏右上角胶囊避让区（右上预留 `≥140px` 宽无交互区域，窄屏关闭按钮可移至左上）；
   - 触控优先，不依赖鼠标悬停提示，可点击控件高度 `≥44px`。
3. **动态画像槽位留空**：
   - 首领/护卫头像与 M901「星阵宗师」角色立绘均由客户端运行时从现有角色库与灵宠库动态加载，切片只需提供头像框与立绘底座，不得把具体怪物或角色画死在 UI 底板上。
4. **入口约束**：主城 HUD 不加催促红点；入口位于「首领试炼备战页」「主城闲时卡」「赛季印页签」与「战斗结算页行内提示条」。

## 2. 需制作的界面与功能区域

### 2.1 主窗口「五行试炼志」
- **顶栏**：标题牌位（程序叠放标题与副标题）、关闭按钮、一行状态区（平时显示赛季与规则版本号，异常/刷新/换代时切换为状态提示条）、同步状态胶囊（可点击刷新）。
- **左侧目录栏（5 项切换）**：总览 / 卷一·破阵试炼 / 卷二·灵障玄毒 / 卷三·季游奇谈（S1 独立存档） / 里程碑录；有可领里程碑的页签右上角可叠放数字角标。
- **中部主区**：
  1. 顶部 3 张数据指标卡：已点亮永久道印（含距 18 印宗师差值）、当前卷或本季进度、待领取里程碑与拓印/自用砂余额。
  2. 分节标题条（程序叠放当前分页标题）+ 右侧简短说明。
  3. 中间可滚动列表：
     - **关卡列表模式**（共 11 格：卷一 4 格、卷二 4 格、卷三 3 格）：每行含首领头像框（右下叠护卫小头像位）、关卡名、难度标签、2–3 枚战法印状态徽标（分类「通/守/巧/速」，区分已点亮与未点亮）、进度数值与挑战按钮；选中行向下展开逐条战法印触发条件、单人最佳回合与配装复盘（灵宠+法宝+赛季印）、好友合战纪录（队友名+人数）或未解锁提示。
     - **里程碑列表模式**（共 10 档：M101–M104、M201–M203、M901、301–302）：每行展示达成进度、奖励明细（仅自用重铸砂、自用法宝拓印、名片印戳、专属形象或评语标题）、领取按钮（未达标 / 收取 / 已领取）以及已解锁评语的「读评语」按钮。
  4. 底部「法宝凭券」八选一横条：展示当前凭券数与状态文案、8 件自用法宝选择格（选中态 + 已持有数量角标）与「兑换所选法宝」按钮。
- **右侧固定栏（M901 宗师里程碑置顶区）**：
  - 顶部标题与「M901」标识；
  - 中部立绘底座（留空给程序放入 `20_star_formation_master_girl` 立绘）；
  - 18 枚宗师道印 2×9 网格（区分已点亮与未点亮状态）；
  - 底部主操作按钮（未达标查看里程碑 / 18 印领取专属形象 / 已领取阅读宗师跋文）及衣柜快捷入口。
- **底部信息条**：左侧操作提示或错误提示，右侧快照修订号。

### 2.2 两个轻量弹窗
1. **法宝兑换二次确认弹窗**：展示所选法宝名称、仅自用不可交易/拆解说明、允许兑换同名第二件说明，以及「取消 / 确认兑换」按钮。
2. **留灯院评语阅读弹窗**：展示评语出处、标题、正文滚动区（《祝停云·破阵跋》《阿禾·三首记》《留灯院·试炼宗师跋》）与「收起」按钮。

### 2.3 战斗结算页嵌入式行内提示条
- 仅当本局属于试炼志对局（`TrialJournalEntryId != 0`）时嵌入战斗结算面板，不弹窗打断；
- 左侧一枚印记图标位，中间两行文本（本局试炼名与新亮印数、新点亮战法印名称或新纪录摘要），右侧一个「看试炼志」次要按钮。

## 4. 验收预览必须覆盖的 9 种状态

交付预览图（透明底 PNG，窗口外 Alpha = 0，演示数据统一标明「UI 演示数据」）需覆盖以下 9 态 + 结算条：
1. 首次加载骨架屏（无快照，不假显示 0 印）；
2. 刷新中（保留旧快照与列表可见 + 顶栏刷新提示）；
3. 真空档（0 印、困难未解锁、无纪录）；
4. 进行中（部分点亮、可展开战法印与配装复盘、有待领里程碑与可用法宝凭券）；
5. 18 印宗师达成（右侧 M901 18 印全亮，可领取「星阵宗师」）；
6. 卷三季游隔离（展示本季独立进度与独立归档提示）；
7. 规则换代（旧版纪录留档提示，已点亮战法印保留）；
8. 背包满报错（兑换失败提示，凭券与选中法宝保持不变）；
9. 断线恢复（保留上次快照，所有联网领取/兑换/跳转按钮置灰禁用）；
10. 独立「战斗结算页行内提示条」预览与移动端窄横屏（`896×414`）排版检查图。
