## 1. 功能与技术红线（非美术风格要求）

1. **增量边界**：不修改或覆盖旧目录既有成品；第一批落 `designs/economy-trade-ui-v1/`，第二批落 `designs/economy-trade-ui-v2/`（所有路径均相对 `image` 仓根目录，不写死盘符）。
2. **输出规范**：
   - 全部 `previews/` 与 `slices/` 必须为窗口外真实透明 PNG（RGBA，四角 Alpha = 0，窗外不画背景场景）；
   - `previews/` 用于排版定调，包含样例业务文案；
   - `slices/` 为 Unity 运行时切片与道具/状态图标，**绝对不烘焙任何动态价格、昵称、数字、星级或倒计时文字**，按钮/底板/标签中间留干净区域供程序叠字。
3. **双形态与交互约束**：
   - 避让移动端刘海与微信/抖音小游戏右上角胶囊区；
   - 核心风控提醒全部直接显性展示或点击展开，**绝不依赖鼠标 Hover**。
4. **平台合规红线**：
   - 商城与寄售界面**严禁出现微信支付、支付宝、二维码或任何站外跳转/打折充值图标与文案**，严守 iOS IAP 隔离。
