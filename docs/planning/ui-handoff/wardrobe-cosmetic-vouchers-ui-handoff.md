## 1. 通用交付技术规范（不含风格要求）

1. **格式**：透明底 PNG-32（轮廓外 `alpha = 0`，无白底、无背景框、无棋盘格、无外溢杂点）。
2. **无字原则**：两枚图标**严禁烘焙任何汉字、字母、数字或水印**；道具名称、数量、灵石价格与角标均由运行时动态叠加。
3. **尺寸、拉伸与留白**：
   - 画布统一 `512×512`（对齐既有 `item_appearance_card.png` 道具图标规格）；
   - 固定等比显示，不做九宫格拉伸；
   - 主体居中，四周预留约 8%～12% 透明安全留边；需确保缩小至 `48×48` 与 `64×64` 格内时剪影与主题仍一眼可辨，且两枚图标外形轮廓明显区分，避免在背包和百宝阁中混淆。
