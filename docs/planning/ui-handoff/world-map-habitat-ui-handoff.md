> 通用要求：请按项目既有的统一 UI 美术风格制作；所有切图均为 **PNG-32 格式、真实透明背景（Alpha 通道完整透明）**，不带纯色外框或背景杂边；切图内**严禁烘焙任何文字或数字**（标题、可捕灵宠列表、按钮文字均由程序运行时动态叠放）。

## 1. 界面功能与结构说明

本批素材服务于玩家身处野外地图（`八景岛` / `月汐湾` / `碧渊水宫`）时主界面底部中央常驻的**野外灵宠栖息地快捷遇敌条（`WildPetHabitatBar`）**：
- 逻辑参考分辨率：`2560×1080`（左上原点），兼容 `16:9` 居中安全区。
- 浮条位置与尺寸：`x=880, y=984, w=800, h=76`（底边距屏幕下缘留 16px，居中摆放，不遮挡左上角地图/分线、左侧快捷入口、左下角背包以及右侧帮战/任务侧栏）。
- 仅在玩家位于可捕宠野外图且未打开大地图、未处于战斗中时显示；回主城（`天墉城`）自动隐藏。
- 浮条内部从左到右三段布局：
  1. 左侧标识图标槽：`x=18, y=14, w=48, h=48`（标示野外灵宠栖息地入口）。
  2. 中部两行文字安全区：`x=78..582`（上行 `y=8, h=30` 显示栖息地标题与灵潮提示，如 `八景岛 · 灵宠栖息地 · 灵潮中`；下行 `y=39, h=28` 显示当地可捕灵宠或状态提示，如 `可捕灵宠：云鹤（10级）、竹风狸、霞角鹿`）。
  3. 右侧主行动按钮：`x=594, y=13, w=190, h=50`（程序叠放文字 `寻宠遇敌`，点击即发起当前野外图的单人寻宠战斗）。
