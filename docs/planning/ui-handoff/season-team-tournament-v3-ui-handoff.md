## 1. 功能与技术红线（非美术风格要求）

1. **增量边界**：不新增第 6 个主分页、不改天墉城底图、不改动 V1/V2 既有资源文件。
2. **输出规范**：
   - 全部 20 枚切片必须为真实透明底 PNG（边缘 Alpha = 0，无棋盘格底、无白边）；
   - 标明「无字底板/按钮/胶囊」的切片，中间必须留出干净区域供 Unity 运行时渲染动态文本；
   - 标明「内置文字」的 3 枚弹窗标题与 4 枚图章/牌匾，Unity 接入时**不再叠加文字**，切片本身需包含清晰可读的指定文案。
3. **安全区与交互**：
   - 适配 `1920×1080` 与 `2400×1080` 横屏，右上角预留 `140px` 宽小游戏胶囊避让区；
   - 不依赖鼠标 Hover 展示信息，移动端可点击区域高度 ≥ 44px。
4. **合规文案红线**：禁止出现「押注 / 赌 / 筹码 / 元宝购买」等字样（竞猜全程免费，热身零积分）。

## 3. 需要覆盖的 4 个交互界面/弹窗内容

1. **热身约战弹窗（模块 D）**：
   - 顶部标题（`d-warmup-title.png`）+ 状态胶囊（`warmup-badge.png` 显示「零积分演练」）+ 说明「不计入海选积分与场次」；
   - 可选目标战队编号输入框（留空为全服随机匹配）；
   - 演练五行灵脉 6 选 1（无脉 / 金锐 / 木生 / 水润 / 火炽 / 土厚）；
   - 本队成员首发勾选（选满 3 人）+ 底部「取消 / 发起零积分热身」按钮。
2. **淘汰赛对阵树竞猜态 + 《神机问道榜》弹窗（模块 E）**：
   - 对阵树未开战节点：A/B 队行右侧各挂「猜胜」按钮（`predict-pick.png`，显示已猜态与双方票数）；
   - 对阵树已决出节点：若玩家参与过预测，显示 `predict-hit.png`（中）或 `predict-miss.png`（惜）；
   - 《神机问道榜》弹窗（`predict-panel.png` + `e-predict-title.png`）：顶部个人汇总条（命中场次 / 神机分 / 当前排名 / 领奖门槛），下方左列「我的预测记录」、右列「全服神机问道榜 Top 50」，底部「刷新 / 关闭」。
3. **MVP 高光战报卡弹窗（模块 F）**：
   - 淘汰赛已决出节点挂可点击 `mvp-seal.png`；
   - 点击弹出高光卡（`mvp-card-bg.png`）：左侧真实角色头像位 + `mvp-seal.png`，右侧展示场次名、MVP 角色名与战队名、综合战功分、累计有效输出、累计治疗与护盾、累计成功硬控次数，以及「观看高光战报 / 关闭」按钮。
4. **战队徽标选择 + 季军争夺战节点（模块 G）**：
   - 建队弹窗附带 8 枚徽标单行选择；战队页队长可点「更换战旗」弹出 4×2 网格选择弹窗（`g-emblem-title.png`）；
   - 淘汰赛末轮并列展示「全服总决赛」与「季军争夺战」（节点顶部挂 `bronze-banner.png`）；
   - 冠军殿堂补充展示总决赛 MVP 与季军战队信息。
5. **BO3 赛前五行灵脉禁选弹窗（模块 H）**：
   - 未开赛的 BO3 淘汰赛节点提供「灵脉禁选」入口；
   - 弹窗横向排布 5 条五行灵脉（金锐/木生/水润/火炽/土厚），已被 A/B 队队长禁用的灵脉叠盖 `ban-seal.png`，下方实时展示剩余 3 条将依次生效的 G1/G2/G3 灵脉序列。
6. **《本季名局录》精选回放墙弹窗（模块 I）**：
   - 顶部标题（`i-highlights-title.png`）+ 底板（`highlights-panel.png`）；
   - 滚动列表展示最多 10 场自动策展名局（总决赛巅峰局 / 决胜三局激战 / 季军争夺战 / 高光问鼎局），每条含双方战队与徽标、比分、MVP 摘要、一键回放按钮（支持 BO3 分局 G1/G2/G3）。
7. **战队赛季荣耀铭牌展区（模块 J）**：
   - 「我的战队」与「冠军殿堂」展示本队已点亮的 6 枚荣耀铭牌（`honor-01..06`），未点亮灰态显示达成条件。
