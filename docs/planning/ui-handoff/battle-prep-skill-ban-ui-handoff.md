## 1. 通用交付技术规范（不含风格要求）

1. **格式**：全部为透明底 PNG-32（边缘 `alpha = 0`，无白底、无棋盘格、无外溢杂点）。
2. **无字原则**：全部 8 枚切片**严禁包含任何文字、字母或数字**；所有标题、数字（如 `0/3`、`25 秒`）、页签文案（控场/输出/辅助/灵宠）、技能名及「已禁」文字均由运行时动态叠加。
3. **拉伸与安全留白**：
   - 标明「九宫格拉伸」的底板/框体需四边边框厚度均匀、中心区域平缓；
   - 标明「横向三段拉伸」的页签底图需左右端帽清晰对称、中段可水平拉伸；
   - 标明「等比图标/槽框」的切片主体居中，预留约 8%～12% 安全留边，槽框中间需保持可透出或清晰承载下层技能图标的区域。
4. **图仓输出目录（与游戏引擎/客户端完全无关）**：`D:\work\image\designs\battle-prep-skill-ban\assets\`
