## 1. 界面功能与结构说明

本批素材服务于两处界面：
1. **既有「活动中心」窗口内的 3 张新活动入口卡**（155×155 显示槽位）：
   - `900001`「青云游历手记 · 第一期」：主活动入口卡，点击打开游历手记主窗。
   - `900002`「留灯风物 · 免费试穿」：免费试穿体验入口卡，点击跳转易容外观面板。
   - `900003`「灵石百宝阁 · 轻便利」：按需便利商城入口卡，点击跳转灵石百宝阁面板。
2. **独立「青云游历手记」主弹窗**（逻辑参考分辨率 `2560×1080`，主窗居中 `1860×960`）：
   - 顶栏：居中/偏左标题牌、灵石与绑定灵石双余额文字区、刷新按钮、关闭按钮。
   - 顶部横幅区（`1748×148`）：上方程序叠放规则承诺文字，左下方放游历点进度条（`1128×28`），右侧放「一键领取」与「解锁典藏」双操作按钮。
   - 中部双轨滚动区（`1748×584`）：10 档（每 30 游历点 1 档，上限 300）横向行卡片，每行三列——左列档位与点数、中列免费游历轨奖励与领取按钮、右列典藏进阶轨奖励与领取/解锁提示按钮。
   - 底部纪念外显栏：展示已解锁的头像框与称谓切换按钮（零战力纯外显）。
