## 一、需求分析

### 1.1 核心诉求与负责人定案口径（2026-11-26）

1. **创收补位诉求**：在核心官方内购（[灵石百宝阁](spirit-shop-and-starter-packs-v1.md) + 仙途轻享卡）之外，为免费/零氪玩家提供低门槛、零逼氪的激励视频回血入口，同时评估并规避“玩家捐赠独立开发者”的高红线雷区。
2. **「零拒审」是强制一票否决要求**：任何新增变现功能都不得引入首审拒审风险，严守微信小游戏、抖音小游戏、iOS App Store、Google Play 及国内版号/隐私政策红线。
3. **最优长期架构定案（「不怕改动，按最好的改」）**：
   - 核实 `proto/common/base/currency_type.proto` 当前仅有 `CURRENCY_TYPE_GOLD = 0`（银两）、`CURRENCY_TYPE_DIAMOND = 1`（灵石）、`CURRENCY_TYPE_BIND_DIAMOND = 2`（绑定灵石）；
   - 趁项目尚未上线（零历史兼容与混跑包袱），**正式新增 `CURRENCY_TYPE_BIND_GOLD = 3`（绑定银两）**，建立“流通银两 vs 绑定银两”物理双轨隔离，全服纯系统个人消耗优先抵扣绑定银两、一切玩家间交易/流通/可交易（T）资产绝对禁止触碰绑定银两；
   - 激励视频「观影小礼」直接发放**少量绑定银两**，既 100% 物理隔绝小号刷广告冲击集市银两物价，也为今后全服新手福利、运营补偿、活动奖励提供一劳永逸的安全发奖底座。

### 1.2 「捐赠独立开发者」与「小广告」的红线裁决

| 变现想法 | 合规红线风险 | 本方案裁决 |
|---|---|---|
| 游戏内放微信/支付宝收款码、跳转爱发电 / Patreon / Ko-fi 捐赠 | **极高（直接拒审/下架/封主体）**：违反 App Store 3.1.1、Google Play 计费政策、微信/抖音小游戏禁切支付与防诈骗规范 | **永久禁止进入任何游戏客户端包体** |
| 游戏内无版号开通「纯打赏/捐赠」付费按钮 | **极高（无版号违规内购）**：国内平台只认游戏内资金交易接口，不因“无数值”豁免版号；非慈善机构不得以“捐赠”绕开平台抽成 | **国内无版号阶段彻底关闭一切游戏内真钱入口** |
| 游戏内强弹插屏 / 开屏 / 底部 Banner 广告 | **高（易误触违规 + 严重劝退 MMO 玩家）**：全面屏/刘海遮挡极易触发平台“诱导误触”阶梯冻结 | **永久不做** |
| **游戏内静默可选「激励视频 · 观影小礼（发绑定银两）」** | **低（全平台官方主推，配首审关闭锁与文案/UI 门禁）**：微信/抖音小游戏无版号即可合法开流量主 | **作为 V1 唯一游戏内广告形态** |
| 游戏外社区赞助（TapTap 论坛 / B 站 / 官网放爱发电） | **零（完全不进游戏客户端，不触发提审条款）** | **允许，严禁在游戏内出现任何外链或引导词** |
| 拿版号后 / 海外版在「灵石百宝阁」增加「请作者喝杯茶」纪念消耗品 | **低（100% 复用既有合规支付、未成年人限额与退款扣回）** | **留作二期可选配表项（零代码改造）** |

## 二、思想分析（为什么「双银两隔离 + 三道零拒审锁」是最优解）

1. **「绑定银两 = 经济防洪堤」思想**：
   - 传统 MMO（如《问道》《梦幻西游》）能把物价稳住十年的根基之一，就是把**「可交易银两（流通货币）」**与**「储备金 / 绑定银两（仅限个人养成消耗）」**物理分开；
   - 只要广告、活动补偿、新手福利发的是 `CURRENCY_TYPE_BIND_GOLD`，无论多少免费零氪玩家领取，这些银两**永远流不进集市、摆摊、当面交易、聚宝斋与代工费**，工作室开一万个小号也无法把绑定银两变现砸穿物价。
2. **「反洗白铁律」思想（比加币种本身更重要）**：
   - 绑定银两绝对不能经任何间接链路变成可交易银两或可交易道具，尤其是三条最隐蔽的暗道必须从策划层面彻底封死：
     1. **代工大师费暗道**：玩家找铸器/制书大师代工时，代工费会作为可交易 `kCurrencyGold` 发给大师 → **代工费严禁扣绑银**；
     2. **可交易（T）装备增值暗道**：用绑银去强化/打造/解封一件可交易装备，要么会造成 T 装绑定染毒（违背 `project-vision.md` 红线 6），要么等于把绑银洗进成品卖价 → **T 装与解封严禁扣绑银**；
     3. **NPC 商店转手暗道**：若神秘商人售卖可交易物品，用绑银买走再挂集市等于直接洗白 → **神秘商人保持严格按表定单币种扣款，不静默混扣绑银**。
3. **「首审绝对纯净 + 三道零拒审锁」思想**：
   - 微信小游戏本身必须先上线达标（UV ≥ 500 等）才能开通流量主，因此**首审包默认关开关（`enabled = 0`），100% 无广告过首审**；
   - iOS / Android App 首审包通过编译期宏 `MMORPG_ENABLE_APP_AD_SDK` 默认关闭，**连第三方广告 SDK 和 `NSUserTrackingUsageDescription` 都不打进首审包**，实现 App 首审 0 广告追踪风险（未来甚至可长期保持“仅小游戏开原生流量主、App 端零广告 SDK”）；
   - 开启后采用「服务端开关 + 正式位号 + 客户端 `load()` 真就绪」三重门禁，未就绪彻底隐藏入口，绝不给审核员留死按钮；文案严格保持中性价值交换，严禁“支持作者 / 帮点广告”等触发 AdMob IVT 与微信/抖音违规的诱导语。

## 三、设计分析

### 3.1 绑定银两（`CURRENCY_TYPE_BIND_GOLD = 3`）消费边界与防洗白总表

| 分类 | 业务场景 | 扣款规则 | 防洗白与体验说明 |
|---|---|---|---|
| **A 类：允许优先扣绑银**<br>（纯个人绑定养成消耗，不足再补扣流通银两） | 人物属性洗点 / 方案开启 | 优先 `BIND_GOLD`，不足补 `GOLD` | 纯角色绑定能力，零可交易产出 |
| | 人物技能修习与升级 | 优先 `BIND_GOLD`，不足补 `GOLD` | 零氪最刚需的银两出口，体验极佳 |
| | 普通绑定宠物购买（`transfer_policy == 0`）、宠物洗点、培育、升阶与词条培养 | 优先 `BIND_GOLD`，不足补 `GOLD` | 已核实商店宠不可转让，100% 自用 |
| | **已绑定（B）装备**的强化、词条重铸、品相打磨、原地升档 | 优先 `BIND_GOLD`，不足补 `GOLD` | 目标装备本就绑定，零染毒风险、零洗白空间 |
| | **非代工且产物为绑定**的个人自用打造 / 技能制书系统手续费 | 优先 `BIND_GOLD`，不足补 `GOLD` | 系统销毁回收，不经他人钱包、不产可交易物 |
| **B 类：严禁扣绑银**<br>（严格只扣流通银两 `CURRENCY_TYPE_GOLD = 0`） | **可交易（T）装备**强化、打造、词条打磨与**解封（`UNSEAL_TO_TRADABLE`）** | **仅 `GOLD`** | 严守“防 T 装绑定染毒”红线且防绑银洗入 T 装价值 |
| | **一切代工费（`proxyFeeGold`）**（铸器代工 / 技能制书代工） | **仅 `GOLD`** | 代工费会作为可交易银两发给大师，严防小号刷绑银洗给大号 |
| | **神秘商人**（默认 `currency_type = 0` 商品） | **仅按表定单币种** | 防止绑银买出可交易道具转手卖银两；未来要开绑银专柜可单独配 `currency_type = 3` 且强制 `bound = true` |
| | **集市、离线摆摊、游戏内当面交易、聚宝斋、帮会捐献、帮战悬赏、玩家间邮件寄钱** | **仅 `GOLD`（业务白名单显式拒收 `BIND_GOLD`）** | 彻底切断绑银进入任何玩家间资金流转的可能 |
| | **灵石百宝阁、仙途轻享卡、游历手记典藏轨、赛季追赶** | **仅按表定单币种（灵石等）** | 守住官方 7:3 真实充值营收锚，互不混扣 |

> **界面展示规则**：参照现有灵石百宝阁同时展示「灵石 / 绑定灵石」的做法，在背包资产栏及所有支持绑银抵扣的养成界面（人物加点、技能、宠物、绑定装备强化）清晰并列展示「银两」与「绑定银两」，并在按钮说明中写明「优先消耗绑定银两」，杜绝玩家误解。

### 3.2 激励视频「观影小礼」入口、交互与数值设计

- **入口位置（克制零打扰）**：放在游戏内**次级界面固定角落**（例如「灵石百宝阁」或「设置 / 福利」静态栏位），绝不在主界面 HUD 漂浮红点，绝不在战败/结算强弹广告。
- **交互闭环**：
  1. 玩家主动点击带高对比度「视频/广告」角标的「观影小礼」按钮；
  2. 弹出极简确认小窗（文案严格中立：`观看一段短视频广告，完成后领取今日绑定银两小礼（剩余 X/2 次）`），**同时显眼、等权展示「观看广告领取」与「关闭」双按钮**（禁延迟、禁缩小、禁移位误触）；
  3. 玩家点击观看 → 服务端签发短效一次性 `ad_session_id` → 拉起宿主原生激励视频；
  4. 仅当宿主 `onClose(res)` 明确返回 `res.isEnded === true` 时领奖；中途退出温和提示“未完整观看，未领取奖励”，无惩罚、无挽留弹窗。
- **数值配表基线（全进 `RewardedAdSlot.xlsx` 支持热更）**：

| 参数项 | 默认值 | 设计依据 |
|---|---|---|
| 奖励币种 | **`CURRENCY_TYPE_BIND_GOLD = 3`（绑定银两）** | 100% 物理不可交易，零物价冲击 |
| 单次奖励数量 | **300 绑定银两**（每日上限 **2 次** = **600 绑定银两/天**） | 折合半场普通 PVE（`600` 银两/场）、够 15 次词条重铸或技能修习，零氪友好又不贬值战斗乐趣 |
| 解锁门槛 | 角色等级 **≥ 10 级** | 对齐首日半小时试炼里程碑，过滤 1 级白号 |
| 切日规则与冷却 | UTC+8 `05:00` 切日（抗时钟回拨）；单次最短观看 **≥ 15 秒**、两次间隔 **≥ 60 秒** | 与游戏内既有切日基准一致，满足抖音频控且防脚本秒刷 |
| 绝不发放项 | **0 流通银两、0 灵石、0 可交易材料、0 独占战力、0 头像框** | 严格对齐 [project-vision.md](project-vision.md) 与 [灵石百宝阁 V1](spirit-shop-and-starter-packs-v1.md) |

### 3.3 全平台提审合规矩阵（零拒审硬标准）

| 平台 | 首审策略 | 正式开启激励视频必检项 | 绝对禁区 |
|---|---|---|---|
| **微信小游戏** | **默认 `enabled = 0`，100% 无广告过首审**；上线达标（UV ≥ 500 等）开流量主后二版开启 | 官方 `wx.createRewardedVideoAd`；清晰「广告/视频」图标；`onClose` 严格判 `res.isEnded === true`；支持/预留官方 SSV 回调 | 禁写“点广告支持作者”；禁不看卡死流程；禁 Banner/插屏误触；个人主体不可开 IAP |
| **抖音小游戏** | **默认 `enabled = 0` 过首审**；具备软著、开流量主拿正式 `adUnitId` 后二版开启 | 官方 `tt.createRewardedVideoAd`；弹窗同时显眼给出「观看」与「关闭」；高对比度图标；请求间隔 ≥ 1 秒；严格判 `isEnded === true` | 禁隐藏/延迟关闭键；禁按钮移位误触；禁虚假现金红包话术；无版号严禁开 IAP |
| **iOS App Store** | **默认关闭编译宏 `MMORPG_ENABLE_APP_AD_SDK`**，首审包 0 广告 SDK、0 ATT plist key | 若未来开启：配齐 `NSUserTrackingUsageDescription` **且代码真实调起 `ATTrackingManager.requestTrackingAuthorization`**；隐私问卷如实申报；拒追仍可正常玩与看非个性化广告 | 禁只写 plist 不弹 ATT；禁利诱点允许追踪；禁广告未就绪留死按钮；禁任何收款码/外链捐赠（3.1.1） |
| **Android / Google Play** | 同上，首审包默认不打包广告 SDK | 若未来开启 AdMob：中立价值交换文案；补齐广告 ID 声明与隐私政策；国内安卓获用户隐私同意后再初始化 SDK | **AdMob 零容忍任何“支持开发者/维持免费”类文案（IVT 封号）**；禁未同意隐私前初始化 SDK |

### 3.4 二期可选：「请作者喝杯茶」纯心意支持（零新增红线）

仅在**海外版（App Store / Google Play）或国内取得游戏版号**后启用，**绝不单独写第二套支付/捐赠系统**：
- 在 [灵石百宝阁 V1](spirit-shop-and-starter-packs-v1.md) `SpiritShopGoods.xlsx` 中追加 1 行明码标价的常规消耗品（如 `60 灵石 · 仙茶小叙 / 支持开发`），回赠 1 个无战力加成的纯纪念称号（不碰被砍掉的头像框），100% 复用既有合规支付与未成年人限额闸；
- 国内无版号时期只在**游戏外**（TapTap 论坛、B 站、官网、玩家群）放爱发电页面，游戏包体内零外链、零二维码。

### 3.5 上位红线准入四问自检（[project-vision.md](project-vision.md)）

1. **普通零氪玩家**：不看广告照样 100% 满配毕业，无红点、无打卡；愿意看时每日拿 600 绑定银两正好缓解前期修习技能、洗点、绑定装重铸的银两压力。**通过**。
2. **个人开发者收入**：无版号阶段即可在小游戏合法开官方流量主回血服务器运维成本；不发真灵石、不蚕食灵石百宝阁与仙途轻享卡 70%+ 主干收入。**通过**。
3. **物价与长期循环**：奖励为物理不可交易的 `CURRENCY_TYPE_BIND_GOLD = 3`，且代工费、T 装强化/打造/解封、神秘商人、集市/摆摊/当面交易全部物理隔离绑银，**实现 0 流通通胀、0 工作室搬砖套利口子**。**通过**。
4. **防骗与资产安全**：游戏内零外链/收款码；`DeductGoldPreferBind` 原子校验防半扣；广告发奖全程走服务端短效落盘会话 + `ClientRequestLedgerComp` 幂等账本 + `GainBlockService` 产出封禁校验。**通过**。

## 四、漏洞分析（策划、防洗白与合规视角）

| 编号 | 潜在漏洞 / 拒审风险 | 危害 | 本方案防护手段 |
|---|---|---|---|
| **P-1** | **代工费洗白绑银**：小号看广告攒绑银，找自己大号代工铸器/制书，系统把代工费发成大号的可交易银两 | 工作室无限将绑银洗白为可交易银两砸盘 | 规则写死：所有 `proxyFeeGold` **必须严格只扣流通银两 `kCurrencyGold`**，绝不走绑银抵扣 |
| **P-2** | **可交易（T）装备用绑银强化/打磨导致染毒或洗白** | 误毁玩家高价值 T 装，或把绑银转入 T 装卖价 | `player_equip` / `player_equipment_v1` 仅对已绑定（B）装备允许优先扣绑银；T 装与解封严格只扣 `kCurrencyGold` |

## 五、步骤分析（分阶段落地方案）

1. **阶段 1（双银两底层基础设施先行）**：趁未上线在三仓（C++/Go、Java 独立服、Unity 客户端）一次性打通 `CURRENCY_TYPE_BIND_GOLD = 3` 枚举、`DeductGoldPreferBind` 原子原语、A/B 类消费点分流、Go/Java 白名单隔离与客户端统一币种展示（清理 Java 硬编码币种上限魔数与客户端 8 处重复文案 switch）。
2. **阶段 2（激励视频服务端与小游戏桥接，默认关闭态）**：落盘 `RewardedAdSlot` 配表（默认 `enabled = 0, currency_type = 3`）、`RewardedAdLedger` 持久化、3 个 Scene RPC、`MinigameAd.jslib` 与 `RewardedAdBuildGuard` 零拒审门禁。
3. **阶段 3（首审无广告上架 → 小游戏二版开流量主）**：首审包保持 `enabled = 0` 与零 App 广告 SDK 一次稳过首审；微信/抖音开通流量主并配好正式 `adUnitId` 后，补 1 枚清晰「广告/视频」角标（届时另出 `ui-handoff` 交 Codex 作图），走完零拒审门禁单后热更开启。
4. **阶段 4（可选 · App 端广告或版号/海外后灵石心意包）**：仅在明确需要 App 端广告时单开 `MMORPG_ENABLE_APP_AD_SDK` 补齐 ATT 与隐私清单；版号/海外上线后如需“请作者喝杯茶”，直接在灵石百宝阁配 1 行消耗品。
