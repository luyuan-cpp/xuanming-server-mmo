## 一、需求分析

### 1.1 为什么推翻 V1 的“2V2 匹配会武”

对照最新[核心循环 V1](core-gameplay-loop.md)（2026-11-23）与[世界地图 V2](world-map-play-v2.md)（2026-11-23），旧稿 [guild-play-v1.md](guild-play-v1.md) 存在四个结构性硬伤：

1. **与论剑 2V2 严重撞车且收益倒挂**：战斗完全同质（同一套 3×3 公共预设），但帮会会武零论剑进度、零帮贡、零资金、零专属外观，理性玩家没有理由进帮会会武。
2. **一次性“永久首胜题名”对 95% 帮众是负激励**：开帮半小时名额写死，后来者永远无法留名，首胜者打完一局即失去复玩动力。
3. **强制匹配池导致鬼城空排死循环**：要求同区两帮各凑 2 名真人同时排队、不补人、不跨区、全天分散，非高峰极易出现“干等 120 秒没人 → 取消散伙”。
4. **帮会氛围缺失**：零观战、非参战帮友不能看回放、零帮会成长收益、且与 11/23 取消每日上限改用 660 永久首套池的新口径脱节。

### 1.2 V2 核心目标与三合一方案取舍

负责人确认的核心产品目标：**全天随时能开干、爱打架可以一直打爽、不需要匹配池、野外路上看到其他帮派的人点一下就能开打、界面直打与地图现场两套入口都要有、帮会奖励要够丰富打起来有赚头**；同时坚持[项目设定](project-vision.md)（好玩优先、不逼肝、小小氪金、不卖付费专属竞技数值）。

本方案放弃“拆成三个独立模式”的割裂方案（会撕裂活跃人口、界面与双服工期翻三倍），将三种经典帮战诉求融为**一套无匹配池的「全天灵脉帮战」**：

| 融合维度 | 解决的玩家诉求 | 融合落点（单一规则与底层） |
|---|---|---|
| **无匹配池全天直打 + 野外路遇互砍** | 0 秒开战、全天一直打、江湖恩怨感 | 彻底砍掉匹配队列；三张常驻野外图路上任意异帮未免战玩家互点直打，帮会面板也可 0 秒直点目标连战 |
| **三座灵脉据点争夺（C）** | 抢地盘目标感、帮会排面与周期分红 | 八仙岛、碧渊水宫、月汐湾各设 1 座灵脉；**每帮最多同时占 1 座**杜绝第一大帮包圆 |
| **守旗阵踢馆 + 摇人驰援（A）** | 半夜 3 点 / 低人口时依然不断档有架打 | 敌帮在线无活人迎战时，0 秒开打敌帮登记的「守旗阵」快照并向占领帮在线成员推轻量警报，活人一键驰援反杀 |
| **连胜悬赏 + 实时观战 + 4 层丰厚奖励（B）** | 打起来有赚头、爱打架有排面、帮众能围观 | 接通 660 首套池、每场帮贡/银两、连胜终结悬赏、每周全帮战功箱、灵脉分红、升级版帮会商店与永久专属形象；全对局开放既有分级观战 |
| **江湖追杀令与仇敌追踪** | 被击败/被踢馆后有仇必报、跨图追踪堵人、反杀博弈 | 结算页与「帮会仇敌录」可对异帮发布固定档位追杀令；查出目标所在野外图与分线一键追踪堵截，追杀成功销单领赏，被追杀者反杀也可赚反杀赏金甚至撕毁追杀令 |

### 1.3 玩家典型场景与满足方式

| 玩家想做什么 | V2 怎么玩 |
|---|---|
| 刚上线手痒，想 0 秒开干连打十把 | 点帮会「帮会争锋」直接挑亮绿灯的异帮活人或守旗阵开战，打完结算页点「继续下一场」，血蓝自动满，通宵不断档 |
| 在八仙岛/碧渊水宫/月汐湾路上碰到其他帮派的人 | 不管对方是不是灵脉占领帮，只要双方已入帮且未开免战，点对方直接「发起帮战」0 秒开打；路人点头顶「激战中」直接围观 |
| 刚在野外被打败或自家灵脉被踢馆，想摇帮友满地图追杀报仇 | 在结算页或「帮会仇敌录」一键发布追杀令；全帮帮友看到对方在「碧渊水宫 · 1 线」出没，一键传送进图堵人执行追杀，赢了领赏金、全帮播报雪耻；对面反杀成功也能拿反杀赏金 |

| 纯休闲上线抓宠、打明雷首领，不想被打扰 | 天墉城主城永远安全区；野外随时可一键切免费「和平/免战」模式，完全免疫强制点战；即便参与帮战被打败，也零掉装、零扣银两，且达防挂机门槛照拿 10 份材料与保底帮贡 |
| 攒帮贡换硬货和拉风外观 | 帮战稳定产帮贡、银两、帮会资金；帮会商店新增**重铸砂**（调词条）、**悟道残页**（拓印正式自由技能库）、**灵兽口粮**及**仅帮会可换的永久角色形象/称号** |

## 二、设计分析

### 2.1 无匹配池三大作战方式（双入口共一套底层）

彻底删除 V1 的双人邀请队列、120 秒排队提示与跨帮撮合池。所有帮战统一走**「点目标 → 原子抢占 `battle:lock` → 立即建房开战」**的单一路线：

#### 1. 野外路上任意异帮直点开战（地图现场入口 · 阶段 2 挂接）
- **生效地图**：与[世界地图 V2](world-map-play-v2.md) 对齐，仅在开服常驻的 **3 张野外图**生效：`2 八仙岛`、`5 碧渊水宫`、`3 月汐湾`（优先 `Fill-First` 1 线聚人）。`1 天墉城`为主城永久安全区，严禁强制帮战点杀。
- **任意异帮互打**：不限哪两个帮会、不限双方是否占领灵脉，只要发起方与目标方满足：
  1. 均已加入帮会且**分属不同帮会**（同归属区）；
  2. 双方均处于同图同线、服务端权威坐标距离 `<= interact_range`（灵脉战区内可适当放宽）；
  3. 双方均**未开启「和平/免战」**，且目标不在**战后 10 秒保护期**与**新手保护期**（可配，默认角色等级 `< 15` 级或可按配表 `GuildWarRule.min_level` 控制）；
  4. 双方当前均未持有 `battle:lock`（不在战斗/其他占用中）；
  - 满足即可由发起方（单人或队长）点击目标直接 0 秒开战！
- **组队人数与防恶意霸凌规则**：
  - 发起方组队发起帮战（无论野外路上还是帮会界面）必须**全员同帮、均达等级门槛、均未开免战、均无战斗占用**（野外路上还须全员同图同线）。
  - 被点方如果是小队（2–5 人），若队内存在**未入帮、低于等级门槛、已开和平免战、或与发起方同帮**的成员，则拒绝本次点战并返回明确提示，绝不将无帮/和平玩家或本帮队友强拉进敌对阵营；符合条件时整队同侧入战（1v1～5v5）。
  - **防 5 打 1 恶意堵门**（建议默认，可由 `GuildWarRule` 调参）：野外普通路上主动点人时，要求 `发起方人数 <= 目标方人数 + 1`（如单人可点 1 人或 2 人队，2 人队可点 1–3 人队，5 人满编队只能点 4–5 人队）；而在**灵脉战旗周围的「灵脉战区」内**不设人数差上限，鼓励帮派小队集结攻防！
  - 被点方在战败后获得 **10 秒不可被强制点战保护**（主动点别人或点旗会立即解除保护），且**战后血蓝自动恢复、零掉装、零扣经验与银两**，极大降低被路人点开的挫败感。
- **免费「和平/免战」模式开关**：
  - 已入帮玩家在非战斗状态可随时一键切换「战意模式（默认，野外可互点开战）」与「和平/免战模式（野外不可点人、不可被点、不可进入灵脉战区抢旗）」。
  - **防打完秒切逃跑**：从「战意」切回「和平/免战」需脱离战斗满 **60 秒**（或回主城天墉城立刻生效）；从「和平」切入「战意」0 秒生效。

#### 2. 三座灵脉据点全天攻防（每帮限占 1 座）
- **三座灵脉**：固定对应 `2 八仙岛`、`5 碧渊水宫`、`3 月汐湾`，作为常驻大舞台（每区独立归属）：
  - **防第一大帮包圆**：硬约束**同一帮会同一时刻至多占领 1 座灵脉**。已占领 1 座灵脉的帮会，成员依然可以随时去攻打另外 2 座灵脉刷个人战功、帮贡、悬赏和 660 材料，也可帮本帮守旗，但把其他灵脉旗势打空后**不会兼并第 2 座**（该灵脉立即回归无主守卫状态待未占领帮会争夺，击溃方获得额外破旗帮贡与帮会资金，并在结算页清晰提示“本帮已占领 XX 灵脉，本次击溃敌旗获得额外破旗赏金”）。
- **旗势条与易主规则**：
  - 每座灵脉拥有 **`0 ~ 1000` 旗势值**（配表可调）。开服初始无主，由原生「灵脉守卫」镇守（按 `DungeonTable` 配置），首个将其旗势打满或击溃守卫达标的未占领帮会占领该灵脉，初始旗势重置为 `600` 并获得 **15 分钟整备护盾**（护盾内仍可无限打真人刷奖励与悬赏，但旗势暂不扣减，防止刚易主 3 分钟就被连环秒偷）。
  - **旗势推进与恢复**（参数全进 `GuildWarRule`）：
    - 攻方真人击败占领帮在线守军：扣占领帮 **100 旗势**；
    - 占领帮在线守军击败攻方真人：恢复本帮 **60 旗势**（上限 `1000`）；
    - 攻方击溃占领帮「守旗阵」（无活人迎战时的踢馆战）：扣占领帮 **35 旗势**；同时按 60 秒节流向占领帮在线成员推送一条轻量通知「本帮【碧渊水宫】灵脉正被【青云阁】踢馆，剩余旗势 62%！」，支持点通知一键迎战或传回现场；
    - 当旗势降至 `0` 时，由给予最后一击的合格未占领帮会接管灵脉（若最后一击方已占其他灵脉，则灵脉回归无主守卫状态并给击溃方发放额外破旗帮贡/资金）。
- **守旗阵登记（AI 托管快照）**：
  - 占领帮的任意成员（上限 5 个守旗槽，帮主/长老可调整槽位优先序或由成员自助上阵/更新，单人刷新冷却 60 秒）可一键将自己**当前真实养成状态**冻结存为一份 `GuildWarGarrisonSnapshot`（复用 `PrepareBattle` 同一套快照构建逻辑生成 `BattlePlayerSnapshot` + 宝宝快照 + 本人已审通过的 `BattleTeamScript` 或官方默认剧本，不冻结角色也不预留背包道具）。
  - **跨服务抓拍纪律**：由客户端向 `scene` 取权威快照或由 `guild` 在开启 MySQL 事务**之前**先向 `scene` 取得已签名/校验快照并限制最大字节数，再在独立事务写入 `guild_war_garrison`，严禁在 SQL 事务内调 RPC。
  - **守旗阵零损耗、零占用**：成员登记守旗阵后可照常下线、打怪或去干架，守旗阵被踢馆时由 `battle` 节点按 AI 托管独立开房，绝不拉起或打断守旗本人的正常游玩。

#### 3. 帮会界面 0 秒直打（界面入口 · 阶段 1 即完整可用）
- 打开「帮会 → 帮会争锋」主界面，玩家不跑图即可直接看到：
  - 3 座灵脉的实时占领帮、旗势进度条、激战中对局（可一键 `WatchBattle` 观战）、当前挂牌的**连胜悬赏猛将**；
  - **当前可直打目标列表**（同归属区、异帮）：
    1. **在线迎战活人 / 小队**（仅限主动开启「挂牌迎战」或此刻位于灵脉战区内战意态的异帮玩家，亮绿灯标识，点一下 0 秒原子抢锁开打真人；**普通野外路上跑图玩家只能被同图同线身边的敌帮现场点战，绝不被远程面板凭空瞬拉**）；
    2. **敌帮守旗阵 / 无主灵脉守卫**（永远在线、永不枯竭，点一下 0 秒开打）；
  - 界面提供**「一键快速开战」**（优先直连此刻有空的在线异帮活人，无活人则 0 秒切入敌帮守旗阵，绝不进入排队等待）、**「直接开战（不切图）」**与**「前往现场（一键传至目标野外图 1 线灵脉旗旁）」**。
  - 结算页提供**「继续开战」**按钮，直接开启下一场，实现爱打架玩家通宵连战的爽快闭环。

#### 4. 江湖追杀令与帮会仇敌追踪（有仇必报、双向博弈）
- **发起入口与仇敌录**：
  - 本帮成员在帮战（野外路遇、灵脉战或踢馆）被异帮玩家击败后，对方自动记入本帮近 24 小时的「**帮会仇敌录**」；受害者本人或本帮帮主/长老可在结算页或仇敌录中对其发布**「追杀令」**（仅限同区、异帮、`>= 15` 级的目标，禁止对无帮、同帮或好友发单）。
  - **固定小额赏金档位（进 `GuildWarRule` 配表，严禁自定义天价防洗钱）**：
    - **普通追杀令**：发布者出资 **5,000 银两**（扣 10% 系统手续费销毁，4,500 银两入托管赏金池）；
    - **重金追杀令**：发布者出资 **15,000 银两**（扣 10% 手续费，13,500 银两入托管赏金池）；
    - **帮会公费追杀令**（帮主/长老专用，每日每帮限 2 张）：消耗 **2,000 帮会资金**，由系统配给固定帮贡与银两赏金。
  - 赏金预扣严格复用既有 `guild_asset_op`（`AssetDebit` 确认 `APPLIED` 后正式挂单生效；24 小时到期未结单则经 `GUILD_CREDIT` 原路退回剩余托管本金，手续费不退）。
- **追踪定位与进图预警**：
  - 追杀令挂在**本帮追杀榜**（可选勾「全区江湖榜」让全服异帮猎手都能接单，刺激感翻倍）。
  - 帮友或猎手点**「追踪行踪」**（15 秒冷却节流），`go/guild` 复用既有 `PlayerLocatorRedisClient` 查出目标当前状态与所在野外图/分线（如「目标正在【碧渊水宫 · 1 线】出没」；绝不泄露实时精确坐标流或账号信息）。若目标正在天墉城安全区或离线，如实提示「目标正藏身安全区 / 暂未露面」。
  - 目标在野外三图时，追杀者点**「一键追踪前往」**传送到目标所在野外图同线的安全入口（不瞬移贴脸秒偷），同时向目标推送一条江湖预警：**「【沧澜盟】的追兵已踏入【碧渊水宫】，请小心迎战或暂避！」**。
- **执行追杀、反杀博弈与防网暴底线**：
  - 野外找到头顶挂「追杀目标」徽标的对方后点**「执行追杀」**（若目标正在帮会面板「挂牌迎战」，也可从追杀榜直接点击开战），走同一条无匹配池 `StartGuildWarBattle` 链路；**执行追杀时同样遵守天墉城安全区、和平免战与战后 10 秒保护**（目标刚主动打赢帮战或踢馆后的 60 秒脱战冷却内无法秒切和平躲追杀；若其一直处于和平免战，追杀令在 24 小时内保持待机，待其切回战意出山即可堵截）。
  - **追杀者胜**：立即领走托管赏金 + 额外追杀帮贡 + 帮会频道雪耻播报，该张追杀令即刻**完成销单**。
  - **被追杀者反杀**：成功击退追杀者可拿一笔**反杀帮贡 + 反杀赏金**并全帮播报；**同一张追杀令下累计成功反杀 2 名不同追杀者，直接撕毁追杀令并没收 50% 托管赏金归自己**（其余退回发布者），让被追杀方同样有极强的博弈和炫耀爽感！
  - **防网暴与防倒金铁律**：同一目标同一时刻全区最多只挂 **1 张活跃追杀令**；被成功追杀销单后享 **30 分钟免再被挂追杀保护**；每名角色每日最多领 **5 次**追杀/反杀银两赏金（超次仍可免费追杀雪耻但不领赏金）；**被追杀失败零掉装、零扣经验、零扣自己背包银两**。

### 2.2 战斗规则：本人真实养成、决胜煞气与实时观战

- **本人真实养成**：对齐最新 [core-gameplay-loop.md](core-gameplay-loop.md) 与 [battle-skill-and-pet-cultivation-expansion.md](battle-skill-and-pet-cultivation-expansion.md)，帮战默认使用玩家真实人物装备（8 部位 + 36 词条 + 2 法宝）、已学正式自由技能库（含策略/率土式扩展技能与 `1 开场 + 3 被动 + 1 追击` 装配槽）、四维加点与出战宝宝条目点，让 30 天养成与小额提速拥有全天最直接的展示舞台。
- **零战损、无消耗鼓励放开打**：帮战内不预留/不消耗真实背包药物，战后人物与宝宝自动回满血蓝，不回写战内伤亡、不掉装备、不扣经验与银两（结算沿 `scene` 战后状态隔离分支处理，仅正常结算奖励账本）。
- **回合上限与「决胜煞气」防膀胱局**：
  - 复用竞技对局时长边界（`720 秒` / `120` 逻辑回合，打满存活判平，修正通用引擎回合上限判 B 胜分支）。
  - 从**第 12 回合起**触发战场环境规则「**决胜煞气**」：每回合全员造成伤害 `+15%`、治疗与护盾效果 `-15%`（封顶可配，如伤害 `+150%`、治疗护盾 `-75%`），确保绝大多数单局在 **4–8 分钟**内痛快分出胜负。
- **PVP 禁主动逃跑与断线重连**：帮战延续现有 PVP 禁逃跑规则，关闭界面不认输，断线走托管并支持 `RequestBattleTicket` + `GetBattleState` 恢复原局。
- **全对局公开实时观战与战报**：
  - 帮战冻结 `spectate_visibility = SPECTATE_VISIBILITY_PUBLIC`，所有帮友与野外路人均可经既有分级观战（[battle-spectate-tiered-fanout.md](../design/battle-spectate-tiered-fanout.md)，L0 直连 / L1 中继 / L2 广播）实时围观。
  - 真人帮战冻结 `record_replay = true`（复用既有 `battle-report-replay.md`）；**阶段 1** 先沿用参战者本人回放列表 + 帮内近 30 场大事记摘要，**阶段 2** 参照试炼碑白名单思路补充每帮近 10 场精选帮战回放的帮内成员只读权限（防全量录像膨胀）。

## 三、思想分析

1. **为什么砍掉匹配池后，体验和工程同时变好？**  
   匹配池只适合“强依赖段位分差 + 固定等员”的排位竞技（这部分已经由论剑承担）。帮战的核心爽感是**“随时有架打、打完立刻接下一场、江湖恩怨即点即战”**。去掉匹配池后，既消灭了中小服最大的死穴（120 秒空排劝退），也顺手砍掉了整个服务端最脆弱的跨帮队列锁与取消/成局竞态状态机。
2. **为什么让“地图现场直打”与“帮会界面直打”并存，却只做一套底层？**  
   MMO 玩家分两类时刻：碎片时间在手机上只想 3 秒开干、一口气打 5 场刷帮贡；晚间有空时喜欢去野外图看人群、堵敌帮、围观大佬打架。两者调用同一个无匹配池开战 RPC、共享同一批活人/守旗阵与同一条灵脉旗势，既满足了全场景体验，又避免了逻辑分叉。
3. **为什么坚持“败方零惩罚 + 免费和平免战 + 奖励全走帮会体系”？**  
   “路上点任意异帮就能开打”之所以在老 MMO 里容易吓跑休闲玩家，本质是因为输了会掉装备、掉经验、被守尸。本设计反其道而行之：**输了不掉任何东西、自动满血、给 10 秒保护、甚至打满有效对抗还给 10 份核心材料和保底帮贡**，再配主城安全区和免费和平开关——把“野外遭遇战”从负面惩罚变成了“反正不亏、干他一架甚至摇帮友干回去”的正反馈循环。
4. **为什么奖励这么丰富却不会打崩经济？**  
   核心装备 660 池自带永久天花板；可交易配额锁在账号终身 60 份；帮会商店里的重铸砂、悟道残页、专属外观全部**绑定仅自用 + 周/永久限购**；同对手 30 分钟递减封死双开互刷。所有高价值产出最终都服务于**自己配词条、收技能、换拉风外观、帮会升 10 级**，既让爱打架的玩家觉得超级肥，又不制造工作室印钞漏洞。

## 四、漏洞分析

| 风险场景 | 具体漏洞与攻击面 | 权威硬防线 |
|---|---|---|
