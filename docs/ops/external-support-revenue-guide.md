# 《五行奇谈》游戏外独立开发者支持收入配置与零拒审运营手册

> 日期：2026-11-26  
> 适用范围：仅用于**游戏客户端之外**的社区主页、开源仓库、自媒体简介与独立静态官网。  
> 红线依据：[AGENTS.md](../../AGENTS.md#9-禁止事项与权限边界) · [项目设定红线 7](../planning/project-vision.md) · [客户端双形态合规规范 §4.1](../../../mmorpg-client/Docs/rules/minigame-and-app-platforms.md)

## 一、核心原则：为什么必须「游戏外物理隔离」

1. **零拒审 / 零下架底线**：App Store（3.1.1）、Google Play 计费政策、微信小游戏、抖音小游戏均将「游戏内放收款码 / 导流站外捐赠 / 绕过官方支付兑换游戏内权益」视为高危一票否决违规项。
2. **完全合规的外部支持收入模式**：
   - 把创作者赞助入口放在**游戏客户端之外**（独立静态支持页 + 爱发电 / Ko-fi / GitHub Sponsors + B 站 / TapTap / 公众号简介）；
   - 明确声明**纯自愿支持开发日志与开源技术维护，不兑换任何游戏内货币、道具、装备、礼包码或账号特权**；
   - 如此既能让喜欢你的玩家从第一天起就可以合法“请你喝杯茶”分担服务器和开发成本，又做到与任何应用商店/小游戏提审 **100% 物理零耦合、零拒审风险**。

## 二、已落地文件清单与 5 分钟上线步骤

仓库已为你准备好开箱即用的游戏外静态支持页与 GitHub Sponsor 配置：

- 独立静态支持页：[deploy/external-support-site/index.html](../../deploy/external-support-site/index.html)
- 渠道配置文件：[deploy/external-support-site/support-config.js](../../deploy/external-support-site/support-config.js)
- GitHub 顶部 Sponsor 按钮模板：[.github/FUNDING.yml](../../.github/FUNDING.yml)

### 步骤 1：开通正规创作者赞助平台（个人开发者零主体门槛）
- **国内首选（爱发电 Afdian）**：
  1. 访问 `https://afdian.com` 注册创作者账号，填写作品介绍（《五行奇谈》独立游戏开发日志）；
  2. 设置 2–3 个轻量心意档位（建议 ¥6 一杯清茶 / ¥18 服务器续命 / ¥30 长期同行），**方案描述里只写「开发日志公开鸣谢 / 抢先看研发周报」，绝不写送游戏内道具/银两/灵石**；
  3. 复制你的主页链接（`https://afdian.com/a/<你的ID>`）。
- **海外可选（Ko-fi / GitHub Sponsors）**：
  - `Ko-fi`（`https://ko-fi.com`）：0% 平台基础抽成，绑定 PayPal/Stripe 即可接收海外小额赞助；
  - `GitHub Sponsors`：适合技术向/开源仓库支持者。

### 步骤 2：填入真实链接
1. 打开 [support-config.js](../../deploy/external-support-site/support-config.js)，把 `channels` 中你已开通平台的 `url` 填上（未开通的保持 `""`，页面会自动隐藏，绝不留死链），顺手填好 `communityLinks`（TapTap / B 站 / GitHub）；
2. 如需开启 GitHub 仓库顶部「Sponsor」按钮，编辑 [.github/FUNDING.yml](../../.github/FUNDING.yml) 取消注释并填入账号。

### 步骤 3：1 分钟免费部署静态支持页（无需后端、无需数据库）
将 `deploy/external-support-site/` 目录直接托管到任一免费静态托管即可（页面零外部 CDN 依赖，国内/海外均秒开）：
- **Cloudflare Pages**：新建项目 → 直接上传 `deploy/external-support-site/` 文件夹或关联仓库指定根目录；
- **GitHub Pages**：推送到单独的静态站仓库或开启 Pages；
- **国内服务器 / 宝塔 / 阿里云 OSS**：直接把 `index.html` 与 `support-config.js` 放到任意已备案域名的静态路径（如 `https://你的域名/support/`）。

## 三、可直接复制的合规社区文案模板（仅限游戏外使用）

> 以下文案**只能发在游戏之外**（B 站 / TapTap / 公众号 / 微博 / GitHub / 玩家交流群公告），**严禁复制进 Unity 客户端、游戏内公告、游戏内邮件或游戏内聊天自动回复**。

### 模板 A：B 站开发日志视频简介 / 置顶评论
```text

如果这些开发日志或开源技术分享对你有帮助，欢迎一键三连支持；
有余力想请作者喝杯茶、帮测试服续个命的朋友，也可以移步爱发电主页（纯自愿心意支持，不兑换任何游戏内道具/特权）：
👉 https://你的外部支持页或爱发电链接
```

感谢大家一路反馈和建议！目前全游戏核心养成均可零氪毕业。

## 四、绝对不可触碰的 5 条「防下架 / 防拒审」铁律

| # | 绝对禁止的做法 | 会触发的平台处罚 |
|---|---|---|
| 1 | 把外部支持页 URL、爱发电链接、个人微信/支付宝收款码放进 Unity 客户端（哪怕藏在“关于我们”或客服页） | App Store 3.1.1 拒审/封开发者账号；微信/抖音小游戏下架 |
| 2 | 在游戏内公告、游戏内系统邮件、NPC 对话或世界聊天里引导玩家去爱发电/私下转账 | 认定为「切支付 / 站外导流消费」，直接下架 |
| 3 | 给在爱发电/Ko-fi 赞助的玩家**发放游戏内兑换码、绑定银两、灵石、称号、装备或任何账号特权** | 认定为「绕过苹果/谷歌/微信官方支付抽成」，严重封号下架 |
| 4 | 在任何地方写“帮点一下游戏内广告支持作者 / 多点广告帮我回血” | 微信流量主阶梯冻结扣款；Google AdMob IVT 永久封号 |
| 5 | 长期使用个人微信/支付宝收款码大规模收款 | 易触发风控限额及合规纠纷；统一走爱发电 / Ko-fi 等正规持牌结算平台 |

> **客户端自动化守卫**：`mmorpg-client` 的 `RewardedAdModelAndComplianceTests.cs` 已内置全客户端脚本字符串红线扫描，一旦有人误把 `爱发电` / `afdian` / `patreon` / `ko-fi` / `收款码` / `支持作者` 写入 `Assets/Scripts/`，测试立即挂红拦截。
