## 0. 强制美术与合规红线（与 V1 完全一致）

1. **视觉体系**：延续《五行奇谈》道家 Q 版水墨青玉风（宣纸底 `#FAF4E6` / 玉青 `#2E6E5E` / 深翠 `#183C34` / 鎏金 `#B9893C` / 朱砂 `#B84A39`），圆润温雅、高对比清晰，不走赛博霓虹或暗黑哥特风。
2. **现役获批造型硬约束**：所有原型中出现的角色演示图，**必须只使用当前仓库获批现役角色造型（姜子牙、吕洞宾、何仙姑、雷震子）并明确标注“演示”**，严禁使用旧版废弃角色图！Unity 接入时仍按玩家真实外观动态绑定。
3. **透明底与边缘干净**：所有导出的切图 PNG 必须真正透明底（无白边/灰底/残影），尺寸精确、可 9-slice 或等比缩放。
4. **双端安全区与小游戏胶囊避让**：
   - 横屏主画布 `1920×1080`；
   - 右上角必须为微信/抖音小游戏胶囊预留至少 `140px` 宽 × `72px` 高的不可交互避让区；
   - 所有移动端触控按钮高度 `≥ 44px`，禁止依赖鼠标 Hover 才能看到信息。
5. **交付目录与 Git 推送**：
   - 输出目录：`D:\work\image\designs\season-team-tournament-v2\`（含可点击 `index.html` 原型、透明切图 `assets/`、渲染预览 `previews/` 与 `README.md` 资产清单）；

## 1. 需要 Codex 制作的 3 组增量 UI 清单

> 注：V2 模块 D（报名期战队热身约战）与模块 C 的公开战报回放按钮全部复用 V1 已有界面，**无需 Codex 新增美术资源**。以下仅列真正需要新做的 3 组增量组件。

### 增量组 1：半决赛 / 总决赛 BO3 + 「五行灵脉阵眼」（对应 V2 模块 A）

#### 1.1 五行灵脉阵眼圆章（5 枚透明切图 PNG）
- **尺寸**：`128×128` 透明 PNG（内嵌圆形玉质描金徽章，可缩小至 `36×36` / `56×56` 依然一眼辨认五行）。
- **文件名与意象**：
  1. `assets/leyline-metal.png`（金锐灵脉）：鎏金飞剑/乾金印纹，主色 `#D9A441`
  2. `assets/leyline-wood.png`（木生灵脉）：青翠灵叶/仙藤印纹，主色 `#3D8B68`
  3. `assets/leyline-water.png`（水润灵脉）：玄青水波/太极泉纹，主色 `#2F7FA3`
  4. `assets/leyline-fire.png`（火炽灵脉）：朱砂丹火/离火印纹，主色 `#D15338`
  5. `assets/leyline-earth.png`（土厚灵脉）：琥珀山岳/坤土八卦纹，主色 `#A37846`

#### 1.2 淘汰赛对阵树 BO3 局分胶囊（增量切图 + 原型状态）
- **用途**：叠挂在 V1 对阵树半决赛/总决赛节点卡右侧，清晰区分 BO1 与 BO3。
- **切图**：`assets/bo3-score-pill.png`（`112×44` 透明 PNG，可横向 9-slice，深翠金边小牌，内放 `BO3` 标签 + `2 : 1` 居中局分）。
- **原型状态**：展示 3 种状态——`0:0 未开战（含 3 枚预告灵脉小圆章）`、`1:1 局间换阵中（亮金脉冲描边）`、`2:1 已完赛（胜方加粗鎏金）`。

#### 1.3 局间 60 秒「灵脉公示 + 换阵倒计时」居中轻弹层（原型页 + 必要边框）
- **画布尺寸**：弹窗本体 `820×520`，居中叠在 `1920×1080` 半透明青墨遮罩上（复用 V1 `window_frame` 九宫底板）。
- **信息分区**：
  - 顶部横幅：`半决赛 BO3 · 第 2 局备战` + 大号比分牌 `太玄剑阁 1 : 0 青云仙宗` + 圆形鎏金倒计时 `00:48`；
  - 中部高亮卡「本局五行灵脉阵眼」：左侧 `84×84` 灵脉圆章 + 灵脉名（如「火炽灵脉」）+ 一句话效果说明（`全体五行属性伤害 +6%`）+ 右侧 3 局灵脉序列（第 1 局灰勾 / 第 2 局高亮 / 第 3 局预告）；
  - 下部「本队 4 人快捷换阵条」：横向 4 张紧凑头像槽（3 首发勾绿标 + 1 替补点一下直接互换），右下角主钮「确认出战阵容」（若对手已就绪则显示「对手已就绪，立即开战」；若超时提示「倒计时结束将自动沿用上局阵容」）。
