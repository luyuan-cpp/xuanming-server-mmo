## 1. 需求分析

随着《五行奇谈》落地**官方 7:3 双轨商业化、游戏内当面交易防骗收紧、卖家店铺信用（过户换人清空 + 异地陌生新机直接清 0 + 四重防刷分）、装备纯可交易（T）防“绑定染毒”隔离与集市近 7 日中位参考价**，当前 `image` 仓 `designs/` 中已有的 `jubaozhai-ui`（7 张静态寄售列表）与 `equipment-ui-20261117`（10 张装备/打造/强化/法宝透明页）尚缺少 **5 组关键防骗、信用与官方直售界面/弹窗**。

核心需求目标：
1. **零重绘浪费**：最大限度复用 `jubaozhai-ui`、`equipment-ui-20261117`、`qdao_ui_redesign_v5/components` 与 `official-passport-ui-v1` 的既有玉绿金边面板、按钮、九宫格和图标，只补齐缺失的 5 组业务页面/弹窗及配套无字徽标切片。
2. **风格 100% 统一**：严格承接 `designs/mail-ui-v1/01-mail-event.png` 与 `designs/team-ui-v2/team-ui-v2.png` 的**道家 Q 版高清手绘风格**（墨玉绿 `#244C3E`、深松绿 `#28412B`、象牙暖米纸 `#FFF3D3`、淡金 `#E5CC80`、玉青 `#419B76`、朱砂红克制警示点缀），**严禁光污染**。
3. **预览真透明 + 切片无烘焙字**：全部新建预览图窗框外采用真实透明 Alpha（RGBA PNG，窗口外不画场景）；运行时无字切片不烘焙任何动态价格、昵称、数字、星级或倒计时。
4. **双形态（小游戏 + App）与合规一次过审**：不依赖鼠标悬停（Hover）展示关键风控提醒；避让手机刘海与微信/抖音右上角胶囊；官方商城页绝不绘制微信/支付宝外链扫码图标，严守 iOS IAP 3.1.1 隔离。

### 2.3 逐组页面内容、防骗信息层级与交互约束

#### 组 1：游戏内当面交易防骗主窗 & 条款变更强确认态（`01`、`02`）
- **核心布局**：复用 `1932×814` 玉绿金边主框，顶部标题牌「当面交易」。下方左右对称双列「**我付出**」（左，暖米纸微绿边）与「**我得到**」（右，暖米纸暖金边），中间以玉纹箭头分隔。
- **反欺诈必显信息（缺一不可）**：
  1. 对方身份栏：头像、角色昵称、**服务端权威公开编号**（如 `编号 108492`）、系统好友状态与真实好友时长标（如 `已结交 12 天` / `陌生道友`，加注小字「好友关系不代表官方担保」）。
  2. 模式风控提示条（页面顶部米白窄条）：
     - 默认方案 A 态提示：`当面交易仅支持低价耗材与单日小额银两互助（今日剩余额度 7,500 / 10,000 银两）；贵重装备请走官方集市或指定买家定向单`；
     - 方案 B 态在出现偏离参考价时展示冷静保护锁提示：`低于近7日中位价超50%，成交后将触发 48 小时禁转/禁拆冷静保护锁`。
  3. 明文完整数字：**严禁“万 / 亿 / K”缩写**，示例写成 `100,000 银两`、`10,000 银两`，千分位逗号清晰可读。
  4. 物品格完整标注：装备/道具图标 + 强化等级（如 `+5`）+ 唯一实例尾号（如 `实例 #A8F2`）+ 可交易角标。
- **条款变更强确认态（`02`）**：
  - 当任意一方在锁定后修改了任何条款，清空双方锁定并弹出/高亮朱砂暖金对比横幅，**逐项明文展示前后差异**：
    - `对方银两变更：100,000 银两 → 10,000 银两`
    - `对方物品变更：青云灵剑 +5 (实例 #A8F2) → 青云灵剑 +0 (实例 #B109)`
  - 底部「锁定条款」与「最终确认」两步按钮清晰区分状态（未锁/已锁/需重新核对确认），**绝不允许单键连点完成**。

#### 组 2：卖家店铺信用档案卡、强警示态与交易后评价弹窗（`03`、`04`）
- **店铺信用档案卡（`03` 左侧）**：
  - 复用 `detail-card-nine.png` 视觉语言，像日常电商/店铺主页一样一眼看懂：
    - 顶部：卖家头像、角色名与公开编号、**风控档位徽标**（信赖老店 / 正常卖家 / 新店保护 / 受限警示）、**大号星级与分数**（如 `4.8 ★ · 94 分`）；
    - 中部四宫格数据：`官方托管成交 38 笔`、`好评率 97.4%`、`好评 37 / 中评 1 / 差评 0`、`核实违约 0 次`、`当前持有者起算日 2026-10-12`；
    - 底部小字规则条：`仅认官方托管真实成交；过户换人强制清空重算，异地换陌生设备直接清 0`。
- **交易后评价弹窗（`03` 右侧）**：
  - 仅在官方托管订单完成后 7 天内可打开：展示订单摘要（商品名、实付金额、订单尾号）、三选一大按钮「好评 / 中评 / 差评」（带清晰道家 Q 版表情印章，不靠 hover 区分）、短评输入框（受 `content_guard` 审核提示）与防刷分说明小字（`同账号/同网络/同设备及极小额不计分，7日内同买家限计1次`）。
- **两种高危强制警示态（`04`，左右分列对比，标注“运行时每次仅显示对应一种”）**：
  - **状态 A · 官方过户换人重算**：暖琥珀金警示条，醒目展示 `持有者已变更（2026-11-24），历史信用已清空重算`，档案归零为 `3.0 ★ · 60 分 · 新店/换人保护期`，历史成交 0 笔。
  - **状态 B · 异地陌生新设备清 0（防私下卖号/借号/盗号）**：克制朱砂红警示条（不刺眼、不泛光），醒目展示 `检测到异地陌生新设备登录，历史正面信用已直接清 0`，显示 `1.0 ★ · 0 分 · 受限档`，同时如实保留原有差评与核实违约计数（若为 1 次则红标显眼提示），加注温和提示 `正常坐高铁/切5G换IP不影响信用；换新机建议先在常用Wi-Fi登录`。

#### 组 3：银两集市近 7 日 p50 行情 & 官方“指定买家”定向托管单（`05`）
- **整体承接 `jubaozhai-ui` 玉绿框（1932×814）**，新增两个核心子视图拼合/切页示意：
  - **左/上：标准品近 7 日真实成交 p50 行情卡**：
    - 展示商品图标、名称、**近 7 日中位成交价（p50）**（如 `1,020 银两 / 份`）、**有效样本量**（如 `近7日真实成交 186 笔，已剔除对敲`）、买一/卖一盘口 3 档简要深度；
    - 角落附一个小型内嵌态示意「样本不足态」：`近7日有效样本不足 10 笔，暂隐藏参考行情以防恶意控价`。
  - **右/下：官方“指定买家”定向单上架/购买卡**：
    - 卖家勾选「定向交易给指定道友」，输入对方**权威角色公开编号**，系统实时回显对方头像与昵称确认防填错；
    - 清晰显示**分层公示标签**：小额标准品显示青绿徽标 `快速公示（0–2 小时）`，唯一装备/宠物/角色显示暖金徽标 `高价防盗公示（48 小时）`；
    - 右侧内嵌卖家店铺信用缩略条（星级、分数、是否换人/异地清零标），让买家在官方担保内 1 秒看清卖家可信度。

#### 组 4：装备防“绑定染毒”隔离态 + 长按强确认弹窗 + 「解封剥离符」弹窗（`06`）
- **直接承接 `equipment-ui-20261117/transparent-previews/05-enhancement-transparent.png`（1931×814）的布局语言**，演示三大防误触增量状态：
  1. **底部默认隔离栏**：装备右上角清晰标明 `可交易（T）` 玉绿角标；消耗栏默认勾选锁死 `仅消耗可交易材料`（展示 `可交易强化石 3 / 7（不足）`），主按钮「强化」呈暖灰禁用态并明确给出短提示，**绝不悄悄拿绑定石头凑数**。
  2. **手动降级混用 B 料强确认弹窗（防连点手滑）**：当玩家主动打开独立开关「允许混用绑定材料」时弹出居中警示卡——标题「装备将永久变为仅自用」，明文列出 `青云灵剑 +5（可交易）→ 混用 4 颗绑定强化石后将失去交易/寄售资格`，底部取消按钮常规样式，确认按钮采用**「长按 2 秒确认绑定」进度槽按钮**（或输入框确认「确认绑定」），按钮位置刻意与原「强化」按钮错开，彻底防肌肉记忆连点。
  3. **官方小额「解封剥离符」弹窗（右侧并列示意）**：展示 512×512 道家玉符图标，明确对比左右两侧：`当前：青云灵剑 +5（仅自用 · 原胚可交易）` → `剥离后：青云灵剑 +0（恢复可交易原胚，绑定养成清空不返还T料）`，消耗 `解封剥离符 ×1`（仅 `origin_tradeable=true` 装备可用）。

#### 组 5：官方 7:3 小额直售商城 & 升级版「仙途轻享卡」页（`07`）
- **定位**：个人开发者冷启动一期最核心的 70%+ 盈利引擎，画风温和、体面、绝不做廉价弹脸红点逼氪。
- **顶部四页签**：`仙途轻享卡` | `永久衣柜` | `匠心配套（问道式功能符）` | `限量追赶包`。
- **主体内容**：
  - **左侧主推卡「仙途轻享卡」（¥18 / 30 天）**：柔和仙山卷轴配道童小立绘（无光污染），清晰列出 3 条直白权益：① 离线挂机护航与快捷整理；② **解锁可交易材料/银两持续产出资格**（标明小字：`零氪玩家同样 100% 免费自养至 +10 毕业，月卡只解锁市场流通产出与轻便利`）；③ 每日静默灵石返利（不打卡、累计 7 天不作废）。
  - **右侧 2×2 官方直售商品卡**：
    - `解封剥离符`（¥6 / 60 灵石）
    - `流派副套继承符`（¥12 / 120 灵石）
    - `青岚仙袂·永久外观`（¥28 / 280 灵石，无战力属性标签）
    - `首套追赶礼匣（绑定·限购1次）`（¥18 / 180 灵石，标明「仅加快首套进度，绝不突破战力上限」）

## 3. 思想分析

1. **防骗 UI 的核心不是“把免责条款写满一屏”，而是“打断肌肉记忆 + 放大异常信号”**：
   - 当面交易里，90% 的受骗发生在连点确认或看错位数；因此明文千分位禁缩写、条款变动朱砂红高亮对比、长按 2 秒错位按钮这三处视觉设计，比任何弹窗免责声明都有效。
2. **信用系统必须“一眼像店铺，异常藏不住”**：
   - 正常老店用温和的玉绿+暖金建立信任感；一旦发生过户换人或异地陌生新机清 0，立即通过高辨识度的琥珀金/朱砂红横幅打破习惯性信任，让买家无需点进三级菜单就能立刻警觉。
3. **官方 7:3 直售页要传递“体面微氪、零氪尊严”的氛围**：
   - 延续邮件图与组队图的温润道家手绘质感，绝不用红蓝闪光首充弹窗和夸张折扣大字，让玩家看到的是清爽、透明、买得舒服的长期陪伴式小额付费。

## 4. 漏洞分析与视觉验收防线

| 潜在视觉/工程坑 | 后果 | 强制验收防线 |
|---|---|---|
| **只用文字描述风格而不附参考图** | 生成出写实仙侠风、塑料 3D 光泽或暗黑风，与现有邮件/组队/聚宝斋割裂 | 每次调用必须实际附上 `designs/mail-ui-v1/01-mail-event.png` 与 `designs/team-ui-v2/team-ui-v2.png`（及对应同功能参考图），并在 `.generation.json` 记录参考图路径与哈希 |
| **窗口外带场景背景或半透明脏边** | 违反 2026-11-22 透明背景硬规，Unity 接入出现黑边或切图返工 | 全部 `previews/*.png` 与 `slices/*.png` 必须为 RGBA，窗外四角 Alpha=0，分别在浅底和深底检查锯齿与残留噪点 |
| **把动态价格、星级或金额烘焙进运行时切片** | Unity 动态换字时重影错位 | 严格区分 `previews/`（带样例文案的视觉定调图）与 `slices/`（绝对无字控件与无字徽标） |
| **霓虹发光、过曝高光（光污染）** | 警示条刺眼、文字发虚、破坏道家温润纸绢感 | 全套严守 `image` 仓 `AGENTS.md` 禁止光污染规则，警示用沉稳朱砂/琥珀暖金而非荧光红 |
| **商城页画出微信/支付宝图标或 Hover 提示** | iOS 提审按 3.1.1 直接拒审；手机/小游戏端玩家看不到悬停信息 | 商城页禁画第三方支付通道标志；所有关键防骗提示直接显性排版或点击展开，不依赖 Hover |
| **与豆包共享 Git 冲突** | 覆盖或阻塞美术仓库固定批次发布 | Codex 在 `image` 仓仅交付文件与清单，**严禁操作共享 Git 的 HEAD / index / refs / push** |
