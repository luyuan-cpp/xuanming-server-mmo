# 装备首发规格 V1：正式词条池、数值与八件法宝

更新：2026-11-17。入口：[八部位装备与 UI 接入](equipment-eight-slot-planning.md)。

## 1. 版本与范围

用户要求将词条、数值和首批法宝设计完整后开始 UI 与代码接入。本稿在这一授权范围内收口为 **V1 首发实现基线**，不再并列多套待选数值。用户此前明确确认的八部位、四基础装 +10 必成、首套 300 打造材料 + 300 强化石、每日 20 份自选材料保持不变。

本稿的新数值属于本轮设计结果，不冒称用户逐条指定，也不声称已完成实战平衡验证。八槽、指定穿戴、V1独立强化、打造与首次装词条、36项属性及八件法宝战斗效果均已接入源码，范围见[代码记录](equipment-eight-slot-implementation.md)。按用户要求，本轮先完成代码及生成同步，装备和技能后续统一编译验收；新UI和旧资产转换未实施。

- 只作用于人物自己的装备；宝宝使用自身条目，不继承主人的装备、法宝或百分比。
- 保留体质、灵力、力量、敏捷四维加点，不增加第五种属性点。
- 八位置为武器、帽子、衣服、鞋子、首饰一、首饰二、法宝一、法宝二。用户进一步明确：两首饰位完全互通、两法宝位完全互通；允许两件名称、造型及词条都相同的首饰，也允许两件同名法宝。左右只表示界面位置，不区分戒指/项链或进攻/防守，也不表示首饰与法宝跨类别互装。
- 本稿的 D/E/G/F 编号是策划索引，不是 proto 字段号、正式表 ID、物品 ID 或消息号。
- 仅定人物装备对技能的修正，不改技能已定人数、行动次数、学习资格和时长。人物 A40 是独立主动护盾；P11 过量转盾已经撤回。
- 材料人民币单价仍未定；0.1 元及 60 元只保留为主文档的试算。旧装备转换、宝石开放、交易和升档收费不在本稿中擅自决定。

## 2. 装备结构与固定基础值

| 部分 | 实例内容 | 首次材料 | 强化 |
|---|---|---:|---|
| 四件基础装 | 固定基础值 + 1 个方向位 D + 1 个效能位 E | 每件本体20、两个词条各10，共40 | 每件75石至+10 |
| 两件首饰 | 无额外基础数值；每件2个通用位 G | 每件本体10、两个词条各10，共30 | 无 |
| 两件法宝 | 无基础属性或随机词条；每件1个固定法宝效果 | 每件40，指定兑换 | 无 |

总计四个方向位、四个效能位、四个通用位，以及两个法宝效果。首饰本体的作用是承载两个通用位，未填词条时没有属性，不把它描述成已有满值。

- D/E/G 各位置只能从自身池选一项；D/E 可以跨方向搭配，不按职业锁池。
- 同件首饰的两项 G 不得相同；两件首饰可以完全相同，其相同词条各自计入，因此同一通用词条全身最多两条。例如两件均为气血+4%、速度+1%，合计气血+8%、速度+2%。
- 法宝允许同名双件，两个位置可装相同或不同的法宝；不得以同名、同模板或同效果组禁止第二件穿戴、购买或兑换。这里的两件是两个物品实例，不能让同一实例同时占两个位置。
- 同名两件均完整生效，按物品实例独立计次，同次事件以原基数合并同层加成，不逐件复利；具体条件、取整、触发和双件计算以第5节为准。下文基础数值及限次表描述单件效果。
- 第一次装入词条花10打造材料，定向选择目标词条，并在 [V1 装备窄区间品相与制书规格](equipment-quality-and-skill-crafting-v1.md) 定义的 5 档窄区间（80%/85%/90%/95%/100%，天花板仍为下表原满值；`G02 速度`豁免固定满值）内掷出品相；历史存量 `quality_tier = 0` 实例自动按 100% 满值生效。空位合法，不会在重登时随机补齐。
- 后续可用「1 重铸砂 + 20 银两」对单条已装词条进行**打磨淬炼**（只升不降、累计第 8 次必达极品 100%，并支持绑定「定星保底符」提速）或**重铸换词条**（同槽换流派时 100% 无损保留该槽已达成的品相与保底进度）。宗师打造的极品词条装备永久烙印铸造者署名。

四基础装沿用现有 1/10/20/30/40/50/60/70/80 档。令装备等级为 L：

| 部位 | +0 基础值 | 可强化项 |
|---|---|---|
| 武器 | 物攻、法攻各增加 20L+20 | 两项同时强化，数值相同 |
| 帽子 | 防御增加 6L+6 | 防御 |
| 衣服 | 防御增加 12L+12 | 防御 |
| 鞋子 | 防御增加 6L+6；速度增加 4L+8 | 仅防御，速度不强化 |

强度固定为每级对原始可强化基础项增加2%，+10总加20%，不逐级复利；`强化后基础项 = floor(原始基础项 × (10000+200×强化等级) / 10000)`。词条、首饰、法宝和鞋速度不参与。80级武器1620→1944，帽子486→583，衣服972→1166，鞋防御486→583、速度328不变。

词条百分比在各装备档位保持本稿数值，不按装备等级重复洗更高档；装备成长由上述本体与角色/技能成长承担。改变这一约束必须重新评估养成预算。

## 4. 计算、适用范围与上限

### 4.1 常驻属性、治疗与护盾

所有百分比/概率修正以万分比整数计算，100表示1个百分点。显示区分“攻击+8%”与“命中+4个百分点”。中间乘法使用足够宽的安全范围，最终非负整数按本节规则取整，不通过每个来源各取整制造累计误差。

- 对物攻、法攻、气血、速度：先算自然成长、四维加点、装备本体/强化和其他合法平加来源的基底B，再算 `floor(B × (10000 + 装备对应百分比总和 + 合法常驻被动对应百分比总和) / 10000)`。装备和常驻被动同层相加；临时状态在战斗层按技能规则处理，不回填基底再乘一次。
- 物理词条只进物攻，法术词条只进法攻。技能读取修正后的面板一次，伤害出口不再乘一次装备8%。已有毒伤快照被催毒/毒火消费时不重算当前装备加成。
- 各治疗技能提供独立的 `H0(人物等级,技能等级)`；各护盾技能提供独立的 `S0(人物等级,技能等级)`。它们不读取物攻或法攻面板，也不读取体质/灵力作为额外治疗点。技能线维护各自基础曲线，本稿不复制第二份曲线表。
- 普通施放治疗修正为 `H0 × (10000 + 装备治疗 + 适用被动/临时治疗修正 + 本次法宝治疗修正) / 10000`；其后应用技能本身的条件倍率、目标增疗/减疗，最终一次向下取整并按缺血封顶。装备D03只占这一个施放修正层。已有合法P05等效果按适用性加入，不能删除或重复相乘。
- 盾容量同样由 `S0 × (10000 + 装备护盾 + 适用被动/临时护盾修正 + 本次法宝护盾修正) / 10000` 计算并向下取整。与治疗完全分开；不读目标缺血、治疗结果、治疗加成或减疗。A40“同档基础治疗80%”只是配表标尺，不是运行时拿治疗结果乘80%。
- D03适用A10/A12的即时治疗、A26的正常持续恢复；不放大复活初始血量、吸血、药品、伤害转治疗或法力回复。A26在合法施放时快照完整施放方治疗基础与当时适用修正，包括装备、合法被动和临时治疗修正；每跳只重新读取目标当前增疗/减疗及缺血量。施法者后续状态变化不回算旧印，不在每跳再次乘装备百分比；F04不适用A26，复活血量不读取这份持续治疗倍率。
- D04只增强人物A40独立容量，首发不扩展宝宝B05/B06资格，不增加次数盾的次数、不改善法力盾换算、不产生过量治疗转盾。未来新增护盾必须显式登记，不能按名字自动纳入。
- 物法暴击不作用治疗、护盾、持续伤害、反弹、资源代价和已结算毒伤的再次消费。适用直接伤害的暴击规则沿用各技能定义；装备暴击加入对应类型一次，总概率夹到0—100%，倍率沿用2倍。当前职业基础10%时，四条E01得到物暴18%，不是8%。
- 换装改变最大气血时沿用比例保持，不能靠穿脱回满；战斗内装备锁定。主人装备不修改宝宝自身面板。

### 4.2 分类减耗

令C0为按技能原规则算出的非负整数基础费用（百分比费用先按原规则向上取整）；R为适用装备及合法被动/临时减耗之和。

`最终费用 = C0为0时取0，否则max(1, ceil(C0 × (10000 - clamp(R,0,3000)) / 10000))`。

装备单类别最多减12%，所有减耗来源合计封顶30%。此上限是V1接入参数，不改P09/P19明确的零耗蓝。技能资源转换、固定献祭等非一般法力费用不适用。不同类别不相加；界面展示本技能实际折扣和被上限截去的部分。

### 4.3 障碍判定

封灵、封法、封物、混乱、昏睡、冰冻、中毒是七个独立类型。封灵不是自动同时读取封法和封物；抗物理/法术伤害不参与这里。

1. 先处理技能资格、目标合法性、免疫和冰冻隔离。未开放/基础概率为0的效果、非法目标或免疫直接不生效、不掷骰，不能被概率下限抬起来。
2. 对合法效果取其技能基础概率P0。有效抵抗 = max(0, 同类型抵抗 + 合法通用抵抗 - 适用忽视抵抗)。新版池不发通用抵抗或忽视条目；兼容来源只按已获准规则计一次。
3. 未夹取概率 = P0 + 同类型命中 + 本次法宝/临时命中 - 有效抵抗；所有量统一成万分比。
4. 六种硬控制的最终概率夹到5%—85%；中毒夹到5%—95%。这些上限是首发参数，不代表已验证不存在多人连续控制。
5. 每目标每效果只进行这一次成功判定，不再追加旧异常系统的第二次独立抵抗骰。主目标也可能失败，失败不补抽其他目标。

技能的伤害命中与障碍效果判定仍是不同事情；只有技能契约要求的伤害命中通过后，附带效果才进入上面步骤。当前六控制和中毒的专属标签须真正接入引擎，不能用旧“抗遗忘映射沉默”代替三个封锁类型。

### 4.4 类型抗性

G03/G04沿用既有物法伤害抗性接缝：`受伤比例=max(0.4, K/(护甲+防御+K) × (1-clamp(对应总抗性,0,100%)))`，K=360+120×目标等级（等级沿用现有1—85范围）。基础抗性、对应装备抗性等同层计入；物法分别计算。

常驻减伤上限60%不被新词条突破。主动防御、技能护盾、护心珠的有限条件效果属于各自阶段，不能再把G03/G04在这些阶段重复应用。UI使用“抗物理/抗法术”，不写“最终少受6%伤害”。

## 5. 首批八件法宝

### 5.1 共同规则

- 每件40打造材料定向兑换，效果完整，无升星、强化、随机值、镶孔、洗练或付费解锁强度。两件自由组合，开战快照锁定。
- 表中的“正常动作”包含玩家手动下令和自动战斗选出的正常行动；不包含反击、追击、开场、反弹、连击追加段、混乱强制友伤或法宝派生事件。攻方增效只作用该正常动作指定的合法主目标，不复制到群体副目标；主目标失效不转赠。
- 防守法宝按各自受击条件可响应敌方直接攻击，包含合法反击/追击；不响应毒/灼烧、反弹、援护转伤、生命消耗或资源代价。
- 次数按全局战斗回合/整场记录，不按网络请求或动画段计数。死亡、复活、断线重连和补拉不重置已用次数；死亡清除未消费的封控补偿。每场状态仅在新战斗重建。
- 所有伤害段须有明确且唯一的伤害类型；一个段不能同时获得物理和法术法宝效果。法宝不创造额外正常行动、法力消耗或可递归触发的攻击。
- 固定容量盾仅指以整数容量吸收直接伤害的盾，不含法力盾、按次抵挡、免疫或百分比减伤。具体盾是否吸收某伤害仍由技能契约决定。
- 取整后实际收益为0时不消耗“实际收益”类法宝次数；概率类法宝在真正进入指定判定时消耗，不以结果成功与否退还次数。
- 同名双件均完整生效，次数、待用补偿和失效窗口按各自物品 `item_id` 独立记录，不共享一份次数。同事件先固定原基数，把同层加成相加后统一结算，不能拿第一件结算后的结果再乘第二件。
- 当前收益不足以分给所有来源时，按 `item_id` 升序分配取整后的实际收益，仅实际贡献大于0的实例扣次数；稳定ID顺序只用于封顶、取整与分配，不表达装备先后、物品新旧或触发时间。实例记录和运行状态按ID关联，不依赖两个列表下标相同。F08是概率判定型，符合条件的两件都在该次判定中耗次，最终收益为0也不退还。

### 5.3 破盾、急救、护盾的结算边界

- F01/F02的D取该正常动作主目标第一段已经完成暴击、防御、抗性、主动防御、PVP系数和适用伤害分担后，实际进入主目标自身护盾吸收链的整数直接伤害预算，位于护盾吸收和气血封顶之前。转给援护者的部分不计入D，也不替援护者触发此法宝；不以击杀时实扣的少量气血为基数，不对D再掷暴击。
- 在本段开始吸收前记录“当时已存在、能吸收本段伤害、位于既有吸收序列”的合格容量盾及其顺序，不要求每一层本次都实际吸收过伤害。先完成正常护盾/气血结算；受击者仍存活且记录中的盾有剩余时，再扣 `min(记录中剩余合格容量总和,floor(D×20%))`，沿记录顺序消耗，跳过已经移除的层。免疫盾、类型不匹配盾以及反应中新建的盾均不纳入。两层原容量210、500且D=200时，正常后10、500，额外40扣后为0、470。
- 额外扣盾不溢出到气血、不增加命中段数，不触发受伤回蓝、反击、反弹、吸血或击杀。它位于普通伤害处理完、由本段引起的反应队列执行前；记录盾容量变化供表现与回放使用。
- 本动作第一段不满足破盾条件时，后续连击/多段不能补领机会。没有发生实际额外扣盾时不计本回合使用次数，但仍不能用同动作的后段再试。
- F04低血线只看治疗前当前气血，不把盾量加进去；A10/A12可用，A26回合末恢复、复活、吸血、药品等不可用。增效后仍按缺血封顶，过量不转盾。它加入治疗修正层，不在已经含D03的结果上再乘1.12。
- F05只修正本次A40的新容量，不修补旧盾、不延长时长、不增加目标数；用修正后的新容量与旧剩余量比较，未实际创建/替换则不耗次数。治疗、其他法宝或宝宝护罩不会触发F05。
- 人物治疗和A40分别占正常行动，因此F04/F05不能让同一回合免费治疗加套盾；选择两件意味着放弃其他法宝位置。

### 5.4 补偿、减伤、回蓝与抵抗的状态边界

- F03只由实际概率结果“抵抗”生成；免疫、非法目标、效果关闭、未执行、同名覆盖拒绝等不生成。每技能配置唯一的主障碍类型；多效果技能的其他类型不能生成或消费补偿。
- 每件同时最多一份补偿，仅在下一全局回合有效，回合末未用即消失；允许换主目标，不允许换障碍类型。该件存在尚未消费或到期的补偿时，其他类型的失败不生成新补偿、不覆盖、不排队，也不消耗生成额度。消费判定前先合入该件6点并夹最终概率，判定后必清除；被任一回响补偿的那次若仍失败，两件均不因此再生成补偿。没有消费而到期也不退还已经使用的生成次数，到期后下一回合才可能因新的失败再次生成。
- F06的D是其他防御、护盾和伤害转移都处理后、实际气血封顶前，准备由本人承担的整数直接伤害；不能再用原始攻击伤害算一次。原D被完整挡住时不触发。减免发生在真正扣气血前；后续反弹等按新的实际扣血计算，不先扣血再回血。死亡不复发，复活不刷新开局时间窗；每场一次的条件减免不计入常驻抗性，不被反复套用。
- F07只由原指令为普通防御且实际执行触发。被控跳过、技能附带防御、施法回蓝A15不触发；每次上限锁定入战最大法力，不被临时提高上限放大。实际回复0不扣次数；无论战斗多长，法宝本身最多回15%入战最大法力，不吃治疗/护盾加成。
- F08在敌方正常动作真正对本人进行六硬控之一的概率判定时，给该次抵抗层加8点；同动作多种控制按既定效果顺序仅第一种可用。免疫/非法目标不消费；进入判定即消费，即使夹取后概率未变化或最终仍被控制。不加第二次抵抗骰、不解控、不缩短已中效果，也不将中毒算成硬控制。
- 所有法宝状态、次数和来源进入本场权威状态与回放。开窗、切页、重发请求、施法失败或换动画不会重置次数。

- 同预算比较纯物/纯法/双修、单控制/双控制、纯治疗/纯盾/混合辅助；比较抢速/耐久/定向抗控首饰，不能只测全部无抵抗木桩。
- 真实战斗需包含2—3名控制者接力、2—3名辅助轮流治疗/套盾、驱散、毒伤、低匹配量日常及PVP。85%上限本身不保证不存在连续控制，须核对技能时长/CD/耗蓝；未验证前不宣称已平衡。
- 若护心珠+清心符成为所有流派必选，优先调整效果和触发窗口；若其他法宝没有适用场景，调整战斗内容覆盖及参数。不得通过新增洗练、升星、额外收费或每日任务解决。

## 8. UI 与实现交接

- 首发UI展示三类池、36项固定词条及八件法宝。控制条目在类别筛选后选择具体类型，不能增加“全部控制”快捷属性；推荐搭配只预填，不限制玩家合法混搭。
- 治疗与护盾在面板和对比中分两行；减耗按技能类别显示，概率使用百分点说明；抗物/抗法注明参与常驻减伤公式和上限。
- 法宝卡片至少展示效果、主目标限制、触发条件、每回合/每场次数、兑换材料；战斗内状态可显示剩余次数或回响待用类型。不得把全部八件都标成必收集养成进度。
- 服务端下发正式ID、合法槽/池、单位、现值/上限、预览和可用操作。UI可用本稿做独立样例，但正式计算和扣款以服务器为准，不在界面重新实现一套公式。
- 基础装模板与强化通过独立profile区分新旧规则；打造/词条使用配置指纹和持久forge_revision拒绝过期确认及重复执行。旧全抗/全忽视/全技能等级/随机多词条及旧+1至+12、宝石保持，旧资产转换另行确定。
- 引擎已接入独立治疗/盾基础曲线、按类别障碍判定和减耗、八法宝状态与回放；客户端业务接口及协议已同步。装备与技能的最终编译、联网和运行验收按用户安排后续统一执行，新UI可据权威模型绑定。
- 与技能线的基础曲线、目标选择、状态生命周期接口要对齐；本稿只给装备修正，不擅自改其他聊天正在维护的技能人数、施放次数和已定机制。
