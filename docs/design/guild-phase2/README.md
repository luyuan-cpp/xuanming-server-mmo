## 2. 用户已拍板(2026-09-15)

1. **货币**:银两 = 现有金币(`kCurrencyGold`),灵石 = 现有钻石(`kCurrencyDiamond`),不新增货币类型;客户端标签同步改名。「建设物资」(道具捐献)留到 v1.1。
2. **资产通道**:帮会先做**通用版**,接口名不带 Trade 前缀,聚宝斋 P2 复用(同步改 `jubaozhai-market.md` §6.4)。
3. **活动玩法**:都在帮会界面里参与,不做地图交互。元宵灯会 = 每人每日点灯得帮贡,全帮点灯数达标再给帮会资金;中秋团圆 = 帮会同时在线人数达标后各自领奖;同道历练 = 帮会成员组队打指定副本,胜利得帮贡与资金。
4. **存储**:帮会所有表迁入自己的库 `mmorpg_guild`,修订 D-14 §8。
5. **未反对的默认**:名字全服唯一、2–12 字、建角必填、空名服务端生成;帮主任免长老 / 踢人 / 转让,长老审批 + 踢普通成员;长老上限随等级;申请 72 小时过期;每人最多 3 个待审申请。**所有数值进配表**,上线前由策划改表,不改代码。

## 4. 默认数值(全部在配表里,可随时改)

**GuildLevel**(10 级):成员上限 30→100,长老上限 2→6,升级花费 20000 / 50000 / 100000 / 180000 / 300000 / 460000 / 680000 / 960000 / 1300000 / 0(满级),累计 4,050,000 资金。建帮即 1 级 30 人(原硬编码 50 人作废)。

**GuildRule**(单行):申请 72 小时过期、每人最多 3 个待审、每帮最多 50 个待审、捐献指令 600 秒截止、重投基准 1000 毫秒、团圆最低在线 3 人、入帮满 0 小时即可参加活动(上线改 24)、历练邀请 30 秒过期、同一发起人建房间隔 10 秒。

**GuildDonate**(3 档):银两小捐 10,000 → 10 帮贡 + 1,000 资金,每日 5 次;银两大捐 100,000 → 120 帮贡 + 12,000 资金,每日 2 次;灵石捐献 100 → 200 帮贡 + 20,000 资金,每日 1 次。

**GuildShop**(11 件,分修行补给 / 帮会珍藏 / 节庆好礼三类):30–1500 帮贡,按帮会等级解锁,分别限日购或周购。

**GuildActivity**(3 行,开发期常开):灯会 20 帮贡 + 全帮 3 次点灯给 500 资金;团圆 30 帮贡 + 奖励物品;历练 50 帮贡 + 300 资金,2–5 人,每日 2 次。上线前把档期时间、阈值(灯会 20、团圆 10)、入帮时长 24 小时一起改。

**RoleNameRule**:2–12 字,空名生成「道友 + 6 位随机」。
