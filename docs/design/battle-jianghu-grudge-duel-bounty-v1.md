## 1. 需求分析

### 1.1 业务意图与为什么需要这套玩法

《五行奇谈》现有核心战斗（3 只差异化首领、常驻自养会武 `1V1`/`3V3`、轮换娱乐场、匿名帮会 2V2 会武）已经解决了“单人有空就玩、公平不逼氪”的底盘，但在真实 MMO 长线留存与官方小额付费转化上存在一处明显情绪缺口：

- **匿名匹配打完即散，缺少“记住脸、结下梁子、叫上兄弟打回来”的江湖粘性**；
- 玩家缺少“**为了打赢眼前这个死对头 / 敌对帮派**”去快速补齐第二套克制流派、洗满极品品相、拓印稀世绝学或购买排面外观的强情绪临门一脚。

同时，项目已由负责人拍板严守 [project-vision.md](project-vision.md) 六条红线，**绝不走“野外无门槛强杀和平散人 + 充钱买 3 倍战力碾压”的老路**——在本作低人口冷启动、1 线 Fill-First 聚人与全员同战力上限的架构下，无门槛强杀只会放纵极少数恶意小团体清走散人基本盘，反噬长期收入并引发小游戏/应用商店审核与客诉灾难。

因此本设计的目标非常明确：**在 100% 物理隔离和平散人、0 破坏战力上限与经济防线的前提下，引入“自愿入局的江湖恩怨体系”，用体面的约战仪式感、全服围观打脸、帮派小团体恩怨与二期灵潮集中劫火悬赏，活跃全服气氛并直接/间接拉动官方 70%+ 小额直售收入。**

### 1.2 目标、非目标与反目标

| 类别 | 明确边界 |
|---|---|
| **目标（Goals）** | 1. 个人、小队（2–5 人）与帮派可发起公开「擂台生死状」，开打即全服播报并接入现成 L0/L1/L2 分级观战与战报回放；<br>2. 沉淀「江湖恩怨录」与「帮派恩怨墙」，把一次性胜负变成可持续追踪的长期关系；<br>3. 二期接入随 [world-map-play-v2.md](world-map-play-v2.md) 五行灵潮轮换的「劫火争夺线」，为爱打架的玩家提供单人/小团体/帮派自由劫战、煞气红名、悬赏缉拿与「思过崖」面壁闭环；<br>4. 形成合规、高毛利的官方 7:3 消费拉动（直接小额仪式感/减刑/追踪道具 + 间接拉动定星保底符、天工秘墨、轻享卡与永久外观）。 |
| **非目标（Non-Goals）** | 1. 不做和平野外地图无门槛强杀、偷袭或守尸；<br>2. 不做任何装备掉落、装备损坏或扣除永久 660 首套材料；<br>3. 不做自由额度银两对赌或自由额度悬赏转移银两；<br>4. 不做强迫亮屏挂机数小时的重刑监狱，不另建复杂监狱怪 AI 与重型新微服务。 |
| **反目标（Anti-Goals，出现即视为失败）** | 1. 任何和平散人因本玩法被迫进入 PVP 或被战书/悬赏持续弹窗骚扰；<br>2. 工作室或骗子借生死状/悬赏实现绕过集市 5% 税或当面交易限制的银两转移/刷赏套现；<br>3. 付费玩家靠本玩法道具获得高于零氪玩家的 1 点战斗数值上限；<br>4. 低人口期开启野外劫火线导致活人被进一步拆散或全线空转无人可遇。 |

### 1.3 备选方案评估与拍板结论

设计阶段评估了三条可行路径（均遵守和平散人零波及与零战力突破前提）：

| 方案 | 形态简述 | 核心权衡 | 结论 |
|---|---|---|---|
| **方案 A（轻量一期）** | 天墉城西北双擂台「生死状（1V1～5V5/帮派）」+ 公开分级观战 + 恩怨录 + 限时社交败者印记 | 高度复用现有 `ChallengePlayer`、`WatchBattle`、`BattleReport`、`Chat`；双服工期最短、0 审核雷区、0 洗钱面；缺少野外拔刀与红名蹲崖草莽感 | **采纳为一期基线** |
| **方案 B（全图自愿杀伐）** | 方案 A + 全图手动开关「杀伐态」+ 全图野外强杀/红名/悬赏/思过崖 | 原味最强，但开发量约方案 A 的 3 倍，且开服低人口时极易出现“开了杀伐态满图撞不到人”的空城尴尬 | 不采用（聚人问题被方案 C 替代） |
| **方案 C（灵潮集中劫火）** | 方案 A + 复用五行灵潮周期开放单条专属「劫火线」（自愿进线强杀、红名进思过崖、固定档悬赏缉拿） | 用 40 分钟灵潮窗把全服所有好战分子聚在**同一张图同一条线**碰头，专治低人口空城，同时普通 1 线保持 100% 和平 | **采纳为二期扩展** |

**负责人已拍板路线**：**按「方案 A（一期首发）→ 方案 C（二期按在线达标开关开启）」两阶段统一设计、分步落地**。先用最小双服增量验证生死状与恩怨氛围的留存与转化，待活跃人口与一期约战频次达标后再打开二期劫火线开关。

### 1.4 上位红线准入自检（[project-vision.md §二](project-vision.md#二后续所有子文档准入自检写设计前必答-4-问) 必答 4 问）

1. **普通零氪玩家**：不花钱、不想打架时，野外 1 线 100% 和平、拉黑或开免战后 0 战书打扰；想玩恩怨时，普通战书/洗尘符/铜银悬赏令/思过崖减刑全部有银两或自然免费路径，且战斗使用同一套 +10/+11 与 36 词条上限，绝不卡脖子也不逼上班打卡。
2. **个人开发者收入**：战书金帖、全服播报/入场特效、清风洗尘符、金令全服通缉、千里追踪符、清心保释文书均为**官方商城 100% 直售绑定道具**，不给工作室留 1 分钱分润；同时借恩怨复仇直接拉动既有「定星保底符」「天工秘墨」「仙途轻享卡」「限量提速包」转化，严守官方 7:3 格局。
3. **物价与长期循环**：本玩法**完全不产出 660 核心装备材料与可交易装备**；普通战书、洗尘符、铜/银悬赏令及思过崖银两减刑全部作为**真实 `kCurrencyGold`（银两）销毁出口**（发布银两 100% 销毁，捕快仅拿不可交易义士声望 + 严格低于成本的小额系统封顶补贴），反而帮助稳定中后期银两通胀。
4. **防骗与资产安全**：严禁自由银两对赌与自由金额悬赏，彻底封死绕过 [equipment-economy-charter.md §2.3](equipment-economy-charter.md#23-游戏内当面交易防骗与站外引流阻断) 的洗银/诈骗后门；角色过户（`owner_revision` 变更）自动清空旧持有者私人恩怨、败者印记、煞气与悬赏，杜绝买号背旧仇；所有官方付费道具均永久绑定防洗白。

## 2. 设计分析

### 2.1 国内过审与合规文案规范（一二期统一强制）

为保障微信小游戏、抖音小游戏、iOS 及国内全渠道过审并降低戾气客诉，所有客户端展示文案、系统播报、表字段展示名与 UI 按钮**严禁出现“杀人 / 强杀 / 屠杀 / 监狱 / 坐牢 / 认怂 / 废物”等字眼**，统一采用仙侠江湖软化词汇：

| 内部设计概念 | 对外统一仙侠文案 | 说明 |
|---|---|---|
| 公开约战 / 签生死状 | **天墉生死擂 / 江湖战书（生死状）** | 强调武道切磋与江湖了结 |
| 野外强杀 / 小团体围殴 | **劫火切磋 / 灵潮劫战** | 限定仅在自愿进入的劫火线发生 |
| 杀戮值 / 红名 | **煞气值 / 煞气缠身（黄名/红名）** | 视觉用赤色剑气光环而非血腥图标 |
| 蹲监狱 | **思过崖面壁** | 仙侠闭关思过场景，内设静心石碑与同崖闲聊 |
| 悬赏追杀 | **江湖悬赏榜 / 缉拿文书** | 正邪江湖缉拿语境 |
| 败者头顶debuff | **「封剑思过」/「惜败于 XXX」** | 仅允许查白名单固定模板，零自由输入防辱骂 |

### 2.2 一期核心玩法（方案 A）：天墉生死状 ＋ 江湖恩怨录 ＋ 帮派恩怨墙

一期**零新增大世界强杀、零新场景、零新微服务、不另做独立的“帮派管理宣战帖”审批流程**，把所有交互收口在主城天墉城西北双擂台（[world-map-play-v2.md §2.1](world-map-play-v2.md#21-严格控图与四图生态分工一图一玩法绝不同质换皮)）与个人/帮会面板；帮派恩怨直接靠两帮纯同帮小队打常规生死状自动入帮派恩怨墙。

#### (1) 擂台生死状（单人 1V1 / 小队 2V2·3V3·5V5 / 帮派小队约战）

1. **发起条件、跨图范围与防骚扰四重闸**：
   - **区服与地点口径（建议口径）**：支持**同归属区（含合服组）远程随时约战**，不强制双方同站天墉城坐标；成局后战场采用天墉城西北双擂台景别，并同步在双擂台公开围观入口与本区世界频道播报。
   - **队伍全员确认纪律**：发起方可以是单人，或当前空闲的 2–5 人队伍队长（若双方均为不同帮会的纯同帮小队，系统自动附加「帮派恩怨对决」标签）。严守仓库“队长不得代队员确认进 PVP”纪律（对齐 [guild-play-v1.md §4](guild-play-v1.md)）：**发起方小队需先完成本队全员确认后才对外发出 60 秒邀请；目标队长触发应战后，目标队全员须在 30 秒统一窗口（且不超过邀请截止，或触发后锁定 30 秒最终确认窗）内全员确认**。等待期间任一成员退队、换人、换帮或触发其它玩法占用，整单安全作废且不扣费。
   - 必须通过四重服务端校验方能创建邀请：
     1. **全员双向拉黑拦截**：校验双方全体成员两两之间在 `go/friend` `friend_block` 中均无拉黑记录（最多 5×5 对）；
     2. **全员闭关免战开关**：校验目标全员均未开启「闭关免战（拒收非好友战书）」开关（好友间允许正常切磋/约战）；**开启闭关免战者本人同时禁止主动向他人发战书**，杜绝“开盾约架、打完闭关躲复仇”；
     3. **同目标冷却与日频控**：对同一目标发帖冷却 **5 分钟**（拒绝或过期起算），单角色每日最多发起 **20 次**未成局战书邀请；
     4. **资产预检**：小队生死状由**发起方队长单人出资**，发起时仅做持有/余额预检，**此时绝不扣道具/银两**。
2. **两档战书（零逼氪 + 纯排面分层）**：
   - **普通「江湖战书」**：直接扣除 **500 银两**（不另造占格背包实体道具），成局触发普通样式全服系统公告＋公开观战入口；
   - **官方「金帖生死状」**：官方商城直售绑定道具（参考定价 **20 灵石 = ¥2**），成局触发**金色横幅全服播报＋战报金框留痕**（0 战斗属性加成；独立永久买断的「擂台入场/胜者特效包」留作后续外观拓展，不占一期 M1–M3 工期）。
3. **邀请、拒绝与 `ItemHold` 零吞货扣费时序（关键）**：
   - 发起后写入 `go/match` 权威表 `match_jianghu_duel_invitation`（TTL **60 秒**，同一目标同一时刻至多挂 1 条待应答生死状，复用 `match_challenge_invitation` 的 `owner_account / owner_revision` 围栏）。
   - **邀请阶段绝不发全服公告**！仅通过点对点推送弹窗通知目标。
   - **目标拒绝或 60 秒超时**：不扣发起方任何道具/银两，不发任何全服“认怂”公告（仅私密反馈发起方“对方暂未应战”），杜绝借战书公开网暴或吞玩家灵石道具。
   - **双方确认应战 → `ItemHold` 冻结与实扣（零吞货/零刷货）**：`match` 锁定双方全员占用后，在发起方队长所在 `scene` 的 `PrepareBattle` 阶段沿用现役 `PlayerItemHoldComp`（`BagService::PlaceHold` / 银两预留）按 `duel_invite_id` 幂等冻结 1 张金帖或 500 银两；**仅在战斗正式进入第 1 回合确认开打时提交实扣**；若备战失败、`CreateBattle` 失败、或对局因节点故障裁决为 `BATTLE_OUTCOME_VOID`（作废）/ 零回合异常中止，一律**释放冻结（若已实扣则经 `go/mail` `SenderKind("match") = 6` 按 `duel_invite_id` 幂等原样退还）**。
4. **战斗规则、回合上限与全服围观**：
   - 独立模式枚举 **`MATCH_MODE_JIANGHU_DUEL`**（不混用 `MATCH_MODE_PVP_CHALLENGE`）：
     - **使用双方本人真实养成**（装备、词条品相、法宝、自由技能、宝宝、赛季技/印，局内满血蓝隔离、禁背包药、不回写血蓝），每侧人数按约定 `1V1 / 2V2 / 3V3 / 5V5`（等额人数）；
     - **回合与时限权威判平**：打满竞技回合上限（沿用配置表回合上限）或单场 720 秒时限仍未自然分胜负时，**一律权威判平局**（修正通用引擎默认判 B 胜分支，对齐 [guild-play-v1.md §2.3](guild-play-v1.md)）；
     - **公开观战**：`spectateVisibilityOfMode(MATCH_MODE_JIANGHU_DUEL)` 显式返回 **`SPECTATE_VISIBILITY_PUBLIC`**，成局即进入 `ListWatchableBattles` 并在天墉城/世界系统频道推送**一键围观按钮**（复用 `WatchBattle` 与 L0/L1/L2 分级观战，观众人数暴涨自动升 L2 广播防压垮 battle 节点）；
     - **零材料与零段位污染**：**不计入正式论剑 Elo/段位**，**不计入 660 首套装备材料**（`IsEligibleBattle` 明确排除），彻底杜绝互刷段位与材料；
     - **自动录播战报**：纳入 PVP 战报录制白名单（沿用 `battle-report-replay.md`），双方可从「恩怨录」回看最近交手。
5. **战后结算与轻度社交印记**：
   - 全服系统频道按固定模板播报战果（如：`【天墉生死擂】<胜方> 历经 N 回合击败 <败方>，恩怨录记胜一笔！`；金帖附带金框样式）；
   - **无装备损失、无银两对赌**；败方个人挂载限时社交印记「**封剑思过 / 惜败于 XXX**」（头顶轻微视觉徽记，持续 **30 分钟自然墙钟计时，离线照常递减**；小队战败展示胜方队长名，若为纯同帮队伍则展示胜方帮名；30 分钟内连输给不同对手时**覆盖刷新为最新一场**）。
   - **三种无压消除途径**：① 自然等待 30 分钟消散；② 在后续生死状中击败原胜方队长（或含原胜方任一成员的复仇局获胜）立刻清除；③ 使用「**洗尘符**」（**1,000 银两**基础款立刻消除，或官方商城 **10 灵石 = ¥1**「清风洗尘符」消除并附赠 30 分钟趣味江湖自嘲/洒脱外观徽记）。

#### (2) 江湖恩怨录（个人）与帮派恩怨墙（团队）

1. **个人「江湖恩怨录」**：
   - **权威写入来源与多人粒度（防写放大）**：仅由 `go/match` 在 `MATCH_MODE_JIANGHU_DUEL`（及二期 `MATCH_MODE_JIANGHU_BRAWL`）确认有效终局后自动记录，**不支持客户端手编恩怨战绩**；`1V1` 对局双方互记个人恩怨，**多人小队局（2V2–5V5）个人恩怨录仅记录双方队长（1 对 1）**，其余参战成员通过个人最近战报与帮派恩怨墙追溯，避免打 10 场 5V5 就把 50 个宿敌位冲爆；
   - **展示内容**：展示与每位对手的**累计胜/负/平次数、最近交手时间、最近 20 场战报 ID（可跳转已有回放）**，以及对方当前是否在线、是否处于可下战书状态（**绝不泄露和平玩家所在野外地图与坐标**）；
   - **有界容量与主动放下**：单角色恩怨录最多保留最近活跃的 **50 名对手**（按 `last_battle_ms` 淘汰最旧项）；支持单向「**一笔勾销**」隐藏不再想看的旧对手（不影响对方记录，也不重置防骚扰冷却）；
   - **过户换人隔离**：记录绑定 `(player_id, owner_revision)`，角色经官方过户换人后，旧持有者的全部私人恩怨录与头顶败者印记自动清零/隔离，新号主绝不替前任背仇。
2. **帮派「恩怨战绩墙」**：
   - 当一场 `MATCH_MODE_JIANGHU_DUEL` 双方均为**不同帮会的纯同帮队伍（如 2V2 / 3V3 / 5V5 帮派小队约战）**完成有效对局时，`go/match` 通过既有的可靠投递管线（复用 [guild-play-v1.md](guild-play-v1.md) 帮会战绩投递 outbox 机制）向 `go/guild` 投递一条帮派恩怨战绩；
   - 帮会页新增轻量「**江湖恩怨墙**」分页：按敌对帮会汇总两帮近期交手胜负比与最近 20 场参战名单摘要（帮会解散后不继承至同名新帮，沿用 `guild-play-v1.md §5` 纪律）。

### 2.3 二期扩展玩法（方案 C）：灵潮·劫火争夺线 ＋ 煞气红名 ＋ 悬赏缉拿 ＋ 思过崖面壁

> **上线闸门（强制）**：二期默认以服务端配置开关 `JianghuJiehuoEnabled = false` 关闭。仅在一期运行稳定、单区晚间活跃人数与生死状日活达到设定门槛（建议峰值活人 ≥ 80 且日均公开约战 ≥ 20 场）后，再由负责人评估按区开启，避免低人口期开启导致劫火线空城。

#### (1) 灵潮·劫火争夺线（物理隔离散人 ＋ 专治低人口空城）

- **时间与地图锚点**：完全复用 [world-map-play-v2.md §2.2.2](world-map-play-v2.md#222-全服双层潮汐聚人机制) 与 `go/scene_manager/internal/logic/world_map_overview.go` 的墙钟确定性 `WorldTideSnapshot`（每 60 分钟轮换 1 张野外图、持续 40 分钟）。
- **分线模式隔离与溢出策略**：
  - `SceneChannelInfo` 扩展只读分线模式枚举 `SceneChannelMode`：`CHANNEL_MODE_PEACEFUL = 0`（默认和平线，现有全部 1 线及自动扩容线均为此值）与 `CHANNEL_MODE_JIEHUO_PK = 1`（灵潮劫火线）。
  - 每次灵潮开启时，`scene_manager` 在当期灵潮野外图挂出 **1 条「劫火线」**（仅当单线满员如 200 人时允许按需溢出第 2 条；独立不参与普通 Fill-First 自动选线，默认进图与自动切线**100% 永远只路由至和平线**）。
  - 玩家（或小队由队长发起、全员各自完成二次确认后整队切入）必须手动点选「进入劫火线」并确认风险弹窗（明示允许主动劫战、红名落败进思过崖、不掉身上装备与 660 核心材料）方可切入。
  - **防打完瞬移与绕过拦截（严堵 V-8）**：
    - 劫火线安全区（传送阵 15m）外，**无论何时回和平线或主城均须脱战站立 10 秒读条**（读条期间可被劫战打断）；进线后或每次主动劫战/终局后挂/刷新 **5 分钟退出冷静锁**，冷静锁内禁点“快捷回城”按钮，必须走到传送阵安全区或等冷静锁满后再读条撤离；
    - 劫火线内**全局禁止报名任何匹配/会武、禁止发起/接受生死状、禁止一键跨图传神秘商人或跨区传送**，防止借外部入口绕过读条瞬移脱身；
    - 灵潮 40 分钟结束时由 `scene_manager` 给 **60 秒清场倒计时**（期间禁新开劫战），**尚未打完的劫火战允许自然打完**，终局后统一回送和平线/主城。
- **劫火线吸引力、临时「劫火灵砂」与经济红线**：
  - 线内 2–3 个固定地标 `WorldPoi` 刷出「**劫火灵匣 / 灵砂泉**」，采用**共享触点＋10 秒采集读条（读条可被敌方劫战直接打断）**，完全复用 [world-map-play-v2.md](world-map-play-v2.md) 无状态 `WorldPoi` 底座、不改造成有状态抢点库存；核心抢夺发生在采集打断与携砂回城路上的小团体截杀（胜方抢走败方 30% 临时灵砂）；
  - 玩家携砂安全撤离回和平线或熬过本轮灵潮后自动按 1:1 结算为**少量银两 ＋ 绑定「重铸砂」＋「江湖侠义/枭雄外观印记」**；
  - **跨角色账号级周软上限**：按 `account_id` 独立记账周软上限（到达后不再因采集或抢夺新增结算收益，仍可正常入线打架），**0 产出 660 核心材料、0 产出可交易装备/材料**；
  - **边界态处置**：携砂期间**强退下线直至灵潮结束**，临时灵砂**清空作废**（防掉线白嫖保砂）；白/黄名战败掉 30% 给胜方、保留 70%；红名战败被押送思过崖时，30% 转给胜方、**剩余 70% 随押送没收销毁**。

#### (2) 劫火线主动劫战（小团体 / 帮派混战的回合制落地）

- **无需目标同意即可开战**：在劫火线安全区（传送阵 15m 半径）外，单人或 2–5 人小队靠近另一名未在战斗中、未处于安全区且无「免劫护盾」的目标（单人或整支小队，权威距离 `<= interact_range`），可发起「**劫火切磋**」。
- **服务端权威开局与快照隔离**：`scene` 校验双方均在同条活跃劫火线、距离合法、目标无保护罩、均未被其它匹配/战斗占用 → 调用 `go/match` 直接以 **`MATCH_MODE_JIANGHU_BRAWL`** 开局（支持不等人数如 3V1、5V3，沿用 `isolateBattleTempState = true` 满血蓝开局、禁背包药、不回写血蓝，`SPECTATE_VISIBILITY_PUBLIC`，回合/时限打满权威判平，路人点击头顶“劫战中”即可一键观战）。
- **四重防恶心护栏（防止把核心 PVP 玩家也逼退游）**：
  1. **零装备/背包掉落**：身上八部位装、法宝、宝宝与背包原件 **100% 永不掉落、永不损耐久**；战败仅把本轮劫火线内临时携带的「劫火灵砂」按 **30%** 转移给胜方（不碰其他任何资产）；
  2. **回合制合法遁走（算安全脱身，按个人终态独立结算）**：`MATCH_MODE_JIANGHU_BRAWL` 开启战斗内「撤离/遁走」行动（第 2 回合起可用，受速度对比决定基础脱逃率，被控回合不可遁走；**处于悬赏在榜的红名大幅降低遁走成功率**，防止红名靠秒逃无敌）。战斗结算显式按个人终态区分 `ESCAPED`（安全遁走）与 `DEFEATED`（战败阵亡）：**成功遁走者不掉 30% 劫火灵砂、不给先手方加煞气、红名不进思过崖、悬赏不结案，脱战后直接传回当前劫火线传送阵 15m 安全区并获 60 秒短保护**；多人局中未逃走而阵亡的队友仍按个人终态正常结算掉砂/煞气/入崖/结赏；
  3. **15 分钟防恶意守尸护盾＋堵死“带盾小号护航”**：非红名在劫火线战败后在**本线传送阵 15m 安全区复活**并获 **15 分钟「免劫护盾」**；若小队中混有持盾成员，**敌方对队内任意无盾且在安全区外的成员发起劫战时，整支同线在安全区外的小队一并拉入战斗且持盾成员自动破盾**（小队主动先手发起劫战同样立刻破盾；留在 15m 安全区内的队友不随队参战）；
  4. **帮派 24h 双向宣战免煞气**：两帮帮主/长老双方确认开启「帮派宣战」（邀约有效期 24h、宣战持续 24h、0 道具资金消耗、单帮最多同时对 **3 帮**宣战、按两帮配对 `(min_guild, max_guild)` 独立冷却 72h、须双方管理同意方可提前停战）；宣战期间在劫火线互殴**按个人帮会归属逐人豁免煞气**（仅两宣战帮会正式成员免煞气，混编外援散人照常按白名规则计算）。

#### (3) 煞气值（红名）与「思过崖」面壁闭环

| 状态档位 | 煞气区间 | 视觉与机制影响 |
|---|---|---|
| **清白（白名）** | `0–19` | 正常状态；劫火线内战败不进思过崖 |
| **染煞（黄名）** | `20–59` | 劫火线内显淡赤剑气；可被受害者挂铜/银悬赏；在线/离线每 10 分钟自然消退 5 点 |

- **「思过崖」面壁机制（零重型 AI、遵循不肝红线）**：
  - 复用 1 张小体量独立静态导航场景（标记 `scene_kind = PENITENCE`），无复杂刷怪逻辑；
  - 面壁时长按入崖煞气计算：`10 分钟 + (煞气 - 60) × 0.5 分钟`，**硬上限 30 分钟**；**计时起点为角色首次落入思过崖时刻**（防止红名断线托管战败后直接等 30 分钟上线完全逃避进崖），入崖之后采用**自然墙钟倒计时（离线照常计，绝不逼玩家亮屏挂机）**；
  - **出崖煞气统一清零**：无论通过自然期满、静心石碑、银两减半还是清心保释文书出崖，**离开思过崖时煞气统一重置为 `0`**，杜绝 100 煞气出崖仍红名陷入反复进崖死循环；
  - **面壁期间限制矩阵**：
    - **拦截**：切往野外、报名匹配/会武/锦标赛、帮会同道历练、发起或接收生死状、新上架摆摊或集市挂单（**不强制下架已挂出的合法离线摊位**）；
    - **放行**：商城购买与使用「清心保释文书」、收发邮件、聊天、全服观战（`WatchBattle`）、灵宠翻牌与思过崖内交互；
  - **三条减刑/提前出崖路径**（既照顾零氪，又承接灵潮热战中的高频小额刚需）：
    1. **免费静心减刑**：点击思过崖 `WorldPoi`「静心石碑」完成轻量 60 秒读条静思，每次减刑 **5 分钟**（每次入崖限 2 次，零氪最快几分钟出崖）；
    2. **银两保释减半**：消耗 **1,500 银两**（100% 销毁）减免剩余 50% 时长（每次入崖限 1 次）；
    3. **官方「清心保释文书」**：官方商城绑定直售（参考 **30 灵石 = ¥3**），立刻结束面壁并清零当前煞气，重返劫火线续战；**防无惩罚连杀约束**：24 小时内使用第 1 次立刻清零，第 2 次起仅减刑 50% 且 24 小时上限 2 次，防止大户买断免疫恶意清场。

## 3. 思想分析

1. **为什么“先 A 后 C”而不是一步做“全图野外红名（方案 B）”？**  
   独立 MMO 最大的天敌不是“功能少”，而是**开发周期拖长 + 开服低人口空间稀释**。方案 A 复用率超过 80%（切磋管线、公开分级观战、战报回放、系统播报、西北双擂台全现成），能在极短工期内交付“有脸有仇、全服吃瓜、约架打脸、小额变现”的完整情绪闭环；而当二期在线达标时，用方案 C 把好战者锁进每小时 40 分钟的「灵潮劫火线」而不是撒到全图，能把 20 个好战玩家压缩出 200 人大服的热闹感，同时让和平 1 线 100% 干净。
2. **为什么悬赏和生死状“绝不碰自由银两转移”？**  
   一旦允许 A 给 B 挂 50 万银两悬赏或赌 50 万银两打生死状，玩家交易风控就形同虚设——骗子和工作室会立刻拿擂台/悬赏当“0 税秒到银两转账通道”，直接把我们在 [equipment-economy-charter.md](equipment-economy-charter.md) 辛辛苦苦建的当面防骗与 5% 集市税全部击穿。改成**固定低额银两全销毁（或官方灵石金令）＋ 捕快主拿不可交易义士外观积分**，既保住了江湖恩怨的面子与爽感，又给游戏增加了一条健康的银两回收池。
3. **为什么“思过崖”必须允许离线自然倒计时，而不是强制亮屏挂机？**  
   核心原则是“**用时间差收急切玩家的便利小钱，绝不用折磨人的惩罚赶走免费玩家**”。离线照常走表、上限 30 分钟，保证零氪或休闲玩家被关了也不会气到卸载；而正在 40 分钟灵潮劫火线里和仇人打得上头的玩家，最不想错过眼下这场团战，花 ¥3 买「清心保释文书」立刻重返战场是心甘情愿、极高转化的消费。
4. **为什么全服播报必须放在“双方同意成局之后”，而不是“单方面发帖之时”？**  
   如果单方面发战书就能全服喊话“XXX 敢不敢来打，不敢就是孙子”，就会瞬间沦为低成本全服骚扰、网暴甚至广告喇叭工具，迫使个人开发者天天人工删帖封号。把播报门禁锁在**双方同意应战且扣费成局之后**，全服看到的永远是你情我愿的热闹约战，既爽又零客服纠纷。

## 7. 设计评审已拍板项与默认工程建议清单（供终审核对）

### 7.1 负责人已明确拍板的核心边界
1. **总体红线与分期**：严守 [project-vision.md](project-vision.md)（不逼氪、免费 100% 同战力上限、不波及和平散人）；采用「一期方案 A（生死状＋恩怨录＋帮派墙）→ 二期按在线达标开关启用方案 C（灵潮劫火线＋红名悬赏＋思过崖）」。
2. **一期极简范围**：帮派约战靠纯同帮小队打常规生死状自动入帮派墙（不另做帮派管理宣战帖审批）；普通战书直接扣 500 银两不占背包格；永久买断「擂台入场/胜者特效包」后置为外观拓展，不占一期 M1–M3 工期。
3. **二期劫火战「遁走」语义**：按个人终态独立结算，遁走成功算**安全脱身**（不掉 30% 灵砂、红名不进思过崖、不结悬赏，传回本线传送阵安全区给 60 秒短保护；在榜红名大幅降低遁走率防无敌秒逃）。
4. **二期劫火灵匣/灵砂泉机制**：复用无状态 `WorldPoi`，采用**共享触点＋10 秒采集读条可被劫战打断**，核心争夺发生在打断采集与回城路上截杀抢 30% 灵砂。

### 7.2 结合仓库架构替你先收口的工程默认项（审阅时可随时微调）
- **零吞货扣费**：小队生死状由发起方队长单人出资，采用现役 `PlayerItemHoldComp` 备战冻结、开打实扣；建房失败或中途 `BATTLE_OUTCOME_VOID`/零回合异常中止一律释放或经 `mail` 幂等退还。
- **区服、确认与防骚扰**：同归属区（含合服组）远程随时约战；小队约战须双方全员本人确认；全员两两拉黑拦截＋目标全员免战拦截（开免战者同时禁止主动发帖，好友可绕过免战）。
- **个人恩怨录防冲爆**：`1V1` 双方互记，多对多小队局个人恩怨录仅记双方队长（1 对 1），防止打几场 5V5 冲爆 50 人上限。
- **缉拿唯一场景与奖池防印钞**：绝不在和平主城/和平野外强开缉拿、也不在生死状 `DUEL` 中触发领赏入崖；仅劫火线 `BRAWL` 击败在榜目标自动结案（零额外捕快接单状态机），单张悬赏总奖池按胜方合法人数均分（永不超发），胜方任一成员命中五重防刷即整队 0 赏金（允许发布者叫自己同帮/好友替其复仇领赏）。
- **煞气、思过崖与防绕过**：先手主动打含白名防守队每场至多结算 1 次煞气（均势/少打多 `+20`、多打少 `+30`）；敌方对队内无盾成员发起劫战时安全区外整队拉入且持盾队友破盾（堵死带盾小号护航）；红名在思过崖外不离线衰减，面壁计时从首次落崖起算、离线照常走表、出崖煞气统一清 `0`；劫火线内安全区外撤离永远需 10 秒读条且全局拦截外部匹配/跨图传送，携砂强退至灵潮结束灵砂清零、红名入崖没收剩余 70% 临时灵砂；二期帮派双向宣战单帮最多同时宣 3 帮、按两帮配对 72h 冷却、混编小队按个人帮会逐人免煞气。
