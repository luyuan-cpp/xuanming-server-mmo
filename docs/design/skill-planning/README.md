## 2. 来源和确定程度

- **已定**：用户明确提出、纠正或确认的要求，见下一节。不能用先前助手建议覆盖。
- **保留原型**：用户要求保留前述技能方案，因此保留其效果方向；没有逐项拍板的倍率、冷却、消耗、触发概率等仍是草案。
- **建议/待定**：助手提出的时序、保护窗口、触发限次、复制范围等，写入以便评审，不能宣称已经确认或已经实现。
- **首测采用**：2026-11-17用户授权将完整69项及既有建议落为可调配置，首测采用值统一见[首测参数](first-test-parameters.md)。采用供测试不等于最终平衡定案；候选S/SP/E和技能以外未定系统不因此开放。
- 任何旧建议与用户最新修正冲突，以本页已定规则和公用规则为准。已有实现文档描述旧版本事实，不等于新策划已经落表。

## 3. 已确定的规则

1. 技能可以大量收集、自由搭配，人物技能不按职业锁死。保留人物、队友、宝宝之间的配合。
2. 目标计数包括人物和宝宝；五人物加五宝宝是十个单位。相同单位不能重复计数。
3. 人物横戈裂岳、紫霄雷阵均最多攻击敌方 **5** 个。人物天崩裂岳、九霄归墟也均为敌方 **5** 个，分别是物理、法术群体爆发。物法以同档次预算做平衡；宝宝物法攻击按第19条。
4. 人物封法、封物、中毒、混乱最多作用敌方 **5** 个；人物昏睡、冰冻最多敌方 **7** 个，控制成功数量受逐目标情况影响。宝宝蚀骨毒最多敌2。
5. 本项目**没有道行或武学系统**。控制命中和抵抗使用条目；不引入原作道行差公式。
6. 人物常规辅助、清除友方有害、清除敌方有益效果按 **7** 个目标整理；宝宝辅助按对应阵营 **1** 个。特殊的自身资源转换保留只作用自己的机制。
7. **同一施法主体类别内，同效果只保留目标数最多的版本**。人物与宝宝可以共享原型，但不再强求人数相同；按第19条区分施法者上限。保留合并编号，不为主体目标数差异恢复重复原型。
8. 碎甲与爆发分开行动，可由不同队友、人物与宝宝接力。原状态不能被写成只允许施法者自己消费。
9. 加速、减速从下一回合排速生效，不改本回合已排好的顺序。
10. 同名中毒不无限叠加：同目标一份，同强度刷新时长，更强覆盖。弱毒不覆盖强毒是配套建议。
11. 防御增益持续 **5 回合**：原 A13 赤甲镇关已并入目标更多的 A14 灵鼎护元，五回合要求一并继承。A25 战意昂扬的物伤/法伤增益持续 **5 回合**。
12. A35 断脉咒：敌方 **5** 个，减疗持续 **5 回合**，本身不禁止复活。
13. A26 生生不息：人物施放最多 **7** 个友方，宝宝施放 **1** 个友方，回生印持续最多五次回合末结算；**复活后消耗该目标整份回生印，包括剩余回血效果**。重新施加新印记后可以再次复活；其他目标的印记不受影响。原“每单位每场只能复活一次”限制已经作废。
14. A38 冰封玄狱：敌方最多 **7** 个；中招者无法行动，不能受到伤害或再被施加其他障碍。不可套用“受伤唤醒”的睡眠规则。
15. 物理反击、法术反击为两类被动：受到对应攻击时，**使用自己的属性释放回去相同的技能，反击本身不耗蓝**。P09 反戈一击承接物理反击，新增 P19 法术反击；不能退化成普通反伤或固定普攻。
16. A03 戈鸣断势保留：物理攻击敌方最多 **5** 个并降低物理攻击，降攻持续 **5 回合**。需与A02常规群攻、A39群体爆发保持各自价值；倍率、降攻比例、耗蓝和冷却尚未定值。
17. A23 乱心惑神最多对敌方 **5** 个施加混乱；每个中招者行动时，只能以物理或法术攻击自己随机 **1** 名存活队友，按所用攻击正常耗蓝，不能对队友释放多目标攻击。持续时长、攻击选择和法力不足处理仍待定。
18. A20 封灵咒改为敌方最多 **5** 个，逐目标判定，保留限制所有主动技能的方向。原“1次目标行动”仅为时长建议；命中、持续时间、耗蓝、冷却需与A21封法、A22封物分别平衡，不保留旧单目标版本。
19. **宝宝辅助一律对应阵营单体，物理/法术攻击技能最多敌方2个。** 辅助包括治疗、保护、增益、净化、驱散、纯减益、削蓝、劝退和开场保护；自身效果仍只作用自身，劝退仍只选敌宠。含直接攻击的碎甲击、摄魂汲血按两目标攻击，**蚀骨毒也已明确按持续攻击作用最多2敌**。该规则覆盖旧“人物与宝宝共享相同目标数”的要求；人物目标不变，普通攻击、混乱单队友和反弹返给来袭者不随之扩散。
20. **宝宝有“主动攻击／障碍／辅助”三个手动技能分类入口，已学且允许该宝宝使用的技能都能从对应分类选择，每回合合计最多释放一招。** 这是分类入口，不是只能装备三招；此前“2个主动装配槽”的要求由本次明确澄清覆盖。技能持有数量不受入口数限制，已学可选也不等于任何宝宝都能学习所有技能。被动另计，追击/开场的生效资格、是否需装配及数量仍待定。
21. **现有需要玩家指定目标的手动技能，默认“主目标指定，其余随机”。** 合法主目标占1个名额，剩余位置从对应阵营合法单位中随机、不重复补齐；不采用忽略点选目标的全随机模式。障碍选中目标后仍逐个按条目判定，主目标不保证成功。新策略技能按独立候选记录，尚未加入现有目录或改变旧技能目标上限；固定自身、混乱、追击和开场等按各自规则。

22. **宝宝输出、障碍、治疗、护盾共用一份条目点预算，替代原自选条目加成，不额外赠送障碍或辅助点池。** 条目分配、资质与基础四维共同形成物攻、法攻、封控、辅助或混合方向，不额外叠旧四专长奖励。战外调整、战内锁定，同条件同投入按配置产生确定收益，不随机洗数值、不做专门任务或刷材料升级。总点数、每点收益、单项上限、具体目录与发放细节仍待定；4条、1固有＋3自选、10点6＋4均不作为定案。允许小额付费但商业化未定，此确认不扩大技能学习资格或确定被动数量，详见[宝宝条目点策划](pet-specialties.md)。

23. **人物护盾A40是独立主动技能，友方最多7目标，治疗过量不转成护盾。** 人物和宝宝均计入目标，主目标指定、其余随机；正常施放单独占用行动，不在治疗后免费自动触发。撤回P11余泽成盾，不开放宝宝专属护罩给人物。首测建议为同档普通治疗基础量80%的独立容量、持续2回合、最大法力8%、CD3；仅独立施放与七目标已定，名称、容量公式和上述数值/伤害标签/覆盖/驱散仍是待评审方案，详见[人物主动3.2](active-character.md#32-a40七目标护盾首轮平衡方案)。

24. **人物和宝宝保留体质、灵力、力量、敏捷四维基础加点，人物靠装备词条，宝宝靠自身条目点分配结果。** 不采用神识／慧心六维方案，不新增宝宝装备或继承主人装备词条。宝宝条目点按第22条替代原自选加成，不挪用四维点或给人物增加同类点池。合法被动与临时状态仍按技能规则保留、分别标来源且不重复结算。具体分配目录、收益、预算和上限契约仍待定，见[条目策划](pet-specialties.md)与[宝宝 UI 交接](pet-entries-ui.md)；人物装备以[八部位策划](../equipment-eight-slot-planning.md)及其V1数值入口为准。

### 4.2 保留与合并的判断

撤回记录：P11余泽成盾不再作为有效被动或自动产盾入口；A40是独立主动护盾，不继承其过量治疗触发机制。两者不是同一个技能的改名。

同一主体类别内，仅名称、人数、基本倍率或资源数值不同，不作为另造小目标版本的理由。人物与宝宝的同原型参数可以不同，按各自目标规则配置，不增加学习原型计数。具有不同触发条件、状态联动、行动限制或特殊资源转换的技能可以保留，例如碎梦的睡眠条件、趁隙的破防条件、封灵与仅封法/封物的范围区别。

人物常规五目标群攻与五目标爆发均保留，是用户明确要求的一组物法对应方案。宝宝已开放的攻击原型按最多两目标，不能因人物有该技能就自动开放给宝宝。触发类别不同的主动、被动、追击、开场不能仅因都“加防”就互相删除。

用户本次明确要求把策略选人招式作为独立新技能并标待定，按[策略候选页](strategy-skills.md)单独保留。该批不因目标数较少而被旧归并规则删去，也不折回旧技能的模式开关；后续评审各自价值和数值后再决定进入基础目录的条目。

## 5. 装配规则与获取、成长草案

**技能获取与付费边界已确认（2026-11-17）**：免费玩家和付费玩家最终都能永久获得其主体允许学习的全部技能；同一技能的效果与培养上限一致，付费仅加快解锁进度，不设付费专属技能、付费强化版本或充值限定的最终解锁资格。“全部”不改变人物与宝宝的学习资格，也不改变生效/装配和每回合行动规则。

每项正式开放技能都须有实际可完成的非付费永久获取路径，不能以临时试用、对战复制或极低概率中奖代替最终可得。具体材料、产出、解锁成本、免费全收集时间及价格尚待核算，须符合“不肝、不要太氪”；本条不批准收费项目或重置已学技能。付费提前扩大技能选择仍可能影响未收集齐时的对局，赛季竞技条件另按赛季方案确定，不能把最终同上限当作全阶段已经公平。

“主动”指需要手动选择释放的技能，包含攻击、障碍、治疗和辅助。宝宝界面中的“主动攻击”是攻击类别名称，不把障碍、辅助排除在手动技能之外。“战法槽”是前期对被动、追击、开场共用自动触发装配位的叫法，不是每种各给两个。

| 主体 | 手动技能组织方式 | 自动触发类技能 | 确定程度 |
|---|---|---|---|
| 人物 | 建议4个手动装配槽，攻击/障碍/治疗/辅助从中选择 | 建议2个共享战法槽，供被动/追击/开场选择 | 4＋2均为草案，用户尚未确认 |
| 宝宝 | 主动攻击／障碍／辅助3个分类入口；已学且有使用资格的手动技能均可选，无2或3招装配上限；每回合合计最多一招 | 被动另计；被动/追击/开场是否需装配、如何生效、数量均待定 | 三分类与每回合一招已定；旧2战法仅为未采用建议 |

宝宝辅助单体、物法攻击及蚀骨毒最多敌2继续适用。分类入口数、持有量、每回合行动次数和技能目标数分别定义。普通攻击、防御等基础操作不因分类入口增加而多出行动。

宝宝统一条目点替代旧自选加成按第22条、四维和来源分工按第24条确认。具体方向、总点数、每点收益、单项上限、配置和存档仍待定，不保留旧固定选择数量作为另一份加成。五档名称候选普通→变异→灵兽→神兽→圣兽，以及同点数／同上限、固有特色的具体做法仍待评审，见[宝宝条目点策划](pet-specialties.md)。已学可选不自动放开所有技能，也不新增手动装配上限。

以下仍为建议，尚未确认；涉及获取和成长时须服从用户“不专门做任务、不要太肝、可以小氪”的要求：

- 人物普通攻击、防御、道具不占上述4个手动技能槽；人物最终装配数量仍待讨论。
- 战斗外自由换装，进战斗锁定快照，建议保存三套搭配。
- 新手直接拿到完整基础技能搭配。PvP/PvE资源兑换与困难PvE加量仍是具体获取候选，不能默认成为必须刷的成型门槛；技能最终可免费全量解锁已定，材料产出与兑换细节待核算，宝宝条目不采用刷材料培养。
- 已学永久保留按本节已确认边界执行；**2026-11-24 已定永久技能制书与率土式保值口径**（详见 [equipment-quality-and-skill-crafting-v1.md](../equipment-quality-and-skill-crafting-v1.md)）：常驻永久技能（`season_id = 0`）按主题卷宗（`scroll_id`）分池防稀释、90% 常规残页拓印（80% 拆页回收）+ 每批硬锁 ≤ 10% 稀世绝学（玩法可交易绝学残卷 + 绑定天工秘墨定向合成，绝不抽卡、绝不顶掉已学技能）；同步新增 3 个 5 层封顶的率土式每回合叠加至战斗结束常青成长被动（愈战愈勇 / 深谋远虑 / 步步为营），不把这套流程套到宝宝条目。
- 本次技能策划不重算之前的强化/打造/宝宝洗练经济方案，也不据此新增付费技能抽取系统。
