# 技能实施清单与现状

[返回技能策划总表](README.md) · [共用战斗规则](combat-rules.md)

本文为服务端实施准备。现状来自 C++ 服务端源码、协议与配表结构的静态核对，未进行运行验证。A、B、P、T 和 O 系列是策划引用编号，正式表 ID 需在实施时分配。现按总表的 69 个有效原型排期，旧版 83 个编号用于查找合并去向，分阶段决定上线范围。本文的新技能规格及目标数尚未落入正式配置表。独立 Java 游戏服的本套技能尚未落码，本轮未改独立 Java 仓库。

最新修正：撤回 P11 过量治疗转盾，旧号仅留撤回记录；新增人物主动 A40 独立护盾（名称待定）。人物主动34项、宝宝专属主动11项、被动16项、追击5项、开场3项，合计仍69项。治疗与护盾分别选技能、分别消耗正常行动；A40友方最多7目标已定，人物和宝宝均可受益；容量与资源等采用人物主动3.2的首测建议，未定案或落码，不开放宝宝 B05／B06 给人物。

[策略新技能](strategy-skills.md)的14个人物与2个宝宝候选全部待定，不进入本轮实施；[率土式候选](stzb-inspired.md)8项暂缓，等用户研究具体机制后再讨论。不能把候选人数或效果直接写入基础技能表。

[宝宝条目点与轻量培养](pet-specialties.md)最新确认：基础四维不变，人物专项来自装备，宝宝的输出、障碍、治疗、护盾共用一份条目点预算，替代原自选条目加成，不另赠辅助／障碍池。宝宝不新增神识／慧心或装备，不继承主人装备词条，不叠旧四专长奖励。战外调整／战内锁定、不做专门任务、不刷材料升级或随机洗数值的边界保留；总点数、每点收益、单项上限、具体目录与发放细节待定，4条、1固有＋3自选、10点6＋4不作为正式参数。允许小额付费但具体方案未定。本轮不改代码或公式。

## 现状与施工边界

人物属性、加点与辅助技能界面可先按[UI交接建议稿](character-support-ui.md)接已有接口及隔离演示数据。现版治疗仍读取法攻，现代技能按最大法力比例耗蓝；新独立治疗关系尚未确认，不得仅改UI文案就视为后端完成。当前没有任意加点草稿的精确派生属性／治疗／护盾预览接口。

宝宝制作按[条目点 UI 交接](pet-entries-ui.md)推进：复用现有四维、资质和技能展示，新页显示统一预算的总量／已用／剩余、各项投入与全量分配草稿。新目录、分配保存、每项上限、版本、来源汇总与精确预览须补正式契约。`PetInfo.total_points`／`remaining_points` 与 `AllocatePetPoints` 属原四维，不得挪作条目池；`aptitude`、`skill_table_ids` 也不得代存。不能把未支持数据当0或用客户端推算冒充权威效果。人物装备按[八部位策划](../equipment-eight-slot-planning.md)及[装备V1目录](../equipment-v1-affixes-artifacts.md)推进，不新增人物条目点。

## 建议实施顺序

正式战斗接入前先确定条目点目录、总预算、各项上限和收益曲线，落实“人物装备／宝宝自身统一分配”的存档与快照契约。界面框架可先做，未确认项保持可配置；新专项点替代旧自选收益，不增加基础维度或额外障碍／辅助池。五档候选与固有特色只保留设计状态，不先改品质枚举或旧存档。

1. **公共池与技能资格。** 宝宝使用主动攻击／障碍／辅助三个分类入口，每回合从所有合法已学手动技能中择一。持有、学习资格、分类和行动可用性分别记录，不加入2或3招手动装配上限；人物4手动加2战法仍为草案，宝宝自动效果是否装配及数量另定。验证现有职业学习、默认技能、宠物自带技能及存档仍能进入正常对局。
2. **基础效果。** 按有效原型接入物法攻击、治疗、属性增减、耗蓝、冷却；常驻被动按确认后的生效资格接入，宝宝是否装配及生效数量仍待定。同效果在同一主体类别内去重，人物/宝宝共享原型但按施法者读取目标参数，合并编号按总表归集。先用既有结算能力验证选目标、耗蓝、事件、回放及 PvE／PvP 数值分流。
3. **状态与净化。** 实施逐目标封印、睡眠唤醒、毒、混乱、抗性映射、净化和抗性展示。一起验证异常可互相影响的时序。
4. **回生印与独立护盾／护罩。** A40目标上限7已定；先收口容量等试值、造成实际伤害的判定，再接其独立主动施放、护盾状态、宝宝类型护罩、死亡后标记、复活、战斗结算及回放。不实现已撤回的 P11 过量转盾；治疗与 A40 分别消耗行动，护盾容量独立于气血记录。确认重上新印可在同一场再次复活。
5. **追击、镜像与开场。** 实施触发阶段、递归限制和记录格式。P09 与 P19 在复制边界确认之后开始实现，不依赖反震或普通反击去推导技能回放。

## 落表前核对参数

- **技能免费与付费最终一致（已确认，待实现）。** 对每个正式开放、主体可学的技能登记可完成的非付费永久解锁路径；付费只提前解锁，效果与培养上限相同，不增加专属技能或最终资格。获取材料、成本、全收集用时与定价待核算，临时复制/试用不替代永久获取。验收免费与付费来源生成相同技能身份和同等级战斗参数、都能达到相同上限，且不改变主体资格、装配规则或行动次数。最终可全收集不代表收集途中竞技条件相同，相关赛季规则另定；本次不修改普通耗蓝规则或批准免蓝模式/复制技能的具体实现。
- **宝宝分类与行动已定。** 三个入口为主动攻击／障碍／辅助，每类可列多招已学且主体资格合法的手动技能；每回合跨类别合计只选择一招。普通攻击/防御等动作不能与手动技能额外并用。分类归属不改变独立的攻击两目标/辅助单体规则；混合技能的展示分类需配表明确。被动、追击、开场不占三个入口，生效资格、是否装配和数量待定。
- **人物已定目标与持续时间。** 人物施放A10群体即时治疗、A12残血急救、A14灵鼎护元、A25物法增伤、A33净化、A36援护和A40独立护盾为友方最多7目标，A34驱散为敌方最多7目标。A03戈鸣断势保留、敌方最多5目标、降物攻持续5回合。A14继承合并前A13赤甲镇关的5回合，A25持续5回合，A35断脉为敌方最多5目标、持续5回合。宝宝共享技能的人数另按下一条，原已定时长不因人数而改变。
- **宝宝已定目标。** 友方/敌方辅助各单体：共享治疗、增益、回生印、净化、驱散及B05/B06/B07/B08/B11/B14/B16、O03；劝退B09仅敌宠1，削蓝B13敌1，B15只自身。物法攻击A02/A06/A18/B12及持续攻击A19最多敌2。宝宝T01/T06伤害追击采用敌2上限，具体第二目标和触发次数待定，T05纯破甲仍原命中敌1；人物T01原目标规则不变。人物/宝宝目标差异不是新增技能或开放未授权学习范围的理由。
- **混乱行动。** A23施加混乱最多敌5；每个中招者只能以物理或法术攻击自己的随机1名存活队友，按所用攻击正常耗蓝，不能群伤。物法及具体攻击的选择、法力不足、无合法队友、与其他封锁的优先级、持续时长仍需确认。
- **封灵目标与限制。** A20封灵咒改为敌方最多5目标，逐目标判定，保留限制所有主动技能的方向。原单目标版本不再使用；持续时长及普攻、防御、道具、被动/追击/反击边界另行确认。
- **治疗分工。** A10常规即时、A12残血急救、A26持续恢复与复苏的具体治疗量、阈值、耗蓝、冷却尚未定。按人物主动页3.1节评审收益与代价，不能把机制分工当成已经达到平衡的证据。
- **独立人物护盾。** A40友方最多7目标已定，名称及正式数值仍待定。首测建议见[人物主动3.2](active-character.md#32-a40七目标护盾首轮平衡方案)：同档普通治疗基础量80%作为配表标尺、每目标独立容量、2回合、最大法力8%、CD3；伤害标签、覆盖、驱散与死亡后处理均为草案。运行时容量独立于治疗和过量治疗，不能沿用治疗结果。人物等级、技能等级、护罩容量条目参与的计算关系仍是建议，治疗的新公式也未确认；A35 减疗不自动变为减盾。
- **分类、资格与目标。** 以施法者是人物还是宝宝决定人数，不能按受益者类型决定。宝宝直接攻击附带破甲或吸血不再拆出一组辅助目标，蚀骨毒明确按两目标持续攻击；反弹只返给该次来袭者，B16自我牺牲不占第二个救助目标。人物已确定的常规辅助及O01/O02仍七目标，A40也为友方最多7目标，A15／B15自身资源转换只作用施法者。落表前逐项核对装配资格、第二目标补位、宠物和尸体能否入选，以及PvE／PvP差异。
- **现有技能默认补选已定。** 玩家手动指定合法主目标后保留该目标，余位随机、不重复选取其他合法单位；人物五/七目标对应主目标加最多4/6个，宝宝攻击两目标对应主目标加最多1个，宝宝单体辅助无副目标。主目标失效、随机选取时点和自动战斗主目标规则仍待定。S/SP为独立策略新技能候选，未进入当前默认规则；将来确认后按各招专门选取。固定自身、混乱、被动、追击、开场不套手选规则。
- **消耗与时钟。** 逐项确认耗蓝规则、冷却回合与开始时点，以及持续状态的施放回合是否计入、最后一次效果的结算相位。
- **数值与异常属性。** 逐项确认基础概率、上下限、是否逐目标、伤害和治疗按哪项属性、暴击或闪避、重数成长。人物异常抗性和忽视等按适用装备词条，宝宝按自身条目；合法被动／临时状态单列，不把主人装备聚合值当宝宝条目。核实封法／封物对应字段、冰冻与旧毒的处理口径、睡眠是否被周期伤害唤醒，以及旧词条的展示与实际效果是否一致。
- **持续、消耗与状态优先级。** 确认同类覆盖、互斥、叠层、刷新、净化顺序及死亡保留。核对回生印贴尸体的时序、拉起血量和重上新印条件。核对护罩全吸收后，睡眠、追击和受击被动是否分别触发。
