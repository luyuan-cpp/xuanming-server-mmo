# 人物主动技能策划

更新：2026-11-17。返回 [总览与合并对照](README.md)。本页有效 **34** 项，原编号保留跳号；本页目标栏是人物施放规格，宝宝共享原型的目标数见[宝宝主动](active-pet.md)。

## 1. 阅读口径

目标栏都是“最多”，被选目标可以是人物和宝宝，不能把受益者是宝宝误当作宝宝施法。已明确的五/七目标、五回合、条目控制、复活消耗按用户最新要求；没有标为已定的具体倍率、耗蓝、冷却和次数是待定参数。人物普通辅助按七目标；宝宝施放辅助仅单体，物法攻击及蚀骨毒最多敌2。特殊条件攻击不因“也是攻击”就自动删掉其联动机制。

本页仅列当前有效技能。已合并的 A01/A04/A05/A09/A11/A13 见总览，不继续配置成独立技能。

治疗／护盾属性、辅助加点与界面制作见[人物辅助与 UI 交接建议稿](character-support-ui.md)。该页区分现版法攻相关治疗与新的独立治疗条目建议，不改变本页已定人数，也不表示新公式、人物全部已学可选或4＋2装配已确认。

### 3.1 三种治疗的平衡待定项

用户指出A10/A12/A26的收益差距。**目前仅有机制分工，尚无数值平衡结论**；三招均保留友方最多7目标，A26的五次回合末结算、复活消耗整印及重挂可再复活规则不变。

- **A10常规补血（建议）**：稳定的即时治疗，以较低耗蓝或较短冷却承担平时维持血线的任务。
- **A12残血急救（建议）**：非残血治疗低于A10，残血治疗高于A10；也可通过耗蓝或冷却增加救急的代价。阈值逐目标判断，不能因一名队友残血就给七人全员额外治疗。具体方案、阈值与数值待定；不能同时照搬A10的基础治疗和成本，再免费增加残血收益。
- **A26持续恢复与复苏**：回血分散在回合末，不能把五次总量当作施法时一次到账。建议单次回血低于即时治疗，并以耗蓝、冷却约束续印能力；具体数值、首次回血和复活时点待定。核算实际已生效的回血与复活价值；一旦该目标复活，未结算的剩余回血立即失效，不能把五次满额回血与复活同时计成必得收益。

验收比较持续磨血、群体爆发后的救急、持印倒地三类场景，以及多人交替补血/续印。记录有效回血、过量治疗、耗蓝、行动占用和复活后的存活情况，要求各招有适用场景。若A12最终仍只是同条件下更强的普通治疗，应按同效果去重原则重新评估合并，而不是只靠改名字保留。

### 3.2 A40七目标护盾：首轮平衡方案

**用户已确认**：人物A40作用于友方最多7个单位，人物和宝宝均计入；独立主动施放，不恢复气血、不从治疗或过量治疗产生。同一般手动群体辅助，主目标指定，其余最多6个合法目标随机且不重复。此次确认没有把A40开放为宝宝可学技能，宝宝辅助单体规则不变。

**下表是建议试值，尚未实战验证或落入正式表**。A10的新治疗基数及成本也没有定案；仅为比较选取“同人物等级、同技能档位、无效果条目时，每目标普通治疗1000、整招耗最大法力6%、无冷却”的参照组，不修改现行治疗公式。

| 项目 | A40首测建议 | 平衡目的与边界 |
|---|---|---|
| 每目标基础容量 | 按同档A10普通治疗基础量的80%校准；参照治疗1000时，盾基础800 | 这是配表比较标尺，各等级配置自身基础容量；运行时不读取A10治疗结果、目标缺血或治疗加成来生成盾 |
| 容量加成 | 仅应用适用的护盾容量条目；示例800×1.20＝960 | 与治疗加成分别结算；治疗和护盾的等级曲线、正式修正公式与取整仍待定 |
| 持续时间 | 2回合：施放当回合剩余阶段＋下一回合；下一回合末到期 | R1行动中施放，持续到R2回合末状态到期阶段；不是每轮重新补800。R2回合末到期阶段之后新生成的事件不得再消耗该盾 |
| 耗蓝 | 成功施放时最大法力的8%，再按适用施法减耗与统一取整处理 | 整招扣一次，不按7目标乘7；最大法力2000且无减耗时耗160，参照治疗耗120。未通过施放校验时的资源处理仍遵循公用规则 |
| 冷却 | 3回合间隔：R1成功施放，R2/R3不可用，R4重新可用 | 按全局回合推进，不因施法者跳过行动额外缩短；死亡/复活如何保留剩余冷却与公用时序一起确认 |
| 吸收范围 | 经过防御及适用减伤后的直接物理、直接法术伤害 | 每个目标有独立容量，不是全队共享盾池；普通攻击及符合直接伤害标签的追击/反击伤害段同样按此处理，不在此决定其触发资格 |
| 不吸收 | 毒、灼烧等持续伤害，反弹伤害、援护转伤、生命消耗和其他资源代价 | 初版用明确伤害标签区分，不自动按显示为物理/法术就纳入；护盾不免控、不解控、不复活 |
| 驱散与死亡 | 建议作为可驱散增益；受护目标死亡时移除，施法者死亡不额外移除已生成盾 | 与A34清除项数/优先级配合；不是随施法者存活开关的光环 |
| 同名重复施放 | 同目标只保留一份A40，跨施法者也不叠加 | 新容量≥当前剩余量才以新容量完整替换、刷新时长并切换来源；更小则保留旧盾且不延时。无论原盾多大，都不把两份容量相加 |

同名覆盖例：旧盾剩600，新盾500不覆盖、不续时；旧盾剩200，新盾500替换为500并重新计时。一次合法群体施放按每目标分别判断，某人未获得覆盖不另选第8名、不按比例退还法力；全部目标已无合法资格的取消处理仍由公用规则确定。与B05/B06、B14、O03等不同来源护罩的吸收顺序及是否可并存尚未拍板，本方案不借此定义所有盾的优先级。

**与治疗、加防御的分工**：A10补已经损失的气血，A12处理残血救急，A26分回合恢复并按回生印规则复苏；A40提前提供短期、可耗尽的保护。A14仍提高物防/法防并持续5回合，每次适用攻击都通过伤害公式受益；不改变为固定减伤，也不认为“防御提高20%＝伤害降低20%”。A40不提高防御，不修复血线，未吸收的容量到期消失。

简化算例（只含A14与A40，不代表正式防御倍率）：某击原应扣1500血，800盾后扣700；若加防御后根据实际公式该击变为1200，再扣800盾，实际扣血400。防御只参与一次伤害计算，不在消耗盾容量之后再重复减伤。

七人都获得800容量时，初始容量总和最多5600，但未受击、过期、被驱散的部分不是实际收益；目标不足或旧盾更强时也不能按满七人新增5600统计。同理不能把七人治疗7000当成必得有效回血。

试打至少比较：满血预防爆发、残血救急、连续五回合磨血、毒/灼烧、减疗、驱散、物理/法术阵容、人物与宝宝混合目标和2至3名辅助轮流套盾。记录有效治疗、实际吸收、过期浪费、被驱散容量、耗蓝、行动机会、击杀与战斗时长；个人CD不能保证多人轮盾存在空窗。先验证不叠盾、动作成本、耗蓝与可反制性，再决定是否改容量或成本，不先加未经验证的全队共享CD。

## 5. 共同配表要求

- 普通输出组：A02/A06 最多5；爆发组：A39/A08 最多5。不得再把横戈、雷阵写回3目标。
- A03固定敌方最多5目标、降物攻5回合；用伤害倍率、降攻比例、耗蓝与冷却调整强度。A02保留稳定群伤优势，A39保留短窗爆发优势；不能让A03同时拿到同档群伤和免费的长期降攻。建议同名降攻不叠层，刷新/覆盖细则见公用规则待定项。
- 需要配合的单目标技能（A18/A28/A32/A37等）因条件/状态消费不同而保留，不是被合并普通单攻的别名。
- 主目标失效、补选规则、选到冰冻/免疫单位是否占名额、清除顺序、冷却计数、施法失败是否扣资源均在 [公用规则](combat-rules.md) 和 [实施清单](implementation.md) 标记，不由每个技能各写一套。
- 人物与宝宝共享原型的伤害属性基数按使用者计算，目标数按施法者区分：本页为人物规格，宝宝辅助单体、物法攻击及蚀骨毒最多敌2。人物碎甲击仍敌1，宝宝碎甲击为敌2。技能施加方、状态来源方、催动方要能在战报中区分。
